Cloudflare 토큰 받는 법

[차름 미술] 팝아트는 아무것도 넣지 않아도 기기마다 하루 3번 됩니다. 더 많이 쓰려면 선생님의 Cloudflare 계정(무료)을 넣습니다. Account ID와 API Token, 두 가지가 필요합니다.

  1. Cloudflare 가입 (이미 있으면 로그인) — 무료 요금제로 충분합니다.
  2. Account ID 복사: 로그인한 첫 화면에서 계정 이름 옆 ⋯ → Copy account ID를 누르거나, 왼쪽 메뉴 AI → Workers AI 화면에 보이는 Account ID를 복사합니다(32자리 영문·숫자).
  3. API 토큰 화면 열기
    Create Token → 본보기 목록에서 Workers AI의 Use template → Continue to summary → Create Token. 나온 토큰을 복사합니다(이 화면을 닫으면 다시 볼 수 없음).

    Global API Key는 넣지 마세요. Workers AI 권한만 있는 토큰을 이 일 전용으로 새로 만듭니다.

  4. 팝아트 오른쪽 ⚙ 편집 설정의 ① Account ID, ② API Token 칸에 붙여 넣습니다.

처음 개인 계정으로 사진 분석을 쓸 때 모델 사용 동의가 한 번 필요할 수 있습니다 — 모델 안내 페이지의 동의(agree) 절차를 따릅니다.

Cloudflare 정보는 브라우저에 저장하지 않고 페이지가 열려 있는 동안만 씁니다(창을 닫으면 다시 넣음). Gemini 키와 달리 차름 변환 서버를 거쳐 Cloudflare로 가므로, 다 쓰면 토큰 화면에서 지우세요.
키는 비밀번호와 같습니다. 남에게 보내거나 화면을 찍어 올리지 마세요. 손으로 옮겨 적지 말고 복사 단추로 복사합니다. 학교·교육청 계정은 막혀 있는 일이 많아 개인 계정을 씁니다.
