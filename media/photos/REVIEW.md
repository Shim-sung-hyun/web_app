# 차름 기증 사진 정리 절차 (Claude가 따름)

차름 사진 모음은 **한 앱만을 위한 자료가 아니다.** 낱말·도형·색·장소·분류·퍼즐·말하기 등
앞으로 만들 여러 학습에 계속 쓰는 공용 자료이므로, 사진마다 무엇이 보이는지를 넓게 적어 둔다.

## 흐름

1. 제작자가 `https://www.charum.org/charum-api/donate-admin.php`(관리자 로그인)에서 쓸 사진을 골라 "고른 것 보내기"
   → 비공개 저장소 `Shim-sung-hyun/charum-inbox`의 `inbox/<sid>/`(photo.jpg · art.jpg(있으면) · meta.json).
2. Claude가 정리(제작자가 "기증 사진 정리해 줘"라고 하거나 예약 작업):
   - `inbox/`의 사진마다 **직접 보고** 아래 "권리 검토"를 한다.
   - **문제 없음** → 분류해서 공개 저장소 `web_app/media/photos/<id>/`에 넣고 `photos.json`에 한 줄. inbox에서 지운다.
   - **걸림** → `flagged/<sid>/`로 옮기고 `review.json`을 쓴다. 가려서 쓸 수 있으면 흐리게 한 `fixed.jpg`도 만든다.
     → 관리자 화면 "다시 볼 사진"에 뜨고, 회원 메뉴의 "기증 사진" 숫자에 더해진다.
3. 제작자가 "그대로 저장 / 고친 것으로 저장 / 빼기"를 고르면 `decisions/<sid>.json`이 생긴다.
4. 다음 정리 때 Claude가 반영: keep → photo.jpg로, fixed → fixed.jpg로 사진 모음에 넣음 / drop → 지움.
   반영한 flagged·decisions 파일은 지운다. 처리한 것은 `log.json`에 한 줄씩(sid → 사진 id 또는 "뺌", 날짜, 까닭).

공개 저장소에는 **검토를 마친 사진만** 들어간다. 비공개 저장소의 사진은 누구도 볼 수 없다.

## 권리 검토 (하나라도 걸리면 flagged)

| 볼 것 | 걸리는 경우 | 고칠 수 있으면 |
|---|---|---|
| 초상권 | 사람 얼굴·몸(작게라도 알아볼 수 있으면), 액자·화면·포스터 속 사람 사진 | 그 부분 흐리게 |
| 개인 정보 | 이름표·이름 스티커, 전화번호, 차 번호판, 주소·집 번지·동 호수, 학교·기관 이름, 학생 명단·서류 | 흐리게 |
| 저작권 | 학생·남의 그림·만들기 작품이 주인공처럼 크게, 캐릭터(인형·스티커·그림 카드)가 또렷하게, 책 표지·포스터·화면 속 영상이 크게 | 가리거나 잘라 냄 |
| 상표 | 상표·로고가 사진의 주인공처럼 크게(물건에 작게 붙은 것은 괜찮음) | 흐리게 |
| 사생활 | 남의 집 안, 개인 주택이 주소와 함께 알아볼 수 있게 | 빼는 쪽을 권함 |
| 찍은 사람 | 인터넷에서 받은 사진·남이 찍은 사진으로 보이면(워터마크·화면 캡처) | 빼기 |

작게 스쳐 보이는 것(물건 위 작은 상표, 멀리 있는 책등)은 걸지 않는다. 애매하면 flagged로 보내 제작자가 정한다.
`check: none`(앱 검사 없이 온 것)은 더 꼼꼼히 본다.

`review.json` 꼴:
```json
{"title": "오븐과 전자레인지", "reasons": ["위에 놓인 작은 인형이 캐릭터일 수 있음"],
 "suggest": "인형 부분을 흐리게 한 사진(고친 사진)으로 저장하면 됨", "fixed": true}
```

## 분류 (photos.json 한 줄)

```
id        영문 폴더 이름(물건 이름, 예: oven-microwave). 겹치면 -2
title     학생이 아는 말로 된 이름("이것" 금지)
category  가전·전자기기 / 가구 / 생활용품 / 학용품 / 음식 / 동물 / 식물 / 탈것 / 길·시설 / 학교 시설 / 건물 / 자연 / 작품 / 놀이 / 옷 / 기타
objects   사진에 또렷이 보이는 것들(주인공 먼저) — 나중에 낱말 앱이 찾아 씀
place     교실·복도·화장실·급식실·운동장·바깥·집·가게·교통·기타
colors    주된 색 2~3개(빨강·주황·노랑·초록·파랑·남색·보라·분홍·갈색·흰색·검정·회색·은색·베이지)
shapes    또렷한 모양(원·세모·네모·원기둥·원뿔 …)
tags      장소 + 주제 몇 개
source    maker(제작자 사진·모으기) / donated(선생님 기증)
added     넣은 날(한국 날짜)
privacy   maker-checked
check     gemini / none / maker
rights    {owner, consent, review: "날짜 Claude 검토", status: ok|check, notes}
files     {photo, art(있으면), line(있으면)}
uses      앱별 쓰임: shape {ok:false, shapes:[…]}(도형이 또렷하면 — sample-maker에서 확인 뒤 ok) · puzzle (그림이 생기면 true)
```

사진은 긴 쪽 1280, 위치 정보 없이(JPEG 다시 저장). 넣은 뒤 art-maker·line-maker로 끝 그림·도안을 만들 수 있다.

## 소리도 같은 생각으로

`media/voice/`의 미리 만든 목소리도 공용 자료다. 묶음(`leda-0.92` 등)의 `index.json`에 글과 파일을 적고,
쓰는 앱은 `used_by`에 더한다. 한 앱만을 위해 앱 폴더에 넣지 않는다.
