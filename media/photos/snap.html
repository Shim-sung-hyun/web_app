사진 넣기

  1. 컴퓨터에서 github.com/settings/personal-access-tokens/new 열기 (저장소 설정이 아니라 오른쪽 위 내 사진 → Settings → 왼쪽 맨 아래 Developer settings → Fine-grained tokens)
  2. Repository access: Only select repositories → 사진을 받을 저장소 하나만
  3. Permissions → Repository → Contents: Read and write
  4. 만든 열쇠(github_pat_…)를 아래에 붙여 넣기

열쇠는 이 휴대폰 안에만 남고, 저장소나 다른 곳으로 가지 않아요. 휴대폰을 잃어버리면 GitHub에서 그 열쇠를 지우면 돼요.
