무대 설치도구

처음 장면 구상부터 그림 손질, 배치 검토, 최종 자료 내보내기까지 한 흐름으로 진행해요.

어떤 장면을 만들까요?

먼저 장면의 뜻과 이름을 적으면 배경 그림·소품 판을 만들 때 쓸 프롬프트 초안을 준비해요. 그림 생성은 사용하는 그림 서비스에서 진행한 뒤 다음 단계에서 불러옵니다.

9번 오른쪽 아래 칸은 비워 두는 구성이 기본이에요. 소품은 최대 8개예요.

배경 그림 프롬프트

소품 판 프롬프트

이 도구는 그림을 직접 생성하거나 외부 서비스에 보내지 않아요. 프롬프트를 복사해 원하는 그림 서비스에 붙여 넣고, 받은 그림을 다음 단계에서 불러와 주세요.

배경과 소품 그림을 불러와요

배경은 한 장, 소품은 흰 바탕의 3×3 판 한 장을 선택해요. 원본 파일은 바뀌지 않습니다.

무대 배경은 4:3 가로 그림이어야 해요.

이름 순서대로 왼쪽 위부터 채워 주세요. 오른쪽 아래는 비워 둬요.

밝은 회색을 소품으로 남기려면 값을 낮춰 보세요.

색이 있는 소품까지 지워지면 값을 낮춰요.

칸 사이 선이 있다면 여백을 늘려요.

자동 분리는 그림 인식 AI가 아니에요. 칸의 바깥과 이어진 밝은 색만 지우므로, 안에 갇힌 흰 점은 남을 수 있어요. 실제 그림을 확대해 확인하고 다음 단계에서 손질해 주세요.

소품 가장자리를 살펴요

각 그림을 골라 확대해 보고, 남은 흰 점은 지우개로, 잘못 지워진 부분은 복구 붓으로 칠해요. 투명한 바탕은 체크 무늬로 보여요.

소품을 먼저 골라 주세요

그림 위를 누르거나 끌어 칠해요. 잘못 손질하면 ‘이 소품 다시 자르기’로 자동 분리부터 다시 할 수 있어요.

배경 위에 소품을 놓아 봐요

그림을 끌어 옮기고, 선택한 소품의 크기와 밑동 위치를 조절해요. 이 시안은 검토용이며 원본 배경과 그림은 바꾸지 않습니다.

그림을 먼저 불러와야 배치할 수 있어요.

마지막으로 살펴보고 확정해요

배경과 소품이 자연스럽게 이어지는지, 소품의 흰 점·잘린 부분·크기·땅에 닿는 자리를 확대해 확인해요. 아래 체크를 마쳐야 확정 묶음을 만들 수 있습니다.

지원되는 브라우저에서는 `media/stage` 폴더를 골라 직접 저장할 수 있어요. 이미 있는 무대 자료를 바꿀 때는 한 번 더 확인해요. 직접 저장을 지원하지 않는 브라우저에서는 기존 파일을 덮어쓰지 않는 ZIP으로 내보내고, `index-entry.json`을 차림표에 합쳐 주세요.
