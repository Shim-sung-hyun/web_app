Cloud 키 넣는 방법

웹앱이 자연스러운 Google 목소리로 읽어 주려면 Google Cloud 키가 하나 필요합니다. 처음 한 번만 만들면 되고, 10분쯤 걸립니다. 키가 없어도 기기 목소리로는 바로 쓸 수 있습니다.

비용은요?

Google 목소리(Chirp 3: HD)는 매달 100만 자까지 무료입니다. 시 한 편이 보통 100~300자이고, 한 번 만든 목소리는 기기에 저장해 다시 쓰므로 수업에서 무료 한도를 넘기기는 어렵습니다. 다만 키를 만들려면 결제 카드 등록이 필요합니다. 아래 ⑥처럼 예산 알림을 걸어 두면 안심입니다.

요금은 바뀔 수 있습니다. 최신 내용: Text-to-Speech 가격

1Google Cloud 콘솔 들어가기

  1. console.cloud.google.com에 Google 계정으로 로그인합니다.
  2. 처음이면 이용 약관에 동의합니다.

2프로젝트 만들기

  1. 화면 위쪽의 프로젝트 선택을 누르고 새 프로젝트를 누릅니다.
  2. 이름(예: 수업 웹앱)을 넣고 만들기를 누릅니다.
  3. 다 만들어지면 위쪽에서 그 프로젝트가 선택되어 있는지 확인합니다.

3결제 계정 연결 (카드 등록)

  1. 왼쪽 메뉴 ☰ → 결제로 갑니다.
  2. 안내에 따라 결제 계정을 만들고 카드를 등록한 뒤, 이 프로젝트에 연결합니다.

무료 한도 안에서는 요금이 나가지 않습니다.

4Text-to-Speech API 켜기

  1. ☰ → API 및 서비스 → 라이브러리로 갑니다.
  2. 검색창에 Cloud Text-to-Speech API를 넣고, 나온 항목을 누릅니다.
  3. 사용을 누릅니다.

5API 키 만들기

  1. ☰ → API 및 서비스 → 사용자 인증 정보로 갑니다.
  2. 위쪽 + 사용자 인증 정보 만들기 → API 키를 누릅니다.
  3. 나온 키(AIza…로 시작)를 복사합니다.
  4. 안전하게 제한하기 (권장): 만든 키를 눌러
    • 애플리케이션 제한사항 → 웹사이트 → https://shim-sung-hyun.github.io/* 추가
    • API 제한사항 → 키 제한 → Cloud Text-to-Speech API만 고르기
    • 저장
    이렇게 하면 키가 남에게 알려져도 이 웹앱 말고는 쓸 수 없습니다.

6예산 알림 걸기 (권장)

  1. ☰ → 결제 → 예산 및 알림 → 예산 만들기.
  2. 금액을 1,000원처럼 작게 정하면, 혹시 요금이 생길 때 메일로 알려 줍니다.

7웹앱에 넣기

  1. 웹앱에서 오른쪽 아래 관리 버튼(파란 유리알)을 누릅니다.
  2. 목소리에서 Google을 고르고, Cloud 키를 넣어 주세요 칸에 복사한 키를 붙여 넣습니다.
  3. 이 기기에 키 저장에 체크하면 다음부터 다시 넣지 않아도 됩니다.
  4. 들어 보기로 목소리가 나오는지 확인합니다.

같은 사이트의 다른 웹앱(사진 속 도형 찾기, 무지개 색 찾기 등)에 저장한 키가 있으면 자동으로 채워집니다.

꼭 지켜 주세요

  • API 키는 개인 것입니다. 다른 선생님께는 웹앱 주소만 알려 드리고, 키는 각자 만들어 쓰도록 안내해 주세요.
  • 여러 사람이 쓰는 컴퓨터에서는 "이 기기에 키 저장"을 끄세요.
  • 키가 알려졌다면 ⑤의 사용자 인증 정보에서 그 키를 지우고 새로 만드세요.
