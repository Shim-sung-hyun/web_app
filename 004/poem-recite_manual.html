전자칠판·태블릿용 웹앱 · 설치 없이 바로 실행

무엇을 하나요

시를 화면 가득 크게 보여 주고, 글자를 하나씩 가려 가며 외웁니다. 글자를 누르면 그 글자부터 낱말 끝까지 ( )로 가려지고, ( )를 누르면 한 글자씩 다시 나타납니다. 목소리로 시를 들려주거나, 한 줄씩 듣고 따라 읽을 수도 있습니다. 이 글 위의 ▶ 앱 바로 실행 버튼만 누르면 됩니다.

시작하기

  1. 앱을 열면 "시 암송하기"만 크게 보입니다.
  2. 오른쪽 아래 작은 파란 유리알(관리 버튼)을 한 번 누르면 시와 관리 메뉴가 나옵니다. 여기서 시, 가리기 단계, 글꼴, 목소리를 고릅니다.
  3. 관리 버튼을 다시 한 번 누르면 메뉴가 사라지고 전체 화면으로 수업이 시작됩니다. 수업 중에도 언제든 한 번 눌러 메뉴를 열고 닫습니다.

▲ 첫 화면과, 관리 버튼을 누른 모습 — 위쪽: 가리기 단계 · 시 · 단 · 글꼴 · 소리 · 목소리(Cloud 키 넣는 방법) / 아래쪽: 들려주기 · 한 줄씩 따라 읽기 · 출력

관리 메뉴

  • 시: 공통시(새)와 계절시 네 편. + 새 시로 직접 입력하거나 .txt 파일(첫 줄 제목, 둘째 줄 작가, 나머지 본문, 빈 줄 = 연 나눔)을 불러옵니다. 직접 입력한 시는 여러 편 저장되어 목록에 함께 나옵니다. 예전 앱에서 입력해 둔 시도 그대로 옮겨 옵니다.
  • 단: 자동(가장 크게 보이는 쪽) 또는 1~4단.
  • 글꼴: 명조(시다운 글꼴) · 둥근 글씨(글자를 처음 읽는 학생).
  • 목소리: 기기는 키 없이 바로 나옵니다. Google은 자연스럽고, 고르면 "Cloud 키를 넣어 주세요" 칸이 나옵니다. 키 만드는 방법은 목소리 옆의 Cloud 키 넣는 방법(안내 페이지)에 차례대로 적어 두었습니다(결제 카드 등록 필요, 매달 100만 자 무료). 다른 앱(001·003)에서 저장한 키가 있으면 자동으로 채워집니다. "이 기기에 키 저장"은 여러 사람이 쓰는 컴퓨터라면 끄세요.
  • 출력 (빈칸 활동지): 지금 가린 모습 그대로 이름 칸과 함께 A4 한 장에 인쇄합니다.

가리기 단계

한꺼번에 지우지 않고 조금씩 지워 가며 외웁니다. 글자를 직접 눌러 가리는 것도 그대로 됩니다.

① 전체모두 보임
② 반 가리기낱말 하나 걸러 하나씩 가림
③ 낱말 첫 글자낱말마다 첫 글자만 남김
④ 줄 첫 글자줄마다 첫 글자만 남김 (예전 "첫 글자만 남기기")
⑤ 다 가리기제목까지 모두 ( )

수업 흐름

① 시 보기

▲ 학생 화면에는 메뉴가 없습니다. 화면에 맞춰 단 수와 글자 크기가 저절로 정해집니다.

② 반 가리기 → ③ 낱말 첫 글자

▲ 가려진 ( )를 누르면 한 글자씩 다시 보입니다. 학생이 떠올리지 못할 때 첫 글자만 살짝 보여 주는 데 씁니다.

④ 들려주기

▲ 제목 → 작가 → 본문을 이어서 읽고, 지금 읽는 줄에 옅은 초록 바탕이 생깁니다. 줄과 연이 바뀔 때 조금 더 쉬어 줍니다. 가려진 글자도 소리로는 다 읽어 줍니다.

⑤ 한 줄씩 따라 읽기

▲ 한 줄을 읽어 준 뒤 그 줄이 노란 바탕으로 바뀌고 "따라 해요"가 나옵니다. 읽은 시간의 1.4배(최소 2초) 동안 학생이 따라 말하고, 저절로 다음 줄로 넘어갑니다.

⑥ 둥근 글씨

주의할 점

  • 직접 입력한 시는 그 기기(브라우저)에만 저장됩니다. 다른 기기에서 쓰려면 .txt 파일로 준비해 불러오세요.
  • API 키는 개인 것입니다. 다른 분에게는 이 글 주소만 알려 드리고, 키는 각자 만들어 쓰도록 안내해 주세요.
