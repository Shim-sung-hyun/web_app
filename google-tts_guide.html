Google 음성 키 받는 법

선생님이 넣은 시·낱말, 내 사진의 물건 이름을 앱에 들어 있는 목소리와 같은 목소리로 읽을 때만 필요합니다. 없으면 그런 말은 기기 목소리로 읽습니다. 카드 등록이 필요하고, 컴퓨터에서 15분쯤 걸립니다.

매달 일정량은 요금이 나가지 않고, 한 번 만든 목소리는 기기에 저장해 다시 씁니다. 최신 요금: Text-to-Speech 가격

만들기

  1. Google Cloud 콘솔 열기
    개인 구글 계정으로 로그인합니다. 처음이면 나라(대한민국)를 고르고 약관에 동의합니다.
  2. 맨 위 프로젝트 선택 → 새 프로젝트 → 이름 차름 목소리 → 만들기. 맨 위 칸에 이 프로젝트 이름이 보이는지 확인합니다. 아래 단계는 모두 이 프로젝트에서 합니다.
  3. 결제 화면 열기
    결제 계정을 만들어 카드를 등록하고 이 프로젝트에 연결합니다. 이미 있으면 결제 계정 연결만.
  4. Text-to-Speech 화면 열기
    프로젝트 이름이 맞는지 보고 사용(Enable)을 누릅니다. 관리가 보이면 이미 켜져 있습니다.
  5. 사용자 인증 정보 열기
    + 사용자 인증 정보 만들기 → API 키. 만드는 창에서:
    • API 제한사항: 키 제한 → Cloud Text-to-Speech API 하나만 체크.
    • 애플리케이션 제한사항: 웹사이트 → 아래 세 줄을 하나씩 추가. 세 줄 모두 넣어야 어느 주소에서 열어도 됩니다.
      https://www.charum.org/*
      https://charum.org/*
      https://shim-sung-hyun.github.io/*
    • "서비스 계정을 통해 API 호출 인증" 칸은 체크하지 않습니다.
    만들기를 누르면 AIza로 시작하는 키가 나옵니다. 복사 단추로 복사합니다.

    나중에도 목록에서 키 이름 → 키 표시로 다시 복사할 수 있습니다. 창에 제한 칸이 없으면 만든 뒤 키 이름을 눌러 넣고 저장합니다.

  6. (권장) 예산 및 알림 → 예산 만들기에서 1,000원처럼 작게 정해 두면 혹시 요금이 생길 때 메일로 알려 줍니다.

앱에 넣기

  • [차름 국어] 시 외우기 — 첫 화면 제목을 눌러 메뉴 → 더 정하기 → 목소리 Google (키) → 키 칸
  • [차름 국어] 낱말 익히기 — 설정 화면 목소리 → Google 음성 (키) → 키 칸
  • [차름 수학] 도형 찾기 — 설정 화면 더 정하기의 목소리 내 Google 음성 → 키 칸(휴대폰에서 사진 받을 때 함께 물어보기도 함)

✔️ 들어 보기로 목소리가 나오면 끝입니다.

잘 안 될 때

기기 목소리로만 나와요5번의 웹사이트 세 줄과 API 제한(Cloud Text-to-Speech API)을 확인하세요. 고친 뒤 몇 분 지나야 적용됩니다.
"API가 사용 설정되지 않음"4번을 같은 프로젝트에서 했는지 맨 위 프로젝트 이름을 보세요.
"결제를 사용 설정하세요"3번 결제 연결이 이 프로젝트에 되어 있는지 보세요.
"사용량을 넘었어요"그 수업은 기기 목소리로 이어집니다. 다음 날 다시 되거나 결제 화면에서 사용량을 보세요.
키를 지우고 싶어요앱의 키 칸 옆 키 지우기. 콘솔에서 지우면 어디에서도 못 씁니다.
이 프로젝트(결제 연결)에서 Gemini 키를 만들지 마세요. Gemini 키는 따로 받습니다.
키는 비밀번호와 같습니다. 남에게 보내거나 화면을 찍어 올리지 마세요. 손으로 옮겨 적지 말고 복사 단추로 복사합니다. 학교·교육청 계정은 막혀 있는 일이 많아 개인 계정을 씁니다.
