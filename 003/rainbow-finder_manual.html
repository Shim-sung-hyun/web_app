무지개 색 찾기 사용 설명서

전자칠판·태블릿용 웹앱 · 설치 없이 바로 실행

무엇을 하나요

"빨강을 찾아요." 하고 말하면, 떠다니는 색 동그라미 가운데 그 색을 찾아 누릅니다. 맞히면 말 대신 동그라미가 "뽁" 하고 터지고, 그 자리에 새 동그라미가 생기며 다음 색을 말해 줍니다. 다른 색을 누르면 아무 반응도 없습니다(기록만 남습니다). 대신 정한 시간 안에 못 찾으면 정답이 천천히 커졌다 작아지며 알려 주는 도와주기를 켤 수 있습니다. 이 글 위의 ▶ 앱 바로 실행 버튼만 누르면 됩니다.

처음 한 번 준비

  1. 목소리 고르기
    • Google 음성: 자연스럽습니다. console.cloud.google.com에서 Cloud Text-to-Speech API를 사용 설정하고 API 키를 만들어 넣습니다. 결제 카드 등록이 필요하지만 매달 100만 자까지 무료입니다. '사진 속 도형 찾기'에서 저장한 키가 있으면 자동으로 채워집니다.
    • 기기 목소리: 키 없이 바로 나오지만 기계 소리입니다.
    • 목소리 들어 보기로 미리 확인하세요.
  2. 키 저장: "이 기기에 키 저장"에 체크하면 다음부터 다시 넣지 않아도 됩니다. 여러 사람이 쓰는 컴퓨터라면 끄세요.

수업 정하기

누가 쓰나요교사와 함께 · 학생 혼자 (학생이 동그라미 수와 색 수를 고르고 시작)
찾는 방식같은 색 찾기 (위에 색을 함께 보여 줌) · 이름 듣고 찾기 (이름만)
모양동그라미 · 물건 (풍선·컵·자동차·티셔츠·우산·양말·물고기·별·꽃 — 여러 물건에서 같은 색 찾기, 일반화 단계)
도와주기 (시간 지연)끔 · 5초 · 3초 · 바로. 정한 시간 안에 못 찾으면 정답이 멈추고 천천히 커졌다 작아집니다(번쩍임 없음). "바로"는 처음부터 정답을 알려 주는 무오류 학습입니다.
한 번에 나오는 동그라미2개 · 4개 · 8개 · 10개 · 15개 (색 수보다 많을 수 없음)
나오는 색의 수7색 (빨주노초파남보) · 11색 (+ 연두·하늘색·분홍·갈색) · 15색 (+ 검정·하양·회색·청록)
움직이는 빠르기멈춤 · 느리게 · 보통 · 빠르게
문제 수5번 · 10번 · 20번

색은 왜 15색까지인가요? 학생이 헷갈리지 않도록, 서로 충분히 달라 보이는 색(색차 ΔE2000 20 이상)만 남겼습니다. 노랑과 금색, 회색과 은색, 파랑과 감색, 빨강과 다홍처럼 비슷한 색은 뺐고, 그렇게 고르니 15색이 되었습니다.

추천 순서: ① 같은 색 찾기 · 동그라미 2개 · 7색 · 멈춤 · 도와주기 바로 → ② 도와주기를 3초, 5초로 늘리고 끄기 → ③ 동그라미 수 늘리기 → ④ 이름 듣고 찾기 → ⑤ 움직이기 → ⑥ 물건 모양으로 일반화.

마구 누르기 방지: 다른 색을 누른 뒤 1초 동안은 눌러도 받지 않습니다. 화면에 보이는 반응은 없습니다.

수업 흐름

학생 화면에는 메뉴가 없습니다. 시작하면 동그라미가 바로 움직입니다. 맞힌 동그라미만 터지고 나머지는 계속 움직이며, 새 동그라미가 하나 생기면서 다음 색을 말해 줍니다. 다음에 찾을 색은 화면의 동그라미 가운데 똑같은 확률로 고릅니다. 그래서 새로 생긴 동그라미가 정답일 확률도 동그라미 수만큼 나눈 만큼(10개면 10분의 1)이라 "새것만 누르면 된다"가 통하지 않습니다.

① 같은 색 찾기 (동그라미 10개 · 11색)

▲ 위에 찾을 색과 이름이 함께 보입니다. 아래 점은 문제 진행이며, 찾은 색으로 하나씩 채워집니다.

② 찾았을 때

▲ 남색을 찾은 순간 — 같은 색 물방울이 튀며 터지고 작게 "뽁" 소리가 납니다. 위의 안내는 벌써 다음 색으로 바뀌었고, 곧 새 동그라미가 생깁니다.

③ 동그라미 15개 · 15색

▲ 가장 어려운 단계입니다. 동그라미 크기가 서로 크게 다릅니다(2개일 때는 거의 같은 크기, 많을수록 크기 차이가 커짐). 한 화면의 동그라미는 모두 다른 색이고, 서로 겹치지 않게 부드럽게 튕깁니다.

④ 도와주기 (시간 지연)

▲ 3초 안에 못 찾자 정답(초록 자동차)이 멈추고 천천히 커졌다 작아지며 알려 줍니다. 이렇게 맞히면 기록에 "도움 받아 맞힘"으로 남습니다.

⑤ 물건 모양 (일반화)

▲ 동그라미 대신 여러 물건이 떠다닙니다. "초록"은 티셔츠에도, 자동차에도 있다는 것, 곧 색이 물건의 모양과 상관없는 성질이라는 것을 익힙니다. 물건마다 한 가지 색으로만 그려 다른 색이 섞이지 않습니다.

⑥ 이름 듣고 찾기

▲ 글자도 색도 보여 주지 않고 스피커 표시만 나옵니다(글을 읽는 학생에게 글자가 단서가 되지 않도록). 학생이 스피커를 누르면 다시 들려줍니다. 같은 색 찾기에서도 위쪽 안내를 누르면 다시 들려줍니다.

⑦ 학생 혼자 쓸 때

▲ 학생이 위 줄에서 동그라미 수(점 개수로 보임), 아래 줄에서 색 수(색 점으로 보임)를 고르고 시작을 누릅니다. 고르면 "네 개.", "일곱 가지 색."처럼 말해 줍니다. 색 수보다 많은 동그라미는 고를 수 없게 흐려집니다. 끝나면 찾은 색들과 다시 하기가 나오고, 누르면 다시 고르는 화면으로 갑니다. 점수는 보여 주지 않습니다.

교사 모드

화면 오른쪽 아래의 작은 파란 유리알 버튼(charum)을 3초 동안 누르면 켜지고(심), 한 번 더 3초 누르면 꺼집니다.

  • 위쪽 맨 앞 ▶ 새로 시작: 바꾼 설정으로 처음부터 다시 시작합니다. 하는 중이든 끝난 뒤든 언제나 누를 수 있습니다.
  • 위쪽: 동그라미 수, 색 수, 속도, 방식(같은 색 · 이름 듣고), 모양(동그라미 · 물건), 도움(끔 · 5초 · 3초 · 바로), 문제 수, 사용(교사와 함께 · 학생 혼자), 소리, 설정. 동그라미 수·색 수·속도·방식은 하던 판에 바로 적용되고, 처음부터 하려면 새로 시작을 누릅니다. 설정 화면으로 돌아가지 않아도 됩니다(목소리 바꾸기만 설정 화면에서).
  • 아래쪽 (하는 중): 다시 듣기, 다음 문제, 여기까지, 기록.
  • 아래쪽 (끝난 뒤): 다시 하기, 기록(문제마다 바로 맞힘 / 다시 해서 맞힘 / 도움 받아 맞힘, 먼저 누른 색, 우연히 맞힐 확률), 출력 두 가지.
  • 출력 · 학생용 색칠하기: 오늘 나온 색 이름과 빈 동그라미만 A4 한 장에 인쇄합니다. 크레파스로 이름에 맞게 색칠하며 다시 익힙니다.
  • 출력 · 교사용 기록: 설정, 바로 맞힘 비율과 우연히 맞힐 확률(예: 동그라미 4개면 25%), 색마다 결과와 대신 누른 색, 문제마다 기록을 A4 한 장에 인쇄합니다.

기록은 화면을 닫으면 사라집니다. 필요하면 출력하거나 화면을 캡처해 두세요.

주의할 점

  • 화면 밝기나 기기에 따라 색이 조금 달라 보일 수 있습니다. 실제 크레파스·색종이와 함께 보여 주면 좋습니다.
  • API 키는 개인 것입니다. 다른 분에게는 이 글 주소만 알려 드리고, 키는 각자 만들어 쓰도록 안내해 주세요.
