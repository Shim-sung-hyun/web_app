글자 익히기

그림이 붓이 되어 글자를 써요 · 기초 낱말

1키 설정

전자칠판이라면 휴대폰에서 Gemini 키와 Google 음성 키를 한 번에 보내요.
Gemini 키 받기: aistudio.google.com/apikey 에서 Create API key(API 키 만들기)를 누르고, 키를 복사해 아래 칸에 넣으세요.
Gemini 그림은 무료가 아니에요. 결제 등록이 필요하고, 그림을 한 장 그릴 때마다 약 50원이 들어요. 그린 그림은 이 기기에 저장해 다시 쓰므로, 같은 낱말은 다시 그리지 않는 한 또 들지 않아요(다시 그리기를 하거나 다른 기기·브라우저에서 처음 그릴 때는 다시 들어요). 돈을 쓰지 않으려면 "기본 그림"을 고르세요.
키가 없으면 기본 그림으로 해요.
Google 음성 키 받는 법
  1. Google Cloud 콘솔에서 프로젝트를 고르고(없으면 만들기), 결제 계정을 연결해요. 매달 100만 자까지 무료예요.
  2. Cloud Text-to-Speech API 화면에서 사용을 눌러요.
  3. 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키를 눌러 키를 복사하고, 아래 칸에 붙여 넣어요.
Cloud 키 넣는 방법 (자세히)
넣은 키는 이 기기(브라우저)에 저장돼요. 여러 사람이 쓰는 컴퓨터라면 수업을 마친 뒤 키 지우기를 눌러 주세요.

2오늘 수업

학생을 고르면 기록이 시작돼요. 고르지 않으면 기록하지 않아요(시범·연습). 명단은 이 사이트의 다른 앱과 함께 써요.
"그림으로 쓴 글자부터"를 고르면, 보기 맨 처음에 사과 그림들이 모여 "사과" 글자가 돼요. 그다음 평범한 글자로 넘어가요.
처음에는 쉬운 글꼴(고딕·둥근 글씨)로 시작하고, 익숙해지면 다양하게 바꿔요.
