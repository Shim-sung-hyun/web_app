Google 음성 키 받는 법

앱에 미리 들어 있지 않은 말(선생님이 넣은 시·낱말, 내 사진의 물건 이름)을 앱의 목소리와 같은 목소리로 읽고 싶을 때만 필요합니다. 키가 없으면 그런 말은 기기 목소리로 읽습니다. 처음 한 번 만들면 되고, 컴퓨터에서 천천히 하면 15분쯤 걸립니다.

먼저 알아 두기

  • 컴퓨터에서 만드는 것을 권합니다. 휴대폰으로도 되지만 화면이 좁아 단추를 찾기 어렵습니다. 만든 키는 전자칠판에 휴대폰으로 받기로 보낼 수 있습니다(7번).
  • 개인 구글 계정이 필요합니다. 학교·교육청 계정은 막혀 있는 일이 많습니다.
  • 키를 만들려면 결제 카드 등록이 필요합니다. 매달 일정량은 요금이 나가지 않고, 한 번 만든 목소리는 기기에 저장해 다시 씁니다. 6번처럼 예산 알림을 걸어 두면 안심입니다. 최신 요금: Text-to-Speech 가격

만들기

  1. Google Cloud 콘솔 열기

    개인 구글 계정으로 로그인합니다. 처음이면 나라(대한민국)를 고르고 약관에 동의합니다.

    Google Cloud 콘솔 열기 →
  2. 프로젝트 만들기

    화면 맨 위의 프로젝트 선택(프로젝트 이름이 보이는 칸)을 누르고 새 프로젝트를 누릅니다. 이름은 차름 목소리처럼 아무거나 넣고 만들기를 누릅니다.

    다 만들어지면 맨 위 칸에 그 프로젝트 이름이 보이는지 확인합니다. 다른 프로젝트가 보이면 눌러서 바꿉니다. 아래 모든 단계는 이 프로젝트에서 합니다.

  3. 결제 연결 (카드 등록)

    아래 단추로 결제 화면을 열고, 안내에 따라 결제 계정을 만들어 카드를 등록한 뒤 이 프로젝트에 연결합니다.

    결제 화면 열기 →

    이미 결제 계정이 있으면 결제 계정 연결만 하면 됩니다.

  4. Text-to-Speech 켜기

    아래 단추를 누르면 Cloud Text-to-Speech API 화면이 열립니다. 맨 위에 2번의 프로젝트 이름이 맞는지 보고 사용(Enable)을 누릅니다.

    Text-to-Speech 화면 열기 →

    이미 관리(Manage)가 보이면 켜져 있는 것입니다.

  5. API 키 만들기 사용자 인증 정보 열기 →

    위쪽 + 사용자 인증 정보 만들기 → API 키를 누릅니다. 키를 만드는 창이 나오면:

    • API 제한사항: 키 제한을 고르고 목록에서 Cloud Text-to-Speech API 하나만 체크합니다. (꼭 하나는 골라야 키가 만들어집니다.)
    • 애플리케이션 제한사항: 웹사이트를 고르고 아래 세 줄을 하나씩 추가합니다. 세 줄 모두 넣어야 차름 앱이 어느 주소에서 열려도 됩니다.
      https://www.charum.org/*
      https://charum.org/*
      https://shim-sung-hyun.github.io/*
    • "서비스 계정을 통해 API 호출 인증" 같은 체크 칸이 보이면 체크하지 않습니다.

    만들기(Create)를 누르면 AIza로 시작하는 키가 나옵니다. 옆의 복사 단추로 복사합니다(손으로 옮겨 적지 않기).

    창을 닫은 뒤에도 사용자 인증 정보 목록에서 키 이름을 누르고 키 표시로 다시 복사할 수 있습니다. 제한 칸이 창에 없으면 키를 만든 뒤 키 이름을 눌러 같은 내용을 넣고 저장합니다.

  6. 예산 알림 걸기 (권장)

    예산 및 알림 → 예산 만들기. 금액을 1,000원처럼 작게 정하면, 혹시 요금이 생길 때 메일로 알려 줍니다.

앱에 넣기

  1. 키 칸 찾기
    • [차름 국어] 시 외우기: 첫 화면 제목을 눌러 메뉴를 열고 위 줄 더 정하기 → 목소리 Google (키) → 키 칸
    • [차름 국어] 낱말 익히기: 설정 화면 목소리를 펼쳐 Google 음성 (키) → 키 칸
    • [차름 수학] 도형 찾기: 설정 화면 더 정하기의 목소리 내 Google 음성 → 키 칸 (사진을 휴대폰에서 받을 때 처음 한 번 함께 물어보기도 합니다)

    붙여 넣기 쉬운 기기(컴퓨터·태블릿)는 칸에 붙여 넣습니다. 전자칠판은 키 칸 옆 📱 휴대폰으로 받기를 누르고, 나온 QR을 휴대폰으로 찍어 휴대폰 화면의 Google 음성 키 칸에 붙여 넣고 보냅니다.

    같은 인터넷 주소(같은 기기)에서 다른 차름 앱에 넣어 둔 키는 저절로 채워집니다.

✔️ 들어 보기로 목소리가 나오면 끝입니다. 키는 그 기기(인터넷 창)에만 저장되고 차름 서버로 가지 않습니다.

잘 안 될 때

기기 목소리로만 나와요 · "키 확인"5번의 웹사이트 세 줄이 모두 들어 있는지, API 제한에 Cloud Text-to-Speech API가 체크되어 있는지 보세요. 고친 뒤 몇 분 지나야 적용됩니다.
"API가 사용 설정되지 않음"4번을 같은 프로젝트에서 했는지 확인하세요(맨 위 프로젝트 이름).
"결제를 사용 설정하세요"3번 결제 연결이 이 프로젝트에 되어 있는지 확인하세요.
"키 모양이 맞지 않아요"일부만 복사했거나 앞뒤에 빈칸이 붙었습니다. 복사 단추로 다시 복사하세요.
"사용량을 넘었어요"그 수업은 기기 목소리로 이어집니다. 다음 날 다시 되거나, 결제 화면에서 사용량을 확인하세요.
키를 지우고 싶어요앱의 키 칸 옆 키 지우기. 콘솔에서 키를 지우면 어디에서도 쓸 수 없게 됩니다.

키는 비밀번호와 같습니다. 남에게 보내거나 화면을 찍어 올리지 마세요. 이 키(결제 연결)로 Gemini 키를 만들지 마세요 — 도형 찾기의 Gemini 키는 따로 받습니다.
