글자 익히기

베타그림이 붓이 되어 글자를 써요 · 1~5편 생활 낱말 349개

1목소리

전자칠판이라면 휴대폰에서 Google 음성 키를 보내요.
Google 음성 키 받는 법
  1. Google Cloud 콘솔에서 프로젝트를 고르고(없으면 만들기), 결제 계정을 연결해요. 매달 100만 자까지 무료예요.
  2. Cloud Text-to-Speech API 화면에서 사용을 눌러요.
  3. 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키를 눌러 키를 복사하고, 아래 칸에 붙여 넣어요.
Cloud 키 넣는 방법 (자세히)
넣은 키는 이 기기(브라우저)에 저장돼요. 여러 사람이 쓰는 컴퓨터라면 수업을 마친 뒤 키 지우기를 눌러 주세요.

2학생과 수준

학생을 고르면 기록이 시작되고, 그 학생의 수준과 다음 묶음을 불러와요. 고르지 않으면 기록하지 않아요(시범·연습).

3오늘 수업

더 정하기 (놀이 · 보기 · 쓰기 · 글꼴)
"그림으로 쓴 글자부터"를 고르면, 보기 맨 처음에 사과 그림들이 모여 "사과" 글자가 돼요. 장면 그림 낱말은 이 장면 없이 바로 시작해요.
처음에는 쉬운 글꼴(고딕·둥근 글씨)로 시작하고, 익숙해지면 다양하게 바꿔요.

내가 넣은 낱말

1~5편 낱말 349개는 그림이 들어 있어요. 여기서는 선생님이 더 넣을 낱말을 관리해요. 낱말마다 사진 넣기로 그림을 넣어야 수업에 나와요(흰 바탕이면 바탕을 지워요). 사진은 이 기기에만 저장되고 바깥으로 보내지 않아요.
.txt: 한 줄에 낱말 하나. #으로 시작하는 줄은 건너뛰어요. 넣은 낱말은 "내가 넣은 낱말" 편에서 골라요.
그림이 없어 묶음에서 뺀 낱말(가족·친구 사진을 넣으면 좋아요):
그림낱말
아직 넣은 낱말이 없어요.
