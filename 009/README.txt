009 [차름 과학] 동물원 2편 · 동물 다섯 고개 (교과 차름 과학 · 이름 동물원 · 2편 · 편 이름 동물 다섯 고개) — 과학 영역(보라 #6A4C9C)
전 단계: 동물원 1편 · 동물이 사는 곳(008). 동물 그림·보라색·뼈대(설정·관리 메뉴·기록)는 1편과 같고, 표시는 다섯 점.
예전에 따로 만든 "다섯고개! 알아맞춰 봐요"를 지침에 맞춰 새로 만듦(2026-10-26). 옛 판과 달라진 것: 글로 쓰기·보기 6개·"❌ 아쉬워요"·외부 사진·어려운 힌트 말을 없앰.

파일
- animal-riddle.html : 앱(아직 첫 판 — 선생님 확인 전)
- server-loader.html : 서버 study/009/에 animal-riddle.html 이름으로 올리는 불러오기 파일

한 묶음(다섯 마리): 보기(이름 → 고개 하나씩) → 다섯 고개(동물마다 한 문제) → 정리하기(다섯 마리를 늘 같은 자리에 펼치고, 그 동물만 남는 고개를 한꺼번에) → 카드 뒤집기(보상, 끌 수 있음, 기록 안 함) → 끝 장면
수준(카드 수와 좁히는 방법)
- 1: 카드 2장 · 고개를 들으면 아닌 동물이 저절로 흐려짐 → 남은 하나를 누름
- 2: 카드 3장 · 고개를 들은 뒤 아닌 동물을 학생이 눌러 지움(맞는 동물을 누르면 반응 없음, 8초 뒤 다시, 16초 뒤 지울 동물이 빛남)
- 3: 카드 4장 · 고개를 끝까지 들은 뒤 고름(틀리면 반응 없이 정답이 빛남)
선생님과 함께: 설정에서 묶음을 3개까지 골라 차례로 / 학생 혼자: 학생 화면의 묶음 고르기에서 학생이 고름(마친 묶음 ✓)

고개 규칙(무오류의 핵심)
- 고개 차례: 사는 곳 → 다리 수 → 생김새 → 먹이 → 소리(있는 것만, 다섯까지). 생김새는 그림에서 보이는 것만(2026-10-26 그림을 보고 정함).
- 고개는 그 동물에게 늘 참인 것만. 다른 동물을 흐리게·지우게 할 때는 "확실히 아닌" 것만 — 모르는 것(먹이 칸이 빈 동물, 다리 ?, 그럴 수도 있는 생김새)으로는 흐리게 하지 않음.
  예: 고양이는 줄무늬가 있을 수도 있어 "줄무늬"로 흐리지 않음 / 소 그림에는 뿔이 없어 "뿔" 고개를 쓰지 않음.
- 보기 카드는 앱이 고름: 고개로 반드시 빠지는 동물만(끝까지 들으면 늘 하나만 남음). 같은 묶음 동물을 먼저.
- 묶음 안 다섯 마리는 고개로 모두 가려져야 함(정리하기). 물고기·상어·고래, 거미·원숭이는 가를 수 없어 한 묶음에 두지 않음.
- 자료를 고치면 콘솔에서 확인: 묶음마다 elimAt(정답, 다른 동물) >= 0, 모든 동물·수준에서 pickOpts(동물, 수준, [])가 카드 수만큼 나와야 함.
