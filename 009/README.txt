수준(설정 ②) — 모두 학습 → 퀴즈 → 정리하기 → 같은 동물 찾기
- 하 · 다섯 고개: 오늘의 동물 4마리. 학습(이름 → 고개 다섯) → 퀴즈(동물마다 고개 다섯 번, 고개 하나에 카드 2장: 그 동물 + 그 고개에 확실히 맞지 않는 동물, 매번 다른 동물)
- 중 · 열 고개: 5마리. 학습 → 고개 열 개(*표 단서). 첫 고개에 사는 곳 배경, 고개마다 동물 그림자가 물이 차오르듯 발부터 위로(윗선은 일렁이는 물결,
  동물 모양 그대로 진한 색 불투명 92%, 끝 고개에 다 참. 2026-10-31 바둑판 조각 방식은 이음매가 보여 없앰) → 학생이 이름을 말하면 동물이 나타남.
  답하는 줄(2026-10-31): [정답(마이크)] [선생님이 넣어 주세요 칸 + 확인] [패스]. 정답 단추를 누를 때만 들음(읽던 고개는 멈춤, 7초 말 없으면 멈춤, 다시 누르면 끔).
  말이 어렵거나 기기가 못 알아들으면 선생님이 들은 이름을 칸에 써서 확인. 음성 인식이 없는 브라우저면 정답 단추를 눌렀을 때 크롬을 권하는 말이 나옴.
- 상 · 스무고개: 10마리. 학습(10마리 카드를 눌러 특징을 글과 함께) → 고개 스무 개. 처음 서식지 배경만, 고개는 말과 글로만(그림 단서 없음, 2026-10-27) → 기기 키보드로 이름을 쓰거나 [정답(마이크)]을 누르고 말해서 맞히면 동물이 나타남
  (들은 말은 아래에 작게 보여 주고, 칸이 비어 있으면 칸에도 넣어 줌).
  (자료의 #p 부위·#f 먹이 표시는 지금 쓰지 않음 — 다시 그림 단서를 쓰게 되면 씀)
- 중·상 고개는 말이 끝나고 7초·9초 뒤 저절로 다음(쓰는 중·말하는 중이면 기다림). '패스'를 누르면 기다리지 않고 바로 다음 고개(마지막이면 정답). 다 들어도 못 맞히면 12초 뒤 정답을 보여 줌(도움). 틀린 답에는 반응 없음.
- 하·중은 동물 하나가 한 묶음(2026-10-26 선생님 의견): 특징 학습 → 고개(하 다섯·중 열) → 특징 정리(그 동물과 특징을 한 화면에, 한 번 읽어 줌) → 정지.
  단추 "○○ 한 번 더"(특징 학습부터 고개까지 다시) / "다음 동물"(마지막이면 정리하기로). 저절로 넘어가지 않음. 관리 메뉴 단계 이름은 '동물 하나씩'
- 같은 동물 찾기(놀이, 기록 안 함): 하 2쌍(첫 카드 열린 채, 틀리면 둘 다 닫힘) / 중 5쌍(틀리면 1초 뒤 닫힘) / 상 10쌍(첫 카드는 1초만 보이고 닫힘 → 기억해서 짝 찾기)
크기(2026-10-31): 한 화면에 동물이 둘 이상이면(하 퀴즈 2장·정리하기·상 학습 카드·같은 동물 찾기) 실제 크기 5단계(008과 같은 SZ·BB)로 카드 안 그림 크기를 다르게.
  가장 큰 동물이 1, 가장 작아도 0.3. 땅 동물은 발이 아래에 닿게, 하늘·물 동물은 가운데. 혼자 나오는 화면은 그대로 크게.
오늘의 동물: 사는 곳·먹이(고기·풀·이것저것)가 고루 섞이게 앱이 고름(🔀로 바꿈), 수업을 마치면 다음엔 새로 고름. 정리하기에서 서로 가려낼 수 있는 동물끼리만.
