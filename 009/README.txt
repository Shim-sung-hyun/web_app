수준(설정 ②) — 모두 학습 → 퀴즈 → 정리하기 → 같은 동물 찾기
- 하 · 다섯 고개: 오늘의 동물 4마리. 학습(이름 → 고개 다섯) → 퀴즈(동물마다 고개 다섯 번, 고개 하나에 카드 2장: 그 동물 + 그 고개에 확실히 맞지 않는 동물, 매번 다른 동물)
- 중 · 열 고개: 5마리. 학습 → 고개 열 개(*표 단서). 첫 고개에 사는 곳 배경, 고개마다 동물 그림자가 아래부터 차오름(끝 고개에 다 참) → 학생이 이름을 말하면(기기 음성 인식) 동물이 나타남.
  말이 어렵거나 기기가 못 알아들으면 학생 화면 왼쪽 아래 "🗣 알았어요" → 선생님이 들은 이름을 넣음. 앱이 말하는 동안에는 듣지 않음.
- 상 · 스무고개: 10마리. 학습(10마리 카드를 눌러 특징을 글과 함께) → 고개 스무 개. 처음 서식지 배경만, 고개는 말과 글로만(그림 단서 없음, 2026-10-27) → 기기 키보드로 이름을 써서 맞히면 동물이 나타남.
  (자료의 #p 부위·#f 먹이 표시는 지금 쓰지 않음 — 다시 그림 단서를 쓰게 되면 씀)
- 중·상 고개는 말이 끝나고 7초·9초 뒤 저절로 다음(쓰는 중·말하는 중이면 기다림). '패스'를 누르면 기다리지 않고 바로 다음 고개(마지막이면 정답). 다 들어도 못 맞히면 12초 뒤 정답을 보여 줌(도움). 틀린 답에는 반응 없음.
- 하·중은 동물 하나가 한 묶음(2026-10-26 선생님 의견): 특징 학습 → 고개(하 다섯·중 열) → 특징 정리(그 동물과 특징을 한 화면에, 한 번 읽어 줌) → 정지.
  단추 "○○ 한 번 더"(특징 학습부터 고개까지 다시) / "다음 동물"(마지막이면 정리하기로). 저절로 넘어가지 않음. 관리 메뉴 단계 이름은 '동물 하나씩'
- 같은 동물 찾기(놀이, 기록 안 함): 하 2쌍(첫 카드 열린 채, 틀리면 둘 다 닫힘) / 중 5쌍(틀리면 1초 뒤 닫힘) / 상 10쌍(첫 카드는 1초만 보이고 닫힘 → 기억해서 짝 찾기)
오늘의 동물: 사는 곳·먹이(고기·풀·이것저것)가 고루 섞이게 앱이 고름(🔀로 바꿈), 수업을 마치면 다음엔 새로 고름. 정리하기에서 서로 가려낼 수 있는 동물끼리만.
관리 메뉴 위: 학습·퀴즈·정리하기·같은 동물 찾기 / 아래: 다시 하기·기록·🖨 활동지(A4 2쪽: 고개 읽고 이름 쓰기 + 오려 붙일 그림)·바꾼 설정으로 이어서

자료 규칙(무오류)
- AD 구조 단서(하 퀴즈·정리하기): 사는 곳|다리|겉|움직임(할 수 있는 것 모두)|생김새|그럴 수도 있는 생김새|먹이|소리. ?는 고개로도, 보기로도 쓰지 않음.
  보기 동물은 사실도 다르고 그림에서 보기에도 확실히 달라야 함(2026-10-26: 나비는 그림에 다리가 안 보여 '다리가 없어요'의 보기가 되던 것 고침 —
  비슷해 보이는 생김새는 '그럴 수도'에, 털↔깃털·땅 위↔땅속은 서로 보기로 내지 않음, 먹이는 함께 먹는 것까지 적음).
- RID 스무고개: 동물마다 20개, *표 10개가 중. 넓은 것 → 좁은 것, 끝은 이름 글자 수·첫 글자. #h 배경 · #p:부위 · #f:먹이그림
- PARTS 부위 자리: 512칸 그림 기준(e 타원, r 네모). 2026-10-26 그림을 보고 잡음
