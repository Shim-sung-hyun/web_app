차름 사진 다리

내 앱에서 휴대폰 사진 받기

연수에서 만든 웹앱을 전자칠판·태블릿에 띄워 놓고, 휴대폰으로 찍은 사진을 QR 하나로 불러옵니다. 서버를 따로 마련하지 않아도 됩니다. 차름(charum.org) 서버가 다리가 되어 줍니다.

① 내 앱“휴대폰에서 받기” 단추 → QR과 번호
→
② 휴대폰QR을 찍고 사진을 골라 보내기 (여러 장도)
→
③ 내 앱사진이 한 장씩 들어옴 → 화면에 쓰기

사진은 휴대폰에서 줄이고(긴 쪽 1600px, 위치 정보가 빠짐) 잠가서 보냅니다. 가운데 서버는 사진을 열어 볼 수 없고, 앱이 받는 순간 지워집니다.

1먼저 써 보기

앱을 만들기 전에, 다리가 어떻게 움직이는지 직접 해 봅니다.

예시 앱 열기 (우리 반 사진 카드)받기 페이지 열기

받기 페이지는 앱 없이 휴대폰 사진을 큰 화면에 띄우거나, 내려받아 PPT·한글·학습지에 넣을 때 씁니다(“복사” 단추로 바로 붙여넣기도 됩니다).

2연수 코드 받기

연수 강사에게 연수 코드(예: 2026-11-seoul)를 받습니다. 코드는 연수마다 켜고 끄는 열쇠 같은 것으로, 코드가 켜져 있는 동안 다리를 쓸 수 있습니다. 비밀번호는 아니니 앱 안에 그대로 써도 됩니다. 코드는 연수 기간 동안 켜져 있고, 그 뒤에도 쓰고 싶으면 차름 게시판 댓글로 알려 주세요.

3Claude에게 부탁하기 (가장 쉬운 길)

앱을 Claude와 함께 만들었다면, 아래 글을 복사해 Claude에게 붙여 넣고 밑줄 칸에 연수 코드만 바꿉니다. 사진을 어디에 쓸지(예: “받은 사진을 퍼즐 그림으로”)를 한 줄 덧붙이면 더 좋습니다.

내 웹앱에 "휴대폰에서 사진 받기" 기능을 넣어 줘. 차름 사진 다리를 써. - </body> 바로 앞에 이 한 줄을 넣어: <script src="https://shim-sung-hyun.github.io/web_app/relay/charum-relay.js"></script> - 사진이 필요한 곳에 "📱 휴대폰에서 받기" 단추를 만들고, 누르면 이렇게 불러: CharumRelay.receive({ code: '연수코드', onPhoto: function (blob, info) { … } }) - blob은 JPEG 사진이야. 화면에 보이려면 URL.createObjectURL(blob)을 img.src에 넣어. 새로 고쳐도 남기려면 CharumRelay.toDataURL(blob)로 바꿔 IndexedDB에 저장해. - 한 장만 필요하면 CharumRelay.pick({ code: '연수코드' }).then(function (blob) { if (blob) { … } }) 을 써. - QR·번호가 나오는 받기 창은 모듈이 띄우니 따로 만들지 마. 받은 사진을 다른 서버로 보내지 마. - 단추와 받은 사진을 보여 주는 화면은 내 앱의 색·글꼴·꾸밈에 맞춰 만들어. 받기 창도 color에 내 앱의 주 색을 넣어 맞춰(예: color: '#2E7D5B'). 받기 창 글꼴은 내 앱 글꼴을 따라가. - 연수 코드: ________

4직접 넣기 (코드를 아는 선생님)

앱 HTML의 </body> 바로 앞에 두 덩어리를 넣으면 끝입니다.

<button type="button" id="phone">📱 휴대폰에서 받기</button>
<img id="pic" alt="" style="max-width:100%">

<script src="https://shim-sung-hyun.github.io/web_app/relay/charum-relay.js"></script>
<script>
  document.getElementById('phone').onclick = function () {
    CharumRelay.receive({
      code: '연수코드',                    // ← 받은 연수 코드
      onPhoto: function (blob, info) {      // 사진이 올 때마다(여러 장이면 여러 번)
        document.getElementById('pic').src = URL.createObjectURL(blob);
      }
    });
  };
</script>
쓰는 법하는 일
CharumRelay.receive({...})받기 창(QR·번호 6자리)을 띄웁니다. 한 번 찍으면 여러 장을 차례로 받습니다(번호 하나에 30장까지). 사진이 올 때마다 onPhoto(blob, info), 창을 닫을 때 onDone(받은 장 수).
many: false한 장만 받고 창이 저절로 닫힙니다.
CharumRelay.pick({code})한 장을 받아 돌려줍니다(then(blob)). 창을 그냥 닫으면 null.
CharumRelay.toDataURL(blob)사진을 글자(data URL)로 바꿉니다. 저장하거나 캔버스에 그릴 때.
info{n: 몇 번째, width, height, name}
title, color(선택) 받기 창의 제목과 단추·번호 색. 내 앱의 주 색을 넣으면 앱과 어울립니다. 예: color:'#17766F'. 받기 창의 글꼴은 내 앱 글꼴을 그대로 따라갑니다.

5휴대폰에서는

휴대폰 카메라로 QR을 찍으면 charum.org/study/send.html이 번호가 들어간 채로 열립니다. 사진 찍기 또는 앨범에서 고르기(여러 장) → 보내기. 더 보낼 것이 있으면 더 보내기, 끝나면 다 보냈습니다를 누르면 큰 화면의 받기 창이 닫힙니다.

잘 나온 사진은 나눠 주세요. 사진을 고르면 휴대폰 화면에 “이 사진을 나눠 주실래요? (선택)”이 나옵니다. 나눌 사진을 누르고 무엇을 찍었는지 알려 주면 보내기와 함께 차름 사진 모음에 기증됩니다. 제작자가 살펴본 뒤 올리면, 다른 학교 선생님과 학생들도 낱말·도형·퍼즐 공부에 함께 씁니다. 사람·얼굴·이름·번호판·학교 이름이 보이는 사진은 기증할 수 없습니다. 기증은 고른 사진만, 고를 때만 갑니다. 사진 모음은 출처 표시·비영리(CC BY-NC 4.0)로 누구나 함께 씁니다.

6잘 안 될 때

받기 창의 말이렇게 해 보세요
연수 코드가 맞지 않아요앱에 넣은 코드의 글자를 확인합니다(영문 소문자·숫자·-).
코드가 꺼져 있거나 기간이 끝났어요연수 강사(차름 제작자)에게 알립니다.
https 주소에서만 받을 수 있어요GitHub Pages(https://…github.io)처럼 https 주소로 엽니다. 컴퓨터에 저장한 파일을 바로 열어도 됩니다. http:// 주소나 학교 내부망 주소(http://192.168…)에서는 잠그는 기능이 막혀 있습니다.
중계 서버에 연결할 수 없어요인터넷 연결을 확인합니다. 학교 방화벽이 charum.org를 막는지 정보 담당 선생님께 물어봅니다.
시간이 지났어요번호는 첫 사진까지 3분, 사진이 오면 마지막 사진 뒤 10분 동안 열려 있습니다. “새 번호 받기”를 누릅니다.
휴대폰: 번호가 없거나 시간이 지났어요큰 화면에서 새 번호(QR)를 받고 다시 찍습니다.
이번 달 사용량이 다 찼어요차름 서버의 한 달 전송량을 다 썼습니다. 다음 달 1일에 다시 열립니다.

7꼭 지켜 주세요

학생 얼굴·이름이 나오지 않게 찍어 주세요. 사진은 잠겨서 지나가지만, 앱 안에서 어떻게 보이고 저장되는지는 그 앱을 만든 선생님의 몫입니다.

받은 사진을 다른 서버로 보내는 기능을 덧붙이려면 학교의 개인정보 규정을 먼저 확인해 주세요.

다리는 여러 선생님이 함께 쓰는 차름 서버입니다. 사진을 크게 많이 보내는 용도(영상, 수백 장 백업)로는 쓰지 말아 주세요. 한 장은 보통 0.3~0.6MB입니다.
