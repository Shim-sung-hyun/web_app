Azure 음성 키 받는 법

앱 목소리 묶음 azure-sunhi-0.92(선희 목소리)을 만들 때 씁니다. 키는 목소리 만들기 화면에 넣습니다.

  1. Azure 무료 계정 만들기 (이미 있으면 Azure 포털) — 카드 확인이 있지만 무료(F0)로 쓰면 요금이 나가지 않습니다.
  2. Speech 리소스 만들기
    리소스 그룹은 새로 만들기로 charum, 지역은 Korea Central, 이름은 아무거나, 가격 책정 계층은 Free F0 → 검토 + 만들기 → 만들기.
  3. 다 만들어지면 리소스로 이동 → 왼쪽 키 및 엔드포인트에서 키 1과 지역(koreacentral)을 복사합니다.
  4. 목소리 만들기 화면에서 서비스 Azure Speech를 고르고 키와 지역을 넣습니다.

무료(F0)는 1분에 20문장까지라 목소리 만들기가 문장 사이에 3초씩 쉽니다. 목소리 미리 듣기: Speech Studio 목소리 모음

키는 비밀번호와 같습니다. 남에게 보내거나 화면을 찍어 올리지 마세요. 손으로 옮겨 적지 말고 복사 단추로 복사합니다. 학교·교육청 계정은 막혀 있는 일이 많아 개인 계정을 씁니다.
