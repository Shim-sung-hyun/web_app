사진 속 도형 찾기 사용 설명서

전자칠판·태블릿용 웹앱 · 설치 없이 바로 실행

무엇을 하나요

학생이 고른 사진에서 Gemini(AI)가 원·삼각형·사각형을 찾아 줍니다. 학생은 사진 속 물체로 도형의 이름을 배우고, 붓으로 칠하고, 직접 찾아봅니다. 전자칠판이나 태블릿의 브라우저(크롬·사파리)에서 이 글 위의 ▶ 앱 바로 실행 버튼만 누르면 됩니다. 설치는 필요 없습니다.

처음 한 번 준비

  1. 앱 열기: 이 글 위의 ▶ 앱 바로 실행 버튼을 누릅니다. 새 탭에서 앱이 열립니다.
  2. Gemini 키 (꼭 필요): aistudio.google.com/apikey에서 Create API key를 누르고, 키를 복사해 첫 화면에 붙여 넣은 뒤 키 확인을 누릅니다. 무료입니다.
  3. 목소리 (고르기)
    • Google 음성: 자연스럽고 빠릅니다. console.cloud.google.com에서 Cloud Text-to-Speech API를 사용 설정하고 API 키를 만들어 넣습니다. 결제 카드 등록이 필요하지만 매달 100만 자까지 무료입니다.
    • 기기 목소리: 키 없이 바로 나오지만 기계 소리입니다.
    • 목소리 들어 보기로 미리 확인하세요.
  4. 키 저장: "이 기기에 키 저장"에 체크하면 다음부터 다시 넣지 않아도 됩니다. 여러 사람이 쓰는 컴퓨터라면 끄세요.

키 없이 둘러보려면 예시 사진으로 해 보기를 누르세요.

수업 정하기

학생 수준에 맞는 단계를 고릅니다. 용어는 초등 교과서에 처음 나오는 표현을 씁니다.

단계 배우는 것 학생이 하는 일
1단계 · 도형 이름동그라미·세모·네모이름 듣기, 칠하기, 찾기
2단계 · 변과 꼭짓점원·삼각형·사각형, 변, 꼭짓점변과 꼭짓점을 눌러서 세기
3단계 · 각각, 직각각을 눌러서 세기, 직각 찾기

그 밖의 설정: 도형 하나를 보여 주는 시간(4·6·8초), 붓으로 칠하기 켬/끔, 틀렸을 때(바로 정답 보여주기 / 한 번 더 기회).

수업 흐름

시작을 누른 뒤에는 학생이 할 일을 끝내면 저절로 다음으로 넘어갑니다. 학생 화면에는 메뉴가 없습니다. 아래 그림은 예시 사진으로 1단계를 해 본 화면입니다.

1사진 고르기

교사가 수업할 사진을 고릅니다. 사진을 고르는 순간 Gemini가 사진 속 도형을 찾기 시작합니다.

2붓 고르기

학생이 칠할 붓 색을 고릅니다. 한 번에 3색씩 보이고, "다음 색"을 누르면 다른 색이 나옵니다(모두 12색). 학생이 고르는 동안 Gemini가 사진을 분석합니다.

▲ "어떤 붓으로 칠할까요?" — 색을 누르면 "노랑 붓."처럼 색 이름을 말해 줍니다.

3사진을 보아요

사진이 크게 나옵니다. 학생이 사진을 누르면 사진이 옅어지고, 그 위에 찾은 도형이 선으로 그려집니다.

▲ "사진에 도형이 있어요" — 감은 동그라미로, 그림·스피커·휴대폰·책은 네모로 그려졌습니다.

4배우기

도형이 하나씩 사진에서 빠져나와 오른쪽에 이름과 함께 놓입니다. "감은 동그라미 모양이에요"처럼 사진 속 물체와 도형 이름을 이어 줍니다.

▲ 동그라미(감)를 배운 뒤, 네모(그림·스피커·휴대폰)의 이름을 알려 주는 모습입니다. 앞에서 배운 동그라미는 위로 작게 올라갑니다.

5붓으로 칠하기

학생이 같은 모양의 도형을 모두 칠합니다. 다 칠하면 칠한 자리에 진짜 사진이 선명하게 드러나고, 오른쪽에도 그 모양대로 사진이 보입니다. 2·3단계에서는 이어서 변·꼭짓점·각을 눌러서 셉니다.

▲ 감 2개를 다 칠한 모습 — "꼼꼼하게 칠했어요. 감은 동그라미 모양이에요."

6찾기

"동그라미 2개를 찾아 눌러요"처럼, 사진에서 같은 도형을 모두 찾아 누릅니다. 맞히면 그 물체가 선명해지고 크게 보여 줍니다. 찾은 물체는 다음 문제에서도 밝게 남습니다.

▲ 감 하나를 찾은 모습 — 위쪽 동그라미 표시 2개 중 1개가 채워졌습니다.

7끝

사진이 찾은 도형을 강조한 만화 그림으로 바뀌어 나옵니다. 학생 화면에는 그림과 찾은 도형 이름만 보입니다.

교사 모드

화면 오른쪽 아래의 작은 파란 유리알 버튼(charum)을 3초 동안 누르면 켜지고(심), 한 번 더 3초 누르면 꺼집니다.

  • 위쪽 메뉴: 사진 · 배우기 · 찾기 · 끝 중 원하는 단계로 바로 갑니다. 소리 켜기/끄기, 설정도 여기에 있습니다.
  • 아래쪽 메뉴: 다시 듣기, 다음.
  • 끝 화면: 교사용 기록(과제별 바로 맞힘/도움 받아 맞힘), 같은 사진 한 번 더, 다른 사진으로, 출력(색칠용). 출력은 색을 빼고 선만 남긴 그림을 A4 한 장에 인쇄합니다.

기록은 화면을 닫으면 사라집니다. 필요하면 화면을 캡처해 두세요.

좋은 사진과 주의할 점

  • 물체가 화면 안에 통째로 들어오게 찍습니다. 가장자리에 잘린 물체는 도형으로 쓰지 않습니다.
  • 3단계(각)를 할 때는 책·액자·휴대폰 같은 직각 물체를 넣어 찍으면 좋습니다.
  • 학생 얼굴이나 이름이 보이는 사진은 피하세요. 사진은 분석을 위해 Google Gemini로 보내집니다.
  • 사진에 따라 AI가 도형을 조금 어긋나게 잡을 수 있습니다. 수업 전에 한 번 해 보세요.
  • API 키는 개인 것입니다. 다른 분에게는 이 글 주소만 알려 드리고, 키는 각자 만들어 쓰도록 안내해 주세요.
