학생 얼굴이나 이름이 나오지 않게 찍어 주세요. 물건이 화면 안에 통째로 들어오면 도형을 잘 찾아요.

  • 여러 차름 앱(도형 찾기·내 그림 퍼즐 등)에서 수업 자료로 써요.
  • 사람·얼굴·이름·전화번호·차 번호판·학교 이름이 보이지 않는 사진만 보내 주세요.
  • 제작자가 한 번 더 살펴본 뒤 올려요. 빼고 싶으면 차름 게시판에 댓글로 알려 주세요.

키가 없나요? 키 받는 법 (1~2분, 결제 없음) ① Google AI Studio 열기 →
  1. 구글 계정으로 로그인해요. 처음이면 약관에 동의하고 계속.
  2. API 키 만들기(Create API key)를 눌러요. 프로젝트는 새 프로젝트로 만들어요.
  3. AIza로 시작하는 키 옆의 복사 단추를 눌러요.
