AI 키·할당량 구조 (2026-11-19 선생님 정함, 오늘 작동 확인)
- 화면 조절판의 "API 자격 증명" 칸에서 ① Cloudflare Account ID ② Cloudflare API Token ③ Gemini API Key를 받는다.
  키는 localStorage/cookie에 넣지 않고 **페이지가 열려 있는 동안 메모리에만** 둔다(pagehide에서 지움).
- Gemini 키가 있을 때
  1. Gemini 이미지 생성(gemini-3.1-flash-image)으로 먼저 그려 본다.
  2. 한도·오류로 막히면 사진 해석 모델을 순서대로 시도한다:
     GEMINI_TEXT_MODELS = [gemma-4-26b-a4b-it(1순위), gemma-4-31b-it, gemini-3.1-flash-lite-preview, gemini-3.5-flash-lite, gemini-flash-lite-latest].
     해석글이 위 프롬프트에 붙고, 최종 그림은 Cloudflare AI가 만든다.
  3. **해석 모델이 다 막히면 useCloudflareVision:true를 보내 Cloudflare 비전이 사진을 해석**한 뒤 그림을 만든다(2026-11-19 보완).
- Gemini 키가 없을 때: useCloudflareVision:true로 워커에 보내 Cloudflare가 해석 → Cloudflare가 변환.
- 개인 Cloudflare 계정(ID+토큰 모두 입력)이 있으면 그 계정의 Workers AI 할당량으로 해석·변환(제한 없음).
- 계정이 없으면 개발자 AI 바인딩. **정식: 기기당 하루 3회 / 지금(테스트 중): 해제** (2026-11-21 선생님 정함).
  웹앱이 localStorage `webapp.deviceId`에 만든 익명 번호를 요청마다 `deviceId`로 보내고, 워커는 그 해시로 센다
  (번호가 없을 때만 IP 해시로 대신). 이름·IP 원본은 저장하지 않고 KV 기록은 3일 뒤 지워짐.
  횟수는 **그림이 실제로 만들어진 뒤에만** 센다(실패하면 안 깎임). 전체 합계 상한 cartoonAll 40장/일(무료 뉴런 보호).
  사진 분석(/analyze·/gemini 중계)은 기기당 하루 10회. 9b는 워커 변수 USE_9B=1일 때만.
  **테스트 중 해제 = 워커 변수 LIMIT_OFF=1**(대시보드 → 설정 → 변수). 정식 발행 때 LIMIT_OFF를 지우면 바로 기기당 3회.
- ③ 필터+AI: 윤곽 이미지(guide)를 워커가 input_image_1로 FLUX에 넘겨 실제로 반영한다.
  원래 워커는 guide를 받아도 버렸고, 012/charum-ai-worker.js에서 고쳤다(응답의 usedGuide로 확인).
  FLUX 참조 이미지는 512px 미만이라 사진·윤곽 모두 500px로 보낸다(기본 계정·개인 계정 같음, 2026-11-21).

필터 손질 (2026-11-21, 대상을 더 잘 살리기)
- 윤곽판(AI가 따라 그리는 그림)은 점·별·큰 원 없이 '선 + 평평한 색면'만. 선은 최소 1단계, 얼굴 이목구비 선은 한 단계 더 굵게.
  점은 AI에게 무늬로 잘못 읽혀서 뺐다. 그래서 점 크기·점 많이·레이어 점 칸은 AI 그림을 지우지 않는다(하루 횟수 아끼기) —
  AI를 못 쓸 때의 필터 그림에만 쓰인다. AI 그림을 지우는 설정은 색 조합·선 굵기·디테일·대상·AI에게 알림뿐.
- '인쇄 느낌'(선 1~2px 어긋남 + 종이 색)은 없앴다. AI 그림에는 안 들어가고 윤곽판에 잡음만 넣었기 때문.
- 대상이 '사물'이면 피부·얼굴 판정을 끈다(살구색 나무·종이를 얼굴로 보던 문제).
- 주인공 상자: '사진 보고 자동 설정'이 주인공 자리(box, 0~1 비율)도 받는다. 상자 밖 배경은 잔선을 덜고(문턱 1.35배) 배경 점을 넣되
  상자 쪽으로 갈수록 점이 작아져 사라짐(네모 경계가 안 보이게). 사람은 상자 밖 살구색을 얼굴로 보지 않음.
  사물인데 상자가 없으면 가운데(20~80%, 15~85%)를 주인공으로 본다.
- 별은 주인공 상자를, 큰 원은 얼굴(사물이면 상자)을 피한다. 자리는 0~1 비율로 계산해 AI 그림 비율이 달라도 맞음.
  큰 원 삼각형은 안쪽 15곳을 살펴 주인공에 닿으면 건너뜀.
- 피부색 판정 범위를 조금 넓힘(어두운 피부·노란 조명). 사람 사진으로는 아직 시험 못 함 → 다음에 확인.
