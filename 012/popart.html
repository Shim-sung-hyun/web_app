얼굴이 크게 나온 사진이 좋아요
Gemini 키가 없어도 괜찮습니다. Cloudflare AI가 사진 분석과 그림 생성을 모두 처리합니다. Cloudflare 정보를 비워 두면 기본 제공 계정으로 하루 3회 사용할 수 있습니다. Gemini 키만 입력한 경우에도 Gemini가 막히면 기본 제공 계정(하루 3회)으로 전환됩니다. 기본 제공 계정 · 하루 3회
API 설명 및 키 발급 안내
Cloudflare AI (필수 입력은 아닙니다)

본인 계정으로 사용하려면 Account ID와 API Token을 모두 입력하세요. 두 항목을 비워 두면 기본 제공 계정으로 하루 3회 이용합니다. Gemini 키가 없으면 Cloudflare의 비전 AI가 사진을 분석하고, 이미지 AI가 팝아트를 생성합니다.

Cloudflare 토큰 받기 ↗

토큰은 Workers AI 권한을 부여한 API Token을 사용하세요. Global API Key는 입력하지 마세요. 입력값은 브라우저 저장소에 저장하지 않으며 페이지가 열려 있는 동안 메모리에만 보관합니다.

토큰 전달 안내: Gemini 키와 달리 Cloudflare Account ID와 API Token은 변환 요청을 처리하기 위해 이 서비스의 변환 서버(Worker)를 거쳐 Cloudflare로 전달됩니다. 이 서비스 전용으로 Workers AI 권한만 가진 토큰을 새로 만들어 쓰시고, 사용이 끝나면 Cloudflare 대시보드에서 삭제하세요.

Gemini API (선택 사항)

Gemini 키를 입력하면 Gemini가 사진을 분석합니다. 키가 없거나 입력하지 않아도 Cloudflare AI가 분석하므로 필수는 아닙니다.

Google AI Studio에서 API 키 받기 ↗

Gemini 키는 이 브라우저에서 Google로 직접 전송되며 Cloudflare Worker로 보내지지 않습니다.

한도 초과·오류 시 안내: Gemini가 한도 초과나 오류로 막히면 Cloudflare AI로 자동 전환됩니다. 이때 Cloudflare Account ID와 API Token을 입력하지 않았다면 기본 제공 계정(하루 3회)이 사용됩니다. 전환 후에도 본인 계정의 한도만 쓰려면 Cloudflare 정보도 함께 입력하세요.
