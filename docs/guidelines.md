# 프로젝트 지침(요약) — 차름 웹앱 (발달장애 학생용)

> 정리: 2026-11-06. Claude Code는 저장소 맨 위 `CLAUDE.md`를 먼저 읽는다. 이 글은 GitHub `Shim-sung-hyun/web_app` 저장소의 `docs/guidelines.md`와 프로젝트 문서 `claude/프로젝트-지침-요약.md`에 같은 내용으로 있다. 더 자세한 옛 지침은 저장소 `docs/guidelines-full.md`(프로젝트 문서 `claude/프로젝트-지침-개정판.md`와 같은 내용), 사진 검토 절차는 저장소 `media/photos/REVIEW.md`, 각 앱의 세부는 저장소 `NNN/README.txt`에 있다. 고칠 때는 해당 줄을 고쳐 쓰고 날짜를 바꾼 뒤 저장소에 올린다. claude.ai 프로젝트를 쓰는 동안에는 프로젝트 문서도 같게 맞춘다.

**대상**: 특수학교 초등 고학년~고등 발달장애 학생(말하기 약 0.5~2세, 듣기 약 1.5~6세 수준).
**배포**: GitHub Pages `Shim-sung-hyun/web_app` → 학생·교사는 내 도메인 `https://www.charum.org/study/NNN/앱.html`로 열고, 차름 게시판(라이믹스 webapp)에 소개. 시리즈 이름 **차름**('처음'의 우리말).

## 1. 교육 원칙 (모든 결정의 기준)
- **과제 분석**: 작게 쪼개 쉬운 것 → 어려운 것(보기 → 같은 것 찾기 → 표현 → 이해 → 산출 → 정리).
- **무오류 + 촉진 줄이기**: 처음엔 틀릴 틈 없이 돕고 도움은 빨리 걷는다. 오답에 "틀렸어요" 없음(무반응 또는 정답 빛남).
- **자극 통제**: 목표 자극(글자·소리·모양)으로만 풀게. 크기·자리·색·배경·그림 속 글자가 답을 알려 주면 안 됨. **마우스 커서·올림(hover) 반응·눌림 모양**도 같음 — 정답(숨은 대상) 위에서만 손가락이 되거나 빛나면 단서가 되므로 찾는 화면 전체를 같게(008 숨은 동물 찾기, 2026-10-31). 지난 앱도 고칠 때 이런 단서가 있거나 의심되면 함께 검토. 보기 카드는 같은 크기·꼴, 자리는 문제마다 섞음(정리하기는 고정) — 그냥 무작위면 같은 자리가 서너 번 이어져 자리로 맞히므로, 정답이 덜 나온 자리에서 고르고 바로 앞과 같은 자리는 피함(보기 둘이면 두 번까지, 008 `answerSlot`).
- **변별**: 헷갈리는 짝은 한 화면에 함께 내지 않음(`PAIRS`). 정답이 둘인 대상은 낮은 수준에서 뺌.
- **강화**: 맞히면 바로·짧게(약 2초). 보상 놀이는 학습 뒤, 짧게, 진 것 없음, 기록 안 함.
- **유지·일반화**: 묶음 끝 정리, 어려운 것 다음에 다시. 실제 생활 사진·여러 글꼴·교과서 표기.
- **태도**: 아기 같지 않게(연령 적합), 번쩍임·되풀이 움직임·갑작스런 소리 없음, 예측 가능(같은 자리·저절로 다음, "다음" 단추 없음), 한 화면 한 가지·선택지 2~4개·쉬운 말, 벌점·꾸중 없음.
- **교사 우선**: 앱은 제안, 교사가 단추로 정함. 교사 조건은 최소(가입·키 없이 바로 — 단 이것을 문구로 내세우지 않음).
- **기록**: 그 기기에만, 학생끼리 비교 안 함. 예외: 002 S·S+ 초시계 순위표(선생님이 정한 별명·단계·시간만 서버로).
- **보고마다 점검**: 무오류·촉진, 강화 즉시성, 자극 통제, 변별, 유지·일반화, 인지 부하, 감각 과부하, 정서적 안전, 연령 적합성.

## 2. 일하는 방식
- 한국어. 새 세션 첫 응답에서 **신규/수정**을 묻는다(신규는 영역·대상·수준·성격·맥락을 버튼으로).
- "답만"이면 파일을 바꾸지 않음. 이상하면 멈춰서 묻기. 큰 결정은 제안 → 확인 → 실행. 큰 수정은 목록을 먼저 보여 주고 묶어서.
- 어미: 설명서·보고 "~니다", 학생에게 하는 말·짧은 안내 "~요". 앱을 만든 선생님은 **"제작자"**.
- **세션 나누기**: 따로 총괄 세션을 두지 않는다. 이 지침이 총괄이다. 앱 하나는 그 앱을 맡은 세션에서 고치고, 여러 앱에 걸친 일(공통 모듈·공용 자료·서버)은 선생님이 필요할 때 새 세션에 맡긴다. 어느 세션이든 공통 사항은 이 지침을 따르고, 바꾸면 이 지침도 고친다.
- **공통 모듈**(2026-11-02 선생님 결정): 원본은 `common/이름.js` 한 곳, 앱에는 `<script id="이름">` 칸에 `python3 tools/sync-modules.py`로 복사해 넣는다(앱은 그대로 HTML 한 파일 — 공용 파일을 불러 쓰면 하나 잘못돼도 모든 앱이 수업 중에 멈추므로). 앱 안의 모듈 칸은 손으로 고치지 않음. 모듈은 동작만, 얼굴(단추 class·색·글꼴)은 앱이 넘겨 줌. 지금 `common/`에 있는 것: `roster`(학생 명단). 앞으로 옮길 것: 기록 저장·CSV, 멈춘 곳, 말하기(전체 화면 뒤), 진행 표시, 그리고 지금 복사해 쓰는 adminGate·reportLink·endLesson·printFit·holdBubble·keyRelay·photoRelay. 설정 화면을 모듈로 묶기(모양만이라도)는 실익이 적어 하지 않음(2026-11-04 선생님 결정) — 여러 앱의 설정 화면을 한꺼번에 고치느라 일이 거듭 꼬일 때만 다시 제안.
- **무대(stage)**(2026-11-03·04 선생님 결정): 장면은 **배경 · 대상 · 앞가림을 따로 그려 겹친다**(만화영화 셀처럼). 한 장에 다 그려 받지 않는다(대상만 바꾸거나 움직일 수 없음). 대상은 투명 바탕·밑동 반듯, 발밑 옅은 그림자는 프로그램이 그림(모두 같은 방향·진하기), 앞가림 띠(풀·물결)가 대상의 아랫부분을 살짝 덮어 "그 안에 있는" 느낌. 쌓는 차례는 밑동이 아래(가까운 것)일수록 위, 먼 것은 작고 옅게, 요소는 덩어리로 놓고 빈 땅을 남김. 다시 그려야 하면 옛 그림을 고쳐 쓰지 말고 과감히 새로 받는다. 모양도 자연에서처럼: 쌓이는 것(바위·얼음·모래)은 펑퍼짐하게 퍼지며 높아지고 밑동 앞에 풀·작은 돌이 모이게, 벽돌·정육면체처럼 사람이 쌓은 꼴은 피함. 원본은 `common/stagekit.js`·`media/stage/<갈래>/<장소>/`(갈래 nature·town·school·home·public·_common, 차림표 `media/stage/index.json`), 앱은 가져다 씀. 새 무대는 제작자용 `media/stage/install.html`에서 구상·그림 분리·손질·배치·검토·확정 저장/ZIP 내보내기까지 하며, 원본은 최종 확인 전까지 바꾸지 않는다. 무대 전담 세션이 맡고 자세한 것은 `media/stage/README.txt`. 008 숨은 동물 찾기가 처음 씀(2026-11-04 정식판).
- **버릴 자료 상자 `_trash/`**(2026-11-04 선생님 결정): 안 쓰게 된 그림·파일은 바로 지우지 않고 `python3 tools/trash.py 경로 --why "이유"`로 `_trash/<날짜>/`에 옮긴다(원래 자리·이유가 WHY.txt에 남음). 3개월(90일)이 지나면 `python3 tools/trash.py --empty`로 비운다. 세션을 시작할 때 `python3 tools/trash.py`를 한 번 돌려 비울 때가 된 것이 있으면 비우고 커밋. 앱에서 아직 부르는 파일은 넣지 않음(넣은 뒤 `python3 tools/check-files.py`로 확인).
- **같은 뼈대, 다른 얼굴**: 쓰는 법이 같아야 하는 것만 모든 앱이 똑같이(관리 버튼·메뉴, 수업 끝내기, 오류 알리기, 출력, 진행 표시 자리, 터치, 소리 끄기, 제목 체계, 교육 원칙). 바탕 무늬·번호 꼴·제목 옆 표시·보상 모양·화면 구성은 앱마다 다르게. 새 앱이 기존 앱을 그대로 베끼면 "이 앱만의 것"을 제안한다.
- **그림 프롬프트는 통째로**(2026-11-04 선생님 결정): Gemini 등에 건넬 프롬프트는 그림 한 장마다 그대로 복사해 붙이면 끝나는 완성된 글로 만든다. "공통 글 + 그 장의 글"처럼 나눠 두고 선생님이 합쳐 붙이게 하지 않는다(같은 글이 장마다 되풀이돼도 됨). 장마다 번호 · 붙일 본보기 그림 · 받은 그림이 들어갈 자리를 한국어로 적고, 복사할 곳은 ▼~▲로 표시.
- **시각 디자인은 자연스럽게**: AI가 만든 듯 판에 박힌 꼴(보라·남색 그라데이션, 똑같은 둥근 카드와 그림자를 줄줄이, 이모지 아이콘, 반짝이·유리 효과, 해시태그 알약, 뜻 없는 장식)을 피하고 사람이 손으로 만든 듯 자연스럽게. 꾸밈은 그 앱의 소재(그림·주제)에서 가져오고, 꾸밈보다 내용이 먼저. 그림을 올릴 때는 오려 붙인 티(흰 테두리·떠 있는 느낌)가 나지 않게 — 가장자리 정리(`tools/clean-edges.py`), 땅에 닿는 옅은 그림자.
- **제목**: `[차름 교과] 하는 일`(+ 여러 권이면 `N편 · 편 이름`). `<title>`·인쇄 머리·README는 괄호까지. 게시판 글 제목은 괄호 없이 이름(+편). 앱 화면은 작게 "차름 교과"(영역 색) + 크게 이름(Jua, 004는 명조) + 편. 이어지는 다른 앱은 제목에 번호 없이 설명서에서 "전/다음 단계". 파일 이름·주소·저장 칸은 제목이 바뀌어도 그대로.
- **키 문구**: API를 안 쓰는 곳엔 "키 없이·무료·가입 없이" 같은 말을 넣지 않음. 필요한 곳에만 짧게 + "키 받는 법 자세히 보기" 링크.
- **비밀**: API 키·`$REVIEW_TOKEN`·`$ADMIN_TOKEN`·GitHub 토큰은 코드·저장소·대화에 넣지 않음. 파일 이름은 영문.
- **동시 작업**: 올리기 전 `git fetch` + `merge --ff-only`. 같은 앱을 동시에 고치지 않음. 베타 합칠 때 정식판에 그사이 들어간 것을 지키고 바뀐 부분만 옮김. 지침 문서는 쓰기 바로 전에 다시 읽음. claude.ai 프로젝트를 쓰는 동안에는 프로젝트 "지침" 칸에 선생님이 옮겨 붙임.
- 화면을 크게 바꿀 때는 시안을 나란히 비교한 뒤 정식판에(따로 말이 없으면 베타는 만들지 않음, 2026-11-04). 보고는 짧게(바꾼 것 + 점검). 토큰을 아끼려고 확인은 필요한 부분만.

## 3. 화면·조작 공통
- **관리 버튼**: 오른쪽 아래 Aqua 유리알(꺼짐 "charum" / 켜짐 "심"). 학생용 앱은 3초 누름 → 왼쪽 위 점을 눌러야 열림(`adminGate`), 교사 전용(004·005·006)은 한 번.
- **메뉴가 열린 동안**: 학생 화면 반응 없음, 설정은 고르기만 → "바꾼 설정으로 이어서". 관리 메뉴를 열면 전체 화면에서 나옴(004는 바로 반영 예외).
- **메뉴 줄**: 가운데 한 줄, 좁으면 좌우 밀기(`pan-x`), 끝에 "도움말"(단추마다 말풍선).
- **설정 화면**: 맨 위 제목, 번호 카드 ①누구와 ②무엇을 ③오늘 할 것(③은 저절로). 거의 안 바꾸는 것은 "더 정하기"에 접음. 시작 단추는 맨 아래, 넘치면 떠 있게(sticky). 출처 단추는 흰색, 고른 것만 영역 색.
- **영역 색**(학생 화면엔 단추·진행 표시에만, 003은 무채색): 국어 파랑(007 #3D6FB6, 004 #2F5D8A 종이·명조) · 수학 청록(001 #17766F ○△□, 005 #1B6E87 1·0·0, 006 #1E7F6A 십·일, 모눈·카드 왼쪽 띠) · 과학 보라(008 #6A4C9C 점무늬) · 미술 호박(003 #B7791F 물감 방울) · 놀이 회청(002 #4E6A80 퍼즐 선) · 사회 주황 · 음악 분홍(011 #B0487A 오선지 줄). 설명서 머리 색(교과/이름): 국어 #2F5D8A/#1F3F63 · 수학 #17766F/#0F4F4A · 과학 #6A4C9C/#4E3478 · 미술 #B7791F/#7A4E0E · 놀이 #4E6A80/#2F4556 · 음악 #B0487A/#7A2C53.
- **진행 표시**: 학생 화면 맨 위 가운데, 숫자 없이 칸 막대(10칸 넘으면 이어진 막대), 영역 색 계열. 놀이·끝 장면에서는 감춤.
- **오류·의견 알리기**: 선생님 화면 왼쪽 아래 "💬" → `charum.org/webapp/글번호#write`(모듈 `reportLink`). 글 번호 001 59784 · 002 59282 · 003 59262 · 004 59241 · 005 59205 · 006 59200 · 007 59806 · 008 59860.
- **수업 끝내기**: 관리 모드 왼쪽 아래 "⏻", 두 번 눌러야 → 말 멈춤·저장·전체 화면 나감·탭 닫기(안 닫히면 가림 화면). 모듈 `endLesson`.
- **전체 화면·말**: 시작하면 들어감. 말은 전환이 끝난 뒤(`fsBusy` → `afterFull`). 안 보임·소리 끊김으로 멈춘 말은 돌아온 뒤 처음부터 다시(뒤의 할 일도 이어서).
- **출력**: 모듈 `printFit` — 전체 화면이면 먼저 나간 뒤 인쇄, 그림은 그 방향대로 A4에 꽉. 칠한 그림은 50% 이상 칠했을 때만 고를 수 있음. 여러 장이면 이 그림만·고른 그림·모두.
- **전자칠판 터치**: 놀이 대상은 `pointerdown`, 단추·카드는 60px 안에서 떼거나 `pointercancel`이어도 누름, 화면 전환 뒤 따라오는 click 막기, 학생 단추는 아래쪽.
- **표시**: 출처 문구 없음, 다시 시작 때 잔상 없게, 큰 그림은 메뉴 사이 빈 곳에 맞춤, 글은 위아래 가운데, 수·자리 이름은 오른쪽 정렬.
- **소리**: 교사가 끄기, 놀이 소리 3단계. **멈춘 곳**: 학생마다 저장, "이어 하기 / 지우기".

## 4. 학습 흐름·자료

- **여러 자료 이어서**(001 5장·002 10장): 순서대로, 마치면 4~5초 뒤 저절로 다음, 끝에 모아 보기. "학생 혼자"는 펼쳐 놓고 고르기, 마친 것 ✓.

- **장면 속 대상 크기**(008에서 정함, 동물·물건이 장면에 놓이는 모든 앱): 실제 크기를 따름. 혼자 나와도 작은 것은 작게, 큰 것은 크게(크기를 로그 눈금으로 줄여 장면 높이의 약 17~100% — 다람쥐 26%·개 41%·소 58%·코끼리 82%·고래 100%). 여럿이면 가장 큰 것이 그 크기, 나머지는 비율대로 줄이되 알아볼 수 있는 크기(가장 큰 것의 약 30%) 아래로는 안 줄임. 그림마다 여백이 달라 '그려진 부분의 가장 긴 쪽'으로 잼. **카드 하나에 동물(물건) 하나**면 배경이 없을 때 늘 카드에 가득 — 보기 카드가 여러 장 나란히 있어도 카드마다 가득(크기가 답의 단서가 되지 않게). **한 장면·한 카드에 둘 이상이 함께** 있으면 배경이 없어도 실제 크기 비율로(코끼리와 사막여우가 함께면 사막여우를 작게). (2026-10-31 선생님) 숫자 표와 계산식은 `008/animal-home.html`의 REAL·absFrac·relSize.
- **숨기기·찾기 놀이**(008 숨은 동물 찾기에서 정함): 가림 소품은 곳마다 여러 가지(같은 소품이 되풀이되면 소품 찾기가 됨) + 놓을 때마다 뒤집기·폭·밝기를 조금씩. 어려워도 단서(귀·꼬리 끝)는 살짝 보이게. 가려지는 정도는 상자 크기가 아니라 **실제 그림 모양**(칠해진 칸)으로 세고, 어렵기는 보이는 몫이 아니라 **보이는 넓이(장면 대비)**로 맞춤(큰 동물은 몫이 작아도 넓게 보임) — 008 쉬움 0.9~2% · 보통 0.28~0.5% · 어려움 0.08~0.15%, 아주 작은 대상도 17×17점쯤은 보이게, 다른 것이 앞에서 덮지 않게 검사(`tools/hide-check.js`). 도움은 단계로(조금 나옴 → 숨은 곳이 바스락 흔들림 → 더 나옴). 찾으면 대상이 나와 가운데에서 크게 한 번 보여 준 뒤 제자리로.
