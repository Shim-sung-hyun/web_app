소리

목소리 만들기
앱에 아직 없는 문장만 골라 같은 목소리로 만들어 zip으로 받습니다. 발음이 이상하면 쇠똥구리. = 쐬똥구리.처럼 읽는 법을 붙입니다. 앱 골라 열기: 008010 받은 zip을 Claude 세션에 올리고 "목소리 넣어 줘"

그림·프롬프트

프롬프트 복사
Claude가 만든 그림 프롬프트를 한 장씩 단추로 복사합니다. 복사한 장은 노랗게 남습니다(이 브라우저에만). 위 목록에서 글을 고릅니다. 받은 그림은 폴더째 Claude 세션에 올리기

나눔 다른 선생님께 자료 나누기

차름 자료실
그림·배경·소품·사진을 낱말로 찾아 보고, 하나씩 받거나 골라서 zip으로 받습니다. 목소리는 문장으로 찾아 듣고 받습니다. 자료 보내기 탭으로 다른 선생님이 그림·소리를 보낼 수 있고, 기증 사진·자료 화면(관리)의 "새로 온 자료"에서 보고 골라 보낸 뒤 Claude에게 "자료 정리해 줘"라고 하면 자료실에 올라갑니다. 다른 선생님께는 이 주소를 드리면 됩니다. 조건: 비영리·출처 "차름(charum.org)" 표시(CC BY-NC 4.0). ElevenLabs 목소리는 'elevenlabs.io' 표시도
사진 나눔 승인
자료실에 올릴 사진을 크게 보며 고릅니다. 승인한 사진만 나뉩니다. '승인 줄 복사'를 눌러 Claude 대화에 붙이기

사진

사진 모으기
찍어 둔 사진을 여러 장 올리면 Gemini가 사진마다 이름·장소·쓸 앱을 골라 주고, 사람·얼굴·이름·번호가 보이는 사진은 막습니다.
사진 넣기
휴대폰에서 찍은 사진을 저장소로 바로 보냅니다. 처음 한 번만 GitHub 열쇠를 넣습니다(열쇠는 그 휴대폰에만 남음).
기증 사진 확인
선생님들이 기증한 사진을 한곳에서 보고 고릅니다. 얼굴·이름·번호판·학교 이름이 보이면 지웁니다. 고른 것 zip을 Claude 세션에 올리기 (절차는 media/photos/REVIEW.md)

무대 숨은 동물 찾기 등의 장면

무대 설치도구
장소를 한국어로 적으면 AI(제미나이 키)가 소품 목록과 그림 프롬프트를 지어 주고(그림풍·부탁할 AI 고르기), 그림 불러오기 → 소품 손질 → 배경 위에 놓아 보기 → 확정까지 다섯 단계로 새 장면을 만듭니다. '내 저장소 그림 열기'에 GitHub 저장소 주소를 넣으면 그 안의 무대를 손질부터 하거나, 그림만 골라 새 무대를 만들 수 있어요(누구나 — 공개 저장소).
소품 손질
남은 흰 점을 붓으로 직접 손보고 바로 저장합니다. 모든 장면을 고를 수 있습니다.
소품실
모든 무대 소품을 한곳에서 둘러봅니다. 소품을 누르면 '빌려 쓰는 줄'이 복사됩니다. 복사한 줄을 Claude 대화에 붙이기 — 다른 무대 소품을 새로 받지 않고 빌려 씀
배치 고치기
무대가 짠 판에서 어색한 소품을 끌어 옮기거나 크기를 바꾸고, 빼거나 더합니다.
숨기기 시험
장면마다 동물이 어떻게 숨는지 여러 판을 봅니다.
숨기기 평가
숨긴 판을 보고 잘 숨었는지 매깁니다.
무대 보기
장면을 새 판으로 계속 띄워 보며 그림자·먼 것 흐림·자리 보기를 켜고 끕니다.

키·연결

AI 키 확인 (Gemini · Cloudflare)
Gemini 키와 Cloudflare 토큰이 잘 돌아가는지 같은 사진으로 확인합니다. 모델마다 사진 분석이 되는지, 얼마나 빨리 답하는지 보고(무료 모델 비교), 차례로 돌리면 두 회사 모델이 한 빠르기 순위로 나옵니다. 1분이 넘으면 중지합니다. Cloudflare 계정이 사진 분석 모델 동의를 안 했으면 동의 단추가 나와 한 번에 해결됩니다.
