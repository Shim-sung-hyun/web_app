AI 키 확인 Gemini · Cloudflare

Gemini 키·Cloudflare 토큰이 잘 돌아가는지, 각 모델이 사진을 실제로 분석하는지와 얼마나 빨리 답하는지 확인합니다. 1분이 넘으면 중지합니다(분석 못 하는 것과 같음).

1. Gemini 키

Gemini 키 받는 법

키는 이 브라우저 페이지의 메모리에만 사용하며 저장하지 않습니다. 요청은 Google API로 직접 전송됩니다. 네트워크 탭에는 요청 주소가 보일 수 있으므로 개인 기기에서 테스트하세요.

API 키를 입력한 뒤 모델 목록 조회를 누르세요.

Cloudflare 토큰 (012 팝아트 등에서 쓰는 Workers AI)

Cloudflare 토큰 받는 법

브라우저가 Cloudflare를 바로 부를 수 없어서 차름 중간 서버(charum-ai Worker)를 거쳐 내 계정으로 사진을 분석합니다. 토큰은 저장하지 않고, 이 시험에만 씁니다.

Cloudflare · Llama 3.2 Vision
@cf/meta/llama-3.2-11b-vision-instruct (차름 앱이 사진 분석에 쓰는 모델)
내 계정
이 계정은 아직 사진 분석 모델 사용 동의를 하지 않았어요. 차름 앱이 쓰는 사진 분석 모델(Meta Llama 3.2 Vision)은 Meta의 라이선스에 동의해야 쓸 수 있고, 계정마다 처음 한 번만 하면 됩니다. 동의는 이 계정 주인이 하는 약속입니다 — 내용은 모델 안내(라이선스·사용 정책 링크)에서 볼 수 있어요.

2. 시험 사진 (Gemini·Cloudflare 함께)

사진을 선택하세요. 이미지 크기가 크면 테스트가 오래 걸릴 수 있습니다.

3. Gemini 모델

조회 전
모델마다 한 번씩 요청하므로 무료 사용량을 그만큼 씁니다. 검색으로 줄인 뒤 돌리면 좋습니다. Cloudflare 칸이 채워져 있으면 그것도 맨 먼저 함께 잽니다.
모델 목록을 조회하면 여기에 표시됩니다.

Cloudflare는 개인 계정으로 처음 쓸 때 사진 분석 모델 사용 동의가 한 번 필요합니다 — 동의가 안 된 계정이면 Cloudflare 칸에 동의 단추가 나옵니다. 참고: 목록에 표시된 generateContent 지원 여부는 API 메타데이터입니다. 실제 이미지 입력 지원 및 프로젝트별 사용 가능 여부는 사진 분석 테스트 결과로 확인해야 합니다. 무료 사용량, 결제 설정, 지역 및 모델별 제한에 따라 호출이 거부될 수 있습니다.
