Gemini 키 받는 법

선생님이 찍은 사진으로 수업할 때 AI가 사진 속 도형·물체를 찾아 줍니다. 결제(카드) 없이 받습니다. 휴대폰으로도 5분이면 됩니다.

받기

  1. Google AI Studio 열기 (직접 칠 때 aistudio.google.com/apikey)
    "Gemini" 앱이 아니라 크롬·사파리 같은 인터넷 창으로 엽니다.
  2. 평소 쓰는 Gmail로 로그인합니다. 이미 로그인되어 있으면 오른쪽 위 동그라미(프로필)를 눌러 개인 계정인지 확인합니다.
  3. 처음이면 약관에 체크하고 계속을 누릅니다. 안내 창은 닫습니다.
  4. API 키 만들기(Create API key)를 누릅니다. 목록에 키가 이미 있으면 그 키를 써도 됩니다. 프로젝트를 고르라고 하면 새 프로젝트 만들기로 차름처럼 아무 이름이나 넣습니다.

    결제를 연결한 프로젝트(Google 음성 키를 만든 곳 등)는 고르지 마세요. 그 프로젝트의 키는 쓴 만큼 요금이 나갈 수 있습니다.

    휴대폰에서 단추가 안 보이면 가로로 돌리거나 인터넷 창 메뉴에서 데스크톱 사이트를 켭니다.

  5. 키 옆 복사 단추(겹친 네모)를 누릅니다. 키는 AQ.로 시작합니다(예전 키는 AIza, 둘 다 됩니다).

앱에 넣기

  • [차름 수학] 도형 찾기 — 설정 화면 ② 휴대폰에서 받기: QR을 찍은 휴대폰에서 사진을 고른 뒤 Gemini 키 칸에 붙여 넣고 보냅니다(사진과 키가 함께 감). 태블릿·컴퓨터는 이 기기에서 고르기로 사진을 넣으면 키 칸이 나옵니다.
  • [차름 과학] 무엇으로 만들었을까 — 설정 화면 ② 학습 형태 사진 받기 → Gemini 키 칸에 붙여 넣고 저장. 찾은 물체·물질은 선생님 확인 화면에서 고친 뒤에만 수업에 나옵니다.
  • [차름 미술] 팝아트 — 오른쪽 ⚙ 편집 설정의 ③ Gemini API Key(없어도 됨).
  • 사진 모으기(자료실에 사진 보내기) — 보내기 화면의 키 칸(없어도 보낼 수 있음).

같은 기기에서 다른 차름 앱에 넣어 둔 Gemini 키는 저절로 채워집니다.

잘 안 될 때

"키 모양이 맞지 않아요"일부만 복사했거나 앞뒤에 빈칸이 붙었습니다. 복사 단추로 다시 복사하세요.
"잠시 뒤 다시" · 못 찾아요결제 없는 키는 하루 쓸 양이 정해져 있습니다. 잠시 뒤나 다음 날 다시 하세요.
"이 나라에서는 쓸 수 없어요"VPN을 끄고 다시 여세요.
예전 키에 Blocked 표시오래 쓰지 않은 키는 막힐 수 있습니다. 새 키를 만드세요.
키를 잃어버렸어요1번 화면을 다시 열면 목록에서 복사할 수 있습니다.
결제 없는 키로 보낸 사진은 Google이 서비스 개선에 쓸 수 있습니다. 학생 얼굴·이름이 보이는 사진은 넣지 마세요. 사진을 그림으로 바꾸는 끝 그림은 결제를 연결한 키에서만 그려지고, 없으면 사진 그대로 수업합니다.
키는 비밀번호와 같습니다. 남에게 보내거나 화면을 찍어 올리지 마세요. 손으로 옮겨 적지 말고 복사 단추로 복사합니다. 학교·교육청 계정은 막혀 있는 일이 많아 개인 계정을 씁니다.
