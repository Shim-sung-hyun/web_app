# 초등 3-1 · 3. 식물의 생활 (공통교육과정, 2022 개정)

- 학생용 『과학』 60~85쪽(12차시), 『실험관찰』 40~57쪽(부채책 도안 85쪽), 붙임딱지 『과학』 125쪽
- 이 단원에서는: 여러 식물을 관찰해 특징에 따라 분류 → 잎의 생김새로 분류 → 들·산·사막·연못/강 식물이 환경과 관련됨 설명 → 식물 특징을 이용한 생활용품 설계.
- 실험관찰 활동 정리는 [3-식물의-생활-실험관찰.md](3-식물의-생활-실험관찰.md) 참고.
- 길잡이 캐릭터: 땅이, 로보 / 표지: 땅과 물에서 사는 다양한 식물(수련 등).

## 단원 학습 목표
- [지식·이해] 우리 주변에 다양한 식물이 살고 있음을 설명 / 여러 잎의 생김새를 관찰·특징 설명 / 식물의 생김새·생활 방식이 환경과 관련됨 설명 / 생활 속 식물 특징 이용 예 설명.
- [과정·기능] 잎을 관찰해 특징에 따른 분류 기준을 정하고 분류 / 다양한 환경 식물의 생김새·생활 방식 조사 / 식물 특징 이용 생활용품 조사·발표 / 생활용품 설계.
- [가치·태도] 주변 식물에 흥미·호기심 / 객관적으로 설명하려는 태도 / 식물 활용이 생활을 편리하게 함 인식.

## 핵심 개념

### 식물 관찰과 분류
- "식물은 종류에 따라 모습이 서로 다릅니다."
- "우리 주변에는 여러 가지 식물이 살고 있습니다." (학교: 토끼풀, 자주달개비, 회양목, 단풍나무, 무궁화, 장미, 맥문동 등)
- "식물의 잎은 전체적인 모양, 가장자리 모양 등 생김새가 다양합니다." (단풍나무 — 여러 갈래로 갈라짐 / 사철나무 — 둥근 모양 / 벚나무 — 가장자리 톱니 / 강아지풀 — 가장자리 매끈)
- "식물은 잎의 전체적인 모양, 가장자리 모양 등과 같은 특징으로 분류 기준을 정해 분류할 수 있습니다. 식물을 잎의 특징에 따라 분류하면 식물을 구별하고 이해하는 데 도움이 됩니다."
- 분류 기준은 객관적·명확해야: "‘잎의 모양이 예쁜가?’, ‘잎의 크기가 큰가?’ 등은 분류하는 사람에 따라 생각이 다르기 때문에 분류 기준으로 적합하지 않습니다."

### 환경에 사는 식물
- 들·산: "들과 산에서 사는 식물은 대부분 뿌리, 줄기, 잎이 있으며 땅에 뿌리를 내리고 삽니다." (강아지풀, 명아주, 소나무, 신갈나무, 애기똥풀, 밤나무 등)
- 사막: "알로에는 두꺼운 잎에 물을 많이 저장하고 있어서 사막과 같이 물이 적은 환경에서 살 수 있습니다." / "사막에서 사는 식물도 들과 산에 사는 식물처럼 대부분 땅에 뿌리를 내리고 삽니다." (알로에, 기둥선인장, 바오바브나무)
- 연못·강: "부레옥잠은 잎자루에 공기가 들어 있어 물에 떠서 산다." / "연못이나 강처럼 물이 많은 환경에서 사는 식물은 몸의 전체 또는 일부가 물속에 잠겨서 살거나 물에 떠서 산다."
- 수생식물 4분류: 부유식물(부레옥잠·개구리밥·물상추) / 침수식물(검정말·붕어마름·나사말) / 부엽식물(수련·마름·자라풀) / 정수식물(연꽃·부들·갈대).

### 식물의 특징 이용 (생체 모방)
- "식물의 특징을 이용해 집게 차, 고속 열차 등 일상생활에 필요한 여러 가지 것들을 만들어 사용하고 있습니다."
- 예: 기둥선인장 생김새 → 옷걸이 / 연꽃잎(물에 젖지 않음) → 방수 옷 / 도꼬마리 열매(갈고리) → 찍찍이(캐치볼·테이프).
- 확인: "물이 스며들지 않는 옷은 연꽃잎이 물에 (젖지 않는) 특징을 이용해 만들었습니다."

## 실천하는 과학 — 생활용품 설계하기 (10~11차시, 80~81쪽)
- 문제 예: 수영장 물안경이 벗겨져 가라앉음 / 접시를 떨어뜨려 깨짐.
- 설계 예: 부레옥잠(잎자루 공기→뜸) → 물에 뜨는 물안경 / 벚나무 잎(잘 휘어짐) → 말아서 보관하는 접시.
- 과정: 문제 확인 → 생각 모으기 → 활동(그림·사용법·이용 특징 글·이름 짓기) → 함께 나누기(발표·잘된 점·보완할 점) → 되돌아보기.

## 단원 마무리 (12차시, 82~83쪽)
- 확인: 사막 식물(㉡ 대부분 땅에 뿌리, ㉢ 알로에·바오바브나무) / 들·산 O·X(① 여러 종류 O, ② 물속 뿌리 X, ③ 뿌리·줄기·잎 O) / 분류 기준 빈칸(분류 기준) / 부레옥잠 실험(공기 방울이 위로 올라간다).
- 과학 글쓰기: 빈 공간에 짓는 건축물에 식물 특징 활용 제안 편지(예: 바오바브나무 키 큰 줄기 본뜬 기둥, 빗물 모으는 장치).

## 과학으로 통하는 세상 — 극지방 식물 연구 과학자 (84~85쪽)
- "극지방은 남극과 북극 지역을 말합니다." / "극지방은 온도가 낮고 바람이 많이 부는 환경이지만 여러 가지 식물이 살고 있습니다."
- "극지방에서 사는 식물은 다른 지역에서 사는 식물보다 키가 작고 뭉쳐서 삽니다. 또한 땅속 깊이 뿌리를 내리지 않습니다."
- 예: 남극(남극좀새풀·남극구슬이끼·남극개미자리) / 북극(북극이끼장구채·북극황새풀·노랑습지범의귀). 한국 기지: 남극 장보고, 북극 다산.
- "과학자들은 극지방에서 사는 식물의 특징을 이용해 일상생활에 필요한 기술을 개발하고 극지방에서 사는 식물을 보존하는 방법 등을 연구합니다."

## 기본교육과정과 견주어 보기
- 내용이 가장 가까운 것은 **중학교 기본교육과정 ②Ⅲ-2 식물의 생활**(땅·물·사막 식물, 서식 환경)과 **고등 기본교육과정 ②Ⅲ-1 식물의 구조와 기능 / ②Ⅲ-2 동물과 식물의 활용**(생체 모방)이다.
- 공통은 잎의 생김새로 "객관적·명확한" 분류 기준을 따지고, 부유·침수·부엽·정수 4분류와 극지방까지 넓히며, 생활용품 **설계**(문제 확인 → 설계 → 공유 → 보완)까지 간다.
