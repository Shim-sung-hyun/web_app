# 초등 3-1 · 4. 생물의 한살이 — 실험관찰 (공통교육과정)

- 『과학』 90~109쪽 / 『실험관찰』 64~65·87쪽

## 1~3. 배추흰나비 한살이 관찰 (90~95쪽)
- 준비물: 알/애벌레/번데기·어른벌레가 있는 사육 상자, 돋보기, 스마트 기기, 동물·곤충도감, 그림 도구, 실험복·실험용 장갑.
- 공통 과정: 생김새·색깔·움직임·크기 변화를 꾸준히 관찰해 관찰 기록장에 글·그림으로 기록.
- 알(90~91): 사육 상자 준비(먹이 배추·케일 화분), 기를 때 주의·관찰 방법·기록 방법 정리 → 알 모양·색 관찰.
- 애벌레(92~93): 애벌레 특징 관찰(누리망 영상으로 알→애벌레 과정도 관찰 가능).
- 번데기·어른벌레(94~95): 번데기(양쪽 끝이 뾰족, 가운데 볼록) → 등 갈라지고 어른벌레 나옴 → 몸이 머리·가슴·배로 구분, 다리·날개.
- 안전: 알·애벌레·번데기·어른벌레를 손으로 직접 만지지 않기, 돋보기로 장난·해 금지.

## 4. 한살이 모형 만들기 (96~97쪽)
- 준비물: 한살이 모형판(『실험관찰』 87쪽), 색점토, 점토 조각칼.
- 과정: ① 알·애벌레·번데기 색점토로 만들기 ② 모형판 위에 알·애벌레·번데기·어른벌레 그림 배치 ③ 완성 소개 ④ 모형과 실제 한살이 비교.
- 어른벌레 특징: 몸이 머리·가슴·배로 구분, 세 쌍의 다리, 두 쌍의 날개.
- 안전: 점토 조각칼 사용 시 손 조심.

## 5. 씨가 싹 트는 조건 — 물·온도 (98~99쪽)
- 준비물: 콩, 탈지면, 지퍼백 2개, 분무기, (온도) 냉장고·어둠상자 2개, 실험복·장갑.
- 탐구1(물): 한쪽 지퍼백만 물을 충분히(탈지면 젖을 정도), 다른 쪽은 물 없음 → 약 일주일 관찰. 알게 된 점: 씨가 싹 트는 데 (물)이 필요.
- 탐구2(온도): 두 지퍼백 모두 물 주고, 하나는 냉장고 밖·하나는 냉장고 안(각각 어둠상자) → 약 일주일. 알게 된 점: 알맞은 (온도)가 필요.
- 변인 통제: 다르게 한 조건(물/온도)과 같게 한 조건을 생각.
- 안전: 실험용 날콩을 먹지 않기.

## 6. 식물이 자라는 조건 — 물·햇빛 (100~101쪽)
- 준비물: 크기 비슷한 같은 종류 고추 모종, 물뿌리개, 흰색 어둠상자, 실험복·장갑.
- 과정: ① 필요한 조건 ∨표(물·온도·햇빛·흙·화분) ② 모둠별로 물 또는 햇빛 한 가지를 골라 실험 설계(다르게 할 조건/같게 할 조건: 식물 종류·크기) ③ 결과 예상·관찰(약 일주일) ④ 알게 된 점(식물이 자라는 데 물/햇빛이 필요).
- 예(햇빛): 한 화분은 햇빛 비치는 곳, 다른 하나는 어두운 곳(온도 같게), 물 충분히.
- 마무리: 실험 끝난 고추 모종은 선생님 안내에 따라 정리.

## 7. 여러 생물의 한살이 조사·비교 (102~105쪽)
- 준비물: 스마트 기기, 동물·식물도감.
- 동물(102~103): 연어·맹꽁이·사마귀·황새·고양이 중 택1 조사(어미가 알/새끼 낳음 → 새끼 자람 → 다 자라면 다시 알/새끼) → 비슷한 점·다른 점.
- 식물(104~105): 무·해바라기·민들레·감나무 중 택1(씨→싹→잎·줄기→꽃·열매→씨, 한해살이/여러해살이) → 비교.

## 과학 더하기 — 한살이 소개 작품 전시회 (106~107쪽)
- 준비물: 두꺼운 종이, 그림 도구.
- 과정: ① 소개할 생물·작품 계획·전시 계획 쓰기 ② 역할 분담 ③ 병풍책(두꺼운 종이 접기 → 각 면에 한살이 글·그림 → 전시) ④ 다른 모둠 작품 보고 잘된 점.

## 단원 마무리 (108~109쪽)
- 동물이 태어나 자라 자손을 남기는 과정을 동물의 (한살이).
- 배추흰나비: 알(길쭉·줄무늬, ○) / 애벌레(한곳에 붙어 안 움직임, ✕) / 번데기(마디·가운데 볼록, ○) / 어른벌레(몸이 날개·다리 두 부분, ✕ — 머리·가슴·배).
- 여러 생물: 모든 식물·동물의 한살이 과정이 같지 않다(㉢ — 식물은 한해살이·여러해살이).
- 고추 실험: 어둠상자 씌운 모종은 색이 연하고 줄기가 얇게 자람 → 식물이 자라는 데 (햇빛)이 필요.
- 과학 글쓰기: 배추흰나비 한살이를 재미있는 이야기로 꾸며 쓰기.
