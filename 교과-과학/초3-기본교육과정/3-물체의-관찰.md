# 초등 3 · 3. 물체의 관찰 (2022 개정 기본교육과정)

- 교과서 58~83쪽 / 교사용 지도서 「교수·학습의 실제」 100~125쪽 (`(특)초등과학③-3`)
- 단원 구성: **과학아 안녕**(1차시) → **1. 눈으로 관찰해요**(2~4차시) → **2. 손, 귀, 코로 관찰해요**(5~7차시) → **3. 오감으로 관찰해요**(8~9차시) → **과학아 고마워**(10~11차시) → **학습 되돌아보기**(12차시)

## 단원 개관 (지도서 100~103쪽)
- 단원 표지: 다양한 물체가 놓인 학생 방 책상.
- **성취기준**: `[4과학02-01]` 여러 가지 물질로 이루어진 물체를 감각기관을 통해 관찰한다.
- **학습 계열**: 사전(1~2학년군 슬기로운 생활 자연물) → 본(물체의 관찰) → 후속(초3~4 물체의 종류·물체의 용도, 초5~6 물체를 이루는 물질).
- **지도 고려 사항**: 중증 학생은 선호 물체·분명한 차이 자료, 도구 관찰 시 과제 분석·비디오 본보기. 시각중복장애는 실물·반구체물·촉각 자료와 공간 위치(예: 세면대 위 비누) 함께 안내.
- **배경지식 요점**: 물체(모양이 있고 공간을 차지하는 것) vs 물질(물체를 이루는 재료). 관찰은 목적을 갖고 오감 또는 도구로 정보를 수집하는 것.
