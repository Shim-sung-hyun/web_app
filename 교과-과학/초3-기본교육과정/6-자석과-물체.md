# 초등 3 · 6. 자석과 물체 (2022 개정 기본교육과정)

- 교과서 144~169쪽 / 교사용 지도서 「교수·학습의 실제」 180~205쪽 (`(특)초등과학③-6`)
- 단원 구성: **과학아 안녕**(1차시) → **1. 자석의 힘**(2~4차시) → **2. 자석에 붙는 물체와 붙지 않는 물체**(5~7차시) → **3. 재미있는 자석**(8~9차시) → **과학아 고마워**(10차시) → **학습 되돌아보기**(11차시)

## 단원 개관 (지도서 180~183쪽)
- 단원 표지: 교실에서 자석 낚시 교구로 놀이하는 학생들.
- **성취기준**: `[4과학01-01]` 자석과 여러 가지 물체를 가까이했을 때 나타나는 현상을 관찰하고, 자석에 붙는 물체와 붙지 않는 물체를 분류한다.
- **학습 계열**: 사전(1~2학년군 수학 분류 경험하기) → 본(자석과 물체 사이의 힘) → 후속(초3~4 자석과 자석 사이의 힘, 초5~6 전기가 통하는 물질과 통하지 않는 물질).
- **지도 고려 사항**: **극 표시가 없는 자석** 사용(표시 있으면 색 테이프·종이로 가림, 극 개념은 흥미 있는 학생에게만). 작은 자석 삼킴·네오디뮴 자석 손 끼임 안전 주의. 철로 된 것 같지만 **동전·구리·알루미늄 캔은 붙지 않음**(철·니켈·코발트만 붙음) 지도.
- **배경지식 요점**: 재질별 자석(페라이트·알니코·희토류/네오디뮴·고무 자석), 오개념 바로잡기(자석과 철 물체는 **서로** 끌어당김 — 무거운 책상다리·소화기에 매단 자석이 끌려감 / 네오디뮴 자석은 가운데 빼고 거의 전부에 붙음).
