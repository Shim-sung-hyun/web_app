# 초등 3 · 2. 소리의 세계 (2022 개정 기본교육과정)

- 교과서 32~57쪽 / 교사용 지도서 「교수·학습의 실제」 74~99쪽 (`(특)초등과학③-1,2`)
- 단원 구성: **과학아 안녕**(1차시) → **1. 소리를 찾아요**(2~4차시) → **2. 큰 소리, 작은 소리**(5~7차시) → **3. 높은 소리, 낮은 소리**(8~9차시) → **과학아 고마워**(10~11차시) → **학습 되돌아보기**(12차시)

## 단원 개관 (지도서 74~77쪽)
- 단원 표지: 숲속에서 '야호' 외치는 가족.
- **성취기준**: `[4과학01-04]` 소리가 나는 물체는 떨림이 있음을 알고, 생활 주변의 소리를 듣고 큰 소리와 작은 소리, 높은 소리와 낮은 소리로 구분한다.
- **학습 계열**: 사전(1~2학년군 즐거운 생활 신체감각) → 본(소리의 세기와 높낮이) → 후속(중1~3 소리의 발생과 전달).
- **지도 고려 사항**: 시각중복장애(트라이앵글·북·스피커에 손 대기 촉각 체험), 청각중복장애·보청기/인공와우(스마트 앱으로 세기·높낮이 시각 관찰), 소리 민감 학생(범위 제한), 중증(필요한 소리 변별·듣기 좋은/싫은 소리 구분).
- **배경지식 요점**: 소리=물체·공기 진동(파동), 소리의 3요소(세기=진폭, 높낮이=진동수, 맵시=파형).
