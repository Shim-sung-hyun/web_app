# 초등 3 · 7. 물체의 종류 (2022 개정 기본교육과정)

- 교과서 170~195쪽 / 교사용 지도서 「교수·학습의 실제」 206~231쪽 (`(특)초등과학③-7`)
- 단원 구성: **과학아 안녕**(1차시) → **1. 여러 가지 물체**(2~5차시) → **2. 물체의 생김새**(6~7차시) → **3. 물체의 종류**(8~9차시) → **과학아 고마워**(10차시) → **학습 되돌아보기**(11차시)

## 단원 개관 (지도서 206~209쪽)
- 단원 표지: 컵·시계·안경·펜 등 여러 물체가 놓인 탁자.
- **성취기준**: `[4과학02-02]` 생활 주변의 물체를 형태나 종류 등에 따라 분류한다.
- **학습 계열**: 사전(초3~4 물체의 관찰) → 본(물체의 종류) → 후속(초3~4 물체의 쓰임새).
- **지도 고려 사항**: 학교·집으로 생활 영역을 좁혀 물체 제시, '형태' 대신 쉬운 말 **'생김새'** 사용. 중증은 선호 물체·한 가지 특성·분명한 차이 자료, 시각중복장애는 실물·반구체물·촉각 자료와 공간 위치 안내.
