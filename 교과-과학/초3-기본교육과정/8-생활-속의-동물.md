# 초등 3 · 8. 생활 속의 동물 (2022 개정 기본교육과정)

- 교과서 196~221쪽 / 교사용 지도서 「교수·학습의 실제」 232~257쪽 (`(특)초등과학③-8`)
- 단원 구성: **과학아 안녕**(1차시) → **1. 우리 주변의 동물**(2~3차시) → **2. 동물의 생김새와 특징**(4~6차시) → **3. 동물의 움직임과 사는 곳**(7~9차시) → **과학아 고마워**(10차시) → **학습 되돌아보기**(11차시)

## 단원 개관 (지도서 232~235쪽)
- 단원 표지: 산수유 열매 따 먹는 다람쥐.
- **성취기준**: `[4과학03-02]` 여러 가지 동물을 관찰하고 특징을 표현한다.
- **학습 계열**: 사전(1~2학년군 슬기로운 생활·바른생활·즐거운 생활 동식물 관찰/소중히/표현) → 본(생활 속의 동물) → 후속(초5~6 동물의 한살이·동물의 생활).
- **지도 고려 사항**: 생명을 소중히 여기는 마음 기르기, 생김새 관찰 + 몸짓·소리 모방 활동. 의사소통 판(AAC)·시각장애(동물 모형·소리)·청각(교사 시범·보조공학 음량 조절)·지체(단추 스위치 동물 인형 작동).
- **배경지식 요점**: 동물(스스로 양분 못 만들고 움직임) vs 식물, 보호색(나방·애벌레), 두더지·각시붕어·호랑나비·참새 생태 정보.
