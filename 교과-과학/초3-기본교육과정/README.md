# 기본교육과정 과학 3학년 (2022 개정, 3~4학년군)

- 2022 개정 특수교육 기본교육과정 초등학교 3학년 과학(`(특)초등과학③`, 교사용 지도서 2~284쪽) 정리 폴더다.
- 총론 「과학과 교육의 이해」(공통)는 [`../기본교육과정-과학의-이해.md`](../기본교육과정-과학의-이해.md)로 통합했다. 3~4학년군 공통 「교과용 도서의 구성·활용」은 [`0-교과용-도서-구성-활용.md`](0-교과용-도서-구성-활용.md)에 있다(초4와 동일).
- 교과서 5단계 틀: **단원 시작하기** → **과학아 안녕** → **과학 탐구**(중단원 3개, 9단원만 2개) → **과학아 고마워** → **학습 되돌아보기**(스스로 확인하기 포함).
