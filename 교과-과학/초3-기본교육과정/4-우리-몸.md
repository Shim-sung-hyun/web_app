# 초등 3 · 4. 우리 몸 (2022 개정 기본교육과정)

- 교과서 84~111쪽 / 교사용 지도서 「교수·학습의 실제」 126~153쪽 (`(특)초등과학③-4`)
- 단원 구성: **과학아 안녕**(1차시) → **1. 우리 몸의 위치와 움직임**(2~4차시) → **2. 우리 몸의 생김새**(5~7차시) → **3. 우리 몸이 하는 일**(8~10차시) → **과학아 고마워**(10~11차시) → **학습 되돌아보기**(12차시)
  *(참고: 단원 지도 계획상 10~11차시는 `우리 몸이 하는 일을 알아봅시다`(106~107쪽)와 `과학아 고마워: 몸이 아플 때 가야 하는 병원 찾기`(108~109쪽)가 이어져 배치됨)*

## 단원 개관 (지도서 126~129쪽)
- 단원 표지: 의자에 앉아 한 손을 든 남녀 학생들.
- **성취기준**: `[4과학03-01]` 우리 몸 각 부위의 생김새와 움직임을 관찰한다.
- **학습 계열**: 사전(1~2학년군 통합 교과 학교와 나(몸)) → 본(우리 몸) → 후속(중1~3 인간: 감각기관·뼈와 근육·인간의 성장).
- **지도 고려 사항**: 시각중복장애(언어 정보 충분히 제공 + 교사/친구 신체 부위 촉진), 청각 동반(수어·동작 언어), 중증(부위 명칭 말하기·동작 따라 움직이기 재구성).
- **배경지식 요점**: 뇌·신경·근육·소화·배설 연계, 5감각과 피부 감각점(온점·냉점·압점·통점 — 매운맛·떫은맛은 미각이 아닌 통점 촉각).
