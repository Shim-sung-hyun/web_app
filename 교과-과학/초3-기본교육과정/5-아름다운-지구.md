# 초등 3 · 5. 아름다운 지구 (2022 개정 기본교육과정)

- 교과서 112~137쪽 / 교사용 지도서 「교수·학습의 실제」 154~179쪽 (`(특)초등과학③-5`)
- 단원 구성: **과학아 안녕**(1차시) → **1. 산과 들**(2~4차시) → **2. 강과 바다**(5~7차시) → **3. 사막과 밀림**(8~9차시) → **과학아 고마워**(10차시) → **학습 되돌아보기**(11차시)

## 단원 개관 (지도서 154~157쪽)
- 단원 표지: 산·들·강·바다 자연환경 사진.
- **성취기준**: `[4과학04-01]` 생활 주변 자연환경의 다양한 모습을 관찰하고, 지구의 자연환경에 흥미를 갖는다.
- **학습 계열**: 사전(1~2학년군 즐거운 생활 우리를 둘러싼 자연의 아름다움 감상하기) → 본(아름다운 지구) → 후속(초5~6 지층의 모양).
- **지도 고려 사항**: 학교·공장 등 **인문 환경과 혼동하지 않도록** 자연환경 중심 지도. 중증(외부에서 지표면 직접 관찰 / 평면 위 촉각 자료로 지표면 구성 재구성), 시각중복장애(촉각·확대 자료+언어 정보).
