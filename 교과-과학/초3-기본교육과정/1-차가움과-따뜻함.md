# 초등 3 · 1. 차가움과 따뜻함 (2022 개정 기본교육과정)

- 교과서 6~31쪽 / 교사용 지도서 「교수·학습의 실제」 48~73쪽 (`(특)초등과학③-1,2`)
- 단원 구성: **과학아 안녕**(1차시) → **1. 차가운 느낌과 따뜻한 느낌**(2~4차시) → **2. 차가움과 따뜻함 표현하기**(5~6차시) → **3. 차가움과 따뜻함 이용하기**(7~9차시) → **과학아 고마워**(10~11차시) → **학습 되돌아보기**(12차시)

## 단원 개관 (지도서 48~51쪽)
- 단원 표지: 찜질방(얼음방·불가마방, 냉탕·온탕, 차가운/따뜻한 음식).
- **성취기준**: `[4과학01-03]` 물체의 차가운 정도와 따뜻한 정도를 다양하게 표현하고, 차갑거나 뜨거운 물체를 다룰 때 주의할 점을 실천한다.
- **학습 계열**: 사전(1~2학년군 슬기로운 생활 날씨와 계절) → 본(차가운 정도와 따뜻한 정도) → 후속(5~6학년군 온도). **온도·열·단열 개념은 다루지 않음.**
- **지도 고려 사항**: 개인·상황마다 느낌이 다르므로 다양한 반응 허용. 감각 둔감/예민 학생은 김·물방울·수도꼭지/정수기 빨강·파랑 색깔로 추측, 비구어 학생은 표정·AAC·신체 가리키기. 감각 회피 학생은 면장갑·손수건 활용.
- **배경지식 요점**: 온도(℃), 열의 이동, 화상 응급 처치(찬물 20분 이상, 물집 터뜨리지 않음, 장신구 제거, 바셀린·거즈), 동상(동창) 응급 처치.
