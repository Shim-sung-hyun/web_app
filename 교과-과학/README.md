# 교과-과학 — 과학 교과서 정리

차름 앱을 만들 때 참고하려고 과학 교과서와 지도서를 정리해 두는 곳이다.
원문을 그대로 옮기지 않고 차시별로 정리했다. 「꼭 기억해요」·정리·평가 같은 핵심 문장은 원문대로 적었다.

**교육과정 구분**: 폴더 이름에 `기본교육과정`(특수교육)과 `공통교육과정`(일반)을 붙여 나눈다. 지금 들어 있는 것은 모두 **기본교육과정**이다.
