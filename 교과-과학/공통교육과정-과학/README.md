# 2022 개정 과학과 교육과정 — 공통 교육과정 ‘과학’

## 1. 개요
- **목적**: ‘과학적 소양을 갖추고 더불어 살아가는 창의적인 사람’ 육성. 지식·이해, 과정·기능, 가치·태도의 세 차원을 균형 있게 함양.
- **5개 영역**: 운동과 에너지 / 물질 / 생명 / 지구와 우주 / 과학과 사회.
  - 운동과 에너지: 힘·에너지·전기·자기·열·빛·파동.
  - 물질: 물질의 성질·변화·구조.
  - 생명: 생물 구조·에너지·항상성·유전·생태계.
  - 지구와 우주: 고체·유체 지구·천체·지구계.
  - 과학과 사회: 안전·지속가능 사회·진로 (4개 영역 통합).

## 2. 성격 및 목표
- 초1~2 ‘슬기로운 생활’과 연계, 고등 ‘통합과학’ 등으로 연결.
- 목표: 흥미·호기심 → 과학적 탐구 → 핵심 개념 이해 → 과학·기술·사회 상호관계 이해 및 민주 시민으로 참여·실천.
