# 2022 개정 특수교육 기본교육과정 초4 과학 — 교육의 이해

- 출처: 2022 개정 특수교육 기본교육과정 초등학교 4학년 과학(`(특)초등과학④-1,2`) 교사용 지도서 「과학과 교육의 이해」(286~329쪽)

## 1. 교육과정 개요 (290~298쪽)
- **영역 변화(5개 → 4개)**: 2015 개정(5영역)에서 공통 교육과정과 맞춰 **`운동과 에너지`**, **`물질`**, **`생명`**, **`지구`** 4영역으로 재편(‘우리 몸과 동물’+‘식물’ → `생명`, ‘지구와 우주’ → `지구`).
- **핵심 역량**: 과학적 사고력·탐구·문제 해결·의사소통·협동·진로/직업 역량을 **지식·이해 / 과정·기능 / 가치·태도** 세 차원으로 통합.
- **중도·중복장애 학생**: 생태학적 접근으로 일상생활과 밀접한 친숙한 상황에서 기능 중심 과학 문해력을 기르고, 기초 탐구 과정(관찰·분류·측정·예상·추리·의사소통) 중심으로 지도.

## 3. 교과서 구성 틀과 교수·학습·평가 (308~328쪽)

### 교과서 5단계 구성 (309~310쪽)
1. **단원 시작하기** (2쪽): 명사형 생활 용어 단원명 + 흥미 유발 사진 + 핵심 문장 + 중단원(1·2·3) 제목
2. **과학아 안녕** (2쪽): 실생활 소재·디지털 기기(앱 등)로 흥미 유발 (개념 직접 도입 전 단계)
3. **과학 탐구** (약 16쪽): 중단원 3개 구성, 차시별 2~3개 활동(탐구·조사·놀이)
4. **과학아 고마워** (2쪽): 배운 내용을 실생활 문제·만들기에 적용
5. **학습 되돌아보기** (2쪽): 핵심 개념 사진·글 정리 + **스스로 확인하기**

### 과학 수업 모형 7가지 (321~325쪽)
- **순환 학습 모형**: 탐색 → 개념 도입 → 개념 적용
- **경험 학습 모형**: 자유 탐색 → 탐색 결과 발표 → 교사 안내 탐색 → 탐색 결과 정리 (구체적·감각적 경험, 기초 탐구 중심)
- **발견 학습 모형**: 탐색·문제 파악 → 자료 제시·관찰 → 추가 자료 제시·관찰 → 규칙성 발견·개념 정리 → 적용·응용
- **탐구 학습 모형** (가설 검증): 탐색·문제 파악 → 가설 설정 → 실험 설계(변인 통제) → 실험 → 가설 검증 → 적용·새 문제 발견
- **POE 모형**: 예상(Prediction) → 관찰(Observation) → 설명(Explanation, 모순 해결)
- **STS 모형** (과학-기술-사회): 문제 소개 → 탐색 → 설명·해결 방안 제시 → 실행
- **직접 교수 모형**: 설명하기 → 시범 보이기 → 안내된 연습 → 독자적 연습

### 교수·학습 원리 및 평가 요점 (318~328쪽)
- **교수·학습 4원리**: ① 일상 실물·오감 구체적 경험 ② 발산적 발문 및 오개념 예방 ③ 학생 선호 감각 고려(혐오 자극 배제) ④ 다양한 교수법(전달식·발견적·과정적·상호작용적) 병행.
- **평가**: 제한성 확인이 아니라 **성취기준 달성을 위한 지원 요구 확인**에 중점. 구술·선다형 외 관찰·수행·포트폴리오·비언어적 표현(그림·신체)·백워드 설계 활용, 중증 학생은 기초 학업 기술과 세분된 단계적 수행을 직접 관찰 평가.
