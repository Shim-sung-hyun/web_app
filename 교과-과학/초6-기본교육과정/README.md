# 기본교육과정 과학 6학년 (5~6학년군)

- 2022 개정 특수교육 기본교육과정 초등학교 6학년 과학 교사용 지도서(교수·학습의 실제, 8단원) 정리 폴더.
- 공통 「과학과 교육의 이해」는 [`../기본교육과정-과학의-이해.md`](../기본교육과정-과학의-이해.md)로 통합했다.
- 5~6학년군 공통 「교과용 도서의 구성·활용」은 [`0-교과용-도서-구성-활용.md`](0-교과용-도서-구성-활용.md)에 있다(초5와 동일).

## 책 구성
- **단원 안내** — 사진을 보고 배울 내용을 이야기한다.
- **중단원 도입** — 그림과 이야기로 시작한다.
- **기초활동(초록 단추)** — 관찰과 탐색으로 과학 개념을 배운다.
- **주요활동(빨간 단추)** — 기초활동에 이어지는 탐구활동이다.
- **차시 끝** — 「꼭 기억해요」(핵심 내용·용어), 「정리해 볼까요?」(간단한 문항)
- **보충(더 알아볼까요?)** — 기초활동 내용으로 하는 놀이·조작 활동
- **심화** — 주요활동 내용을 실생활에 쓰는 활동
- **단원 마무리** — 되짚어 보기, 생각 키우기
- 차시마다 이야기 주인공: 1·4·5·6단원 지수, 2단원 솔이, 3단원 미소, 7단원 지후, 8단원 나연.
