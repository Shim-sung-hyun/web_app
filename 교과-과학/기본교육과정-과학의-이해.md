# 기본교육과정 과학의 이해 (공통)

- 2022 개정 특수교육 **기본교육과정** 과학(초 3~5학년군·중 1~3·고 1~3)의 **공통 이해** 부분.
- 원래 각 학년군 지도서 앞부분의 「과학과 교육의 이해」이 학년마다 겹쳐서, 공통 내용을 한곳으로 모았다.
- **학년군별 '교과용 도서의 구성과 활용 방안'**은 각 학년 폴더의 `0-교과용-도서-구성-활용.md`에 따로 정리했다(초3~4 / 초5~6 / 중 / 고).
- 이 이해 내용은 「교수·학습의 실제」(단원별 지도) 앞에 공통으로 놓이는 부분이다.

## 1. 과학과의 성격과 목표
- 2022 개정 특수교육 기본 교육과정 과학과는 초 1~중 3(및 고) 장애학생을 대상으로, 공통 교육과정 과학과 내용을 토대로 장애 특성과 교육적 요구를 고려한 생활·기능 중심 맞춤형 교육과정으로 개정.
- 목표: 장애학생이 자연과 일상생활에 호기심·흥미를 갖고 현상을 관찰·이해하며, 이를 생활 문제 해결에 적용·실천하는 **과학적 탐구역량** 함양.
- 내용 영역 4개: **운동과 에너지 / 물질 / 생명 / 지구**. 각 영역은 지식·이해, 과정·기능, 가치·태도의 3차원으로 학년군·영역 간 연계를 체계화.
- 핵심 아이디어: 4개 영역에 걸쳐 총 14개(운동과 에너지 4, 물질 3, 생명 3, 지구 4).
- 성격: 자연현상과 일상생활에 관심·호기심을 갖고 과학 기본 개념과 탐구 능력·태도를 길러 문제를 과학적으로 이해·해결하고, 민주시민으로 참여·실천하는 과학적 소양을 기르는 교과.
- 총괄 목표: 흥미·호기심을 바탕으로 과학적 탐구를 통해 주변 현상을 이해하고, 기초 과학 지식을 습득하며, 참여·협동으로 일상 문제를 해결. 세부 목표 4개(탐구·참여 / 탐구 방법 적용 / 기초 개념 이해 / 과학·기술·사회 상호관계 이해 및 실천).

## 2. 과학과 내용 체계와 성취기준(개요)
- 내용 체계: 영역별 핵심 아이디어 + 내용 요소(지식·이해, 과정·기능, 가치·태도), 학년군별 계속성·위계성 고려.
- 지식·이해는 초 3~4 / 초 5~6 / 중 1~3 / 고 1~3 학년군으로, 과정·기능과 가치·태도는 초등/중고등으로 구분.
- 과정·기능 범주: 관찰 및 문제 확인 / 분류와 측정 / 자료 수집과 분석 및 예상 / 결론 추론 / 의사소통과 협업.
- 가치·태도 범주: 과학 가치와 태도(존중·배려, 관심·호기심, 참여·협력, 위험 인식·대처 등) / 참여와 실천(유용성, 상상력·창의성, 공동체 활동 참여, 안전 생활 실천 등).
- 성취기준: 내용 요소 2~3개를 연계해 2개 이상 범주를 포함하는 형태로 진술. 총 78개(초 3~4 18, 초 5~6 19, 중 1~3 20, 고 1~3 21).
- 신설: 성취기준 **해설**(설정 이유·명료화·교수학습 주안점)과 **적용 시 고려사항**(장애 정도가 심한 학생, 시각·청각·지체중복장애 학생을 위한 재구성·대체 성취기준).

## 3. 과학과의 교수·학습 및 평가
- 교수·학습 방향: 활동·탐구 중심, 실생활 중심 문제 해결, 호기심·흥미 제고. 온·오프라인 연계 탐구, 디지털 도구 활용, 생태전환 교육 강조.
- 장애학생 요구(발달 수준, 생활 연령, 선호, 감각 특성, 학습 동기·습관)와 교수 환경에 근거해 방법 결정. 구체적 실물자료, 직접 교수·시범 활용.
- 수업 방법: 강의법, 질문법, 실험법(시범·과학 실험), 현장 학습(견학·야외 관찰), 역할놀이, 협동학습(직소, STAD, Co-op Co-op, GI), ICT 활용 수업.
- 평가: 지식·이해, 과정·기능, 가치·태도를 균형 있게 평가. 지필 외 관찰·실기·면담·포트폴리오·작업 표본·루브릭 등.
- 영역별: 과학 지식(지필·실험실습·보고서·면담·구술·포트폴리오) / 탐구 능력(결과·과정 중심, 탐구기능 척도) / 가치·태도(면담·구술·포트폴리오·자기·동료 평가) / 수행평가(실험 과정·보고서·포트폴리오).

## 4. 과학과의 구성 요소
- 과학 지식: 사실·개념·원리·법칙·이론·모형. 개념은 학습자가 능동적으로 형성·획득.
- 과학 탐구와 과정·기능: 기초 탐구 기능(관찰·측정·분류·예상·추리·의사소통)과 통합 탐구 기능(문제 인식·가설 설정·변인 통제·자료 해석·결론 도출·일반화·과학적 사고와 컴퓨터 활용·모형 개발과 사용·증거 기반 토론과 논증).
- 과학 가치 및 태도: 과학 가치(심미적 가치·감수성) / 과학 태도(창의성·윤리성·유용성·개방성 등) / 과학 참여와 실천(리더십·지속가능사회 기여·과학문화 향유·안전사회 기여).

## 5. 과학과 교수·학습 모형 적용
- 수업 목표(개념·지식, 탐구, 태도)에 따라 3범주 모형.
  - **탐구 중심**: 경험 학습(오감 관찰·측정·분류, 전조작기 수준 적합), 발견 학습(귀납적으로 규칙성 발견, 초·중·특수교육 대상에 유용).
  - **개념-탐구 중심**: 순환 학습(탐색-용어 도입-개념 적용), POE(예상-관찰-설명, 오개념→과학 개념), 발생 학습(선개념 확인·도전·적용).
  - **태도 중심**: STS(과학-기술-사회 상호관계, 실생활·사회 문제 해결, 의사결정).
- 각 모형의 배경·특징·절차·적용 과제·유의점 제시.

## 6. 과학과 지도 계획
- 각 단원(예: 중학교 무게와 열, 액체와 혼합물, 우리 몸, 날씨와 기후 변화 등)의 차시별 교수-학습 내용·활동, 주요 용어, 지도 유의점, 활용 전자자료 유형을 표로 제시하는 지도 계획 형태.
- 상세 차시별 계획은 교과용 도서 활용 방안과 연계된 단원별 자료로 제공.
