# 고등학교 과학② · Ⅱ. 물질의 변화 (기본교육과정)

- 교과서 58~109쪽 / 교사용 지도서 「교수·학습의 실제」 532~589쪽
- 중단원: 1. 물과 얼음(7차시) · 2. 연소와 소화(13차시: 11차시 + 과학 다지기·더하기 + 생태 감수성·디지털 활용 수업·단원 정리 및 평가)
- 교과서 차시 틀: 도입 문장 → 활동(해 봐요) → **정리** 한 줄 → **평가** 한 문항. 곳곳에 「과학 용어」, 「도움말」, 「주의」·「안전」 상자, 「지구를 위해」. 붙임딱지 쪽수 표시(3·5·9·11).

## 단원 개관 (지도서 532~535쪽)
- 단원 도입 그림: 왼쪽 역고드름(물이 얼어 생기며 녹아 다시 물이 됨 → **물리적 변화**), 오른쪽 산불 진화(불 탄 나무는 원래대로 못 돌림 → **화학적 변화**). 물질의 변화는 물리적 변화와 화학적 변화로 나눌 수 있다.
- 목표: 물과 얼음의 상태 변화, 연소·소화 과정, 화재 발생 시 대응 방법 등 생활 주변에서 쉽게 볼 수 있고 안전한 생활에 필요한 요소를 학습. 소화의 과학적 이론보다 **생활과 연계**, 화재 발생 시 **안전한 행동 요령 숙지**를 우선 과제로 한다.
- 물과 얼음 단원: 얼음↔물 상태 변화 관찰과 실험으로 무게·부피 변화 이해. 중학교에서 다뤘으나 이 단원에서 더 집중. 부피 차이로 나타나는 자연 현상(빙하, 영구 동토, 언 강)을 이해·설명. 장애 정도가 심한 학생은 물과 얼음을 만져 보며 **다감각적으로 경험**.
- 연소와 소화 단원: 물질이 연소할 때 빛·열을 내고 연소 전후 겉모습이 다름을 이해. 소화 조건을 익혀 작은 화재에 대처. 양초 실험 대신 **음식물(고구마·밤) 굽기** 등으로 성취기준 재구성 가능. 시각장애·중복장애 학생은 연소 현상·변화의 **언어적 정보를 세밀히** 제공.
- 학생 수준에 따라 액체 관련 경험부터 시작, 탐구 활동을 변형하거나 성취기준을 재구성하여 적용.

### 핵심 아이디어
- [물과 얼음] 물질은 고유한 특성이 있으며 물질의 상태에 따라 물리적 성질도 다르다.
- [연소와 소화] 물질이 연소할 때 새로운 물질을 만들며, 연소 과정에서 물질의 성질이 달라진다.

### 성취기준
- [12과학02-03] 물이 얼 때, 얼음이 녹을 때의 변화에 따른 무게와 부피를 비교한다.
- [12과학02-04] 물질이 연소하기 전과 후의 상태를 비교한다.
- [12과학02-05] 연소와 소화 조건을 알고, 소화 방법에 따른 화재 안전을 실천한다.

### 단원 목표 (요약)
- 지식·이해: 물과 얼음 관찰·특징 비교 / 상태 변화에 따른 무게·부피 변화 관찰·측정 / 연소 전후 상태 비교 / 연소·소화 조건과 화재 안전 생활화
- 과정·기능: 자연·일상에서 물질 문제 인식 / 물의 상태·변화 예측·추론 / 연소 후 변화 예측·협력 소통 / 연소·소화 조건의 상황 적용
- 가치·태도: 물의 상태 변화·실험에 호기심과 적극 참여 / 탐구의 유용성 이해 / 생활 속 위험에서 안전 생활 실천 / 연소·소화 실험의 즐겁고 적극적 참여
- 과학과 생활: 물의 상태 변화 현상의 생활 적용 / 화재 시 안전 대피 실천 / 연소 조건과 소화 방법 설명 / 학습 내용의 일상 적용

### 연계
- 이미 배운 내용(초등): 물질의 상태(5~6학년군)
- 이미 배운 내용(중등): 물의 모습과 변화
- 이 단원: 1. 물과 얼음(상태 변화, 무게·부피 변화) / 2. 연소와 소화(연소 전후 비교, 연소·소화 조건, 소화 방법·화재 안전)
- 삶(가정 및 생활)과의 연계: 물의 상태 변화·연소·소화를 경험과 실험으로 학습하고, 화재 예방·대처를 실천하는 역량으로 연결.

### 단원 평가 중점
개별 맞춤형 과정 중심 평가. 핵심 개념의 이해·적용뿐 아니라 과학적 태도도 평가.
- 물과 얼음이 상태 변화할 때 무게와 부피 변화를 설명할 수 있는가?
- 물과 얼음의 상태 변화 결과를 생활 주변에서 찾을 수 있는가?
- 연소 현상을 관찰하고 연소 전후를 비교하여 설명할 수 있는가?
- 소화의 조건을 이해하고 촛불을 끄는 방법을 설명할 수 있는가?
- 화재 발생 시 대처 요령을 이해하고 실천할 수 있는가?

## 1. 물과 얼음 (교과서 60~77쪽, 지도서 538~555쪽)
도입(60~61쪽): 북극 빙하와 바다 — "물이 얼음으로, 얼음이 물로 변화할 때 나타나는 현상을 알아볼까요?"
학습 용어: 물, 얼음, 무게, 부피, 조건, 고체 / 실온(약 20 ℃), 영구 동토, 융해, 응고, 기온, 페트리접시.

| 차시 | 쪽 | 제목 | 교과서 활동 | 정리 / 평가 | 지도서 메모 |
|---|---|---|---|---|---|
| 1 | 62~63 | 얼음이 녹을 때 | 손바닥 위 얼음 변화 관찰(주의: 얼음·녹은 물 입에 넣지 않기), 아이스크림 따뜻한 곳, 스마트 기기로 야외 스케이트장 운영 기간·기온, 햇빛·드라이기·손·뜨거운 물에서 녹는 이유 | 온도가 높아지면 얼음이 녹아 물이 된다 / 평가: 아이스크림을 먹다 보면 점점 녹는다(○) | 얼음, 사진·영상, 아이스크림. '녹는다'는 개념 명확히, 생활 속 언제 녹는지. 보충: 얼음땡 놀이. 0 ℃ 어는점, 소금 뿌려 빨리 녹이기 |

## 단원 마무리 (교과서 109쪽)
- 물과 얼음: 얼음이 녹을 때 → 부피 감소, 무게 일정 / 물이 얼 때 → 부피 증가, 무게 일정
- 연소와 소화: 연소가 일어나기 위한 조건 = 탈 물질 + 산소 + 발화점 이상의 온도
- 단원 평가: ① 추운 겨울 강물이 얼었을 때 얼음은 강물에 (뜬다, 가라앉는다) → 뜬다 ② 화재가 발생했을 때는 (계단, 승강기)을/를 이용해 건물 밖으로 대피 → 계단
