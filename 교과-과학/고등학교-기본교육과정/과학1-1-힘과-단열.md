# 고등학교 과학① · Ⅰ. 힘과 단열 (기본교육과정)

- 교과서 6~55쪽 / 교사용 지도서 120~176쪽
- 중단원: 1. 중력과 마찰력(9차시) · 2. 단열과 우리 생활(11차시)
- 성취기준: [12과학01-04] 물체에 중력과 마찰력이 작용하여 나타나는 현상을 관찰하고 특성을 이해한다. [12과학01-02] 열의 이동을 막는 단열의 원리를 알고, 단열을 이용하는 일상생활 사례를 관찰한다.

## 단원 개관 (지도서 120~125쪽)
- 목표: 중력·마찰력 개념 이해 및 실생활 활용 역량; 온도 차로 열이 이동하는 것을 막는 단열 장치(사례) 관찰·적용 역량.
- 중력·마찰력은 일상 감각 경험으로 즉각 인식 쉬움. 중력가속도·중력의 단위·마찰계수는 다루지 않음. 장애 정도 심한 학생은 동영상·보조자료; 시각장애·중복장애는 거칠기·무게를 직접 느끼는 활동으로 대체.

### 핵심 아이디어
- [중력과 마찰력] 중력의 개념을 알고 중력을 이용하는 사례를 안다. 마찰력의 개념을 알고 마찰력에 영향을 미치는 요인을 말할 수 있다.
- [단열과 우리 생활] 단열의 원리를 알고 일상생활 속에서 효과적인 단열 방법을 적용할 수 있다.

### 단원 목표 (요약)
- 지식·이해: 중력·마찰력 정의 / 중력 방향 / 중력 이용 사례 / 마찰력 영향 요인(거칠기·무게) / 마찰력 크게·작게 하는 방법 / 단열 잘 되는 물질의 예 / 단열 이용 사례
- 과정·기능: 낙하·빗면 마찰력 실험 / 마찰력 크기 조절 방법 알아내기
- 가치·태도: 단열로 에너지 절약, 생태 감수성 / 중력·마찰력 이용 도구의 편리함 인식
- 과학과 생활: 놀이기구·스포츠·수력발전 등 중력 이용 / 스노타이어·장갑·썰매 등 마찰력 / 보온병·오븐 장갑·아이스박스 등 단열

### 연계
- 이미 배운(초등): 미는 힘·당기는 힘, 힘과 물체 위치 변화, 차가운 정도와 따뜻한 정도, 온도(5~6학년군), 무게 측정, 여러 가지 저울, 열의 이동
- 이 단원에서 다루지 않는 것: 중력가속도·중력 단위·마찰계수·정량적 실험·광합성 자세한 과정

### 단원 평가 중점
- 중력·마찰력 개념/방향/이용 사례 / 마찰력 크게·작게 상황 구분 / 영향 요인 / 단열 잘 되는 물질 / 단열 사례·적용 태도

## 단원 마무리 (교과서 55쪽)
- 중력과 마찰력: 물체를 놓으면 아래로 떨어짐 / 지구는 모든 물체를 지구 중심으로 당김 / 중력 이용 놀이기구·스포츠 / 마찰력=움직임 방해하는 힘 / 영향 요인=거칠기·무게
- 단열과 우리 생활: 열의 이동 속도 다름 / 뽁뽁이 열 이동 막음 / 주방 도구 안전 / 차가움 유지 / 보온병 / 방한용품·창문·동파 방지
- 단원 평가: 잡고 있던 물체를 놓으면 아래로 떨어지는 이유는 (중력). 비 오는 날 미끄러지지 않으려면 마찰력이 (큰) 신발. 단열 이용 물건: 보온병·두꺼운 점퍼.

## 차시 평가 모음 (지도서 176쪽)
- 중력과 마찰력: 물체를 놓으면 모두 아래로 떨어진다 / 지구는 모든 물체를 지구 중심으로 당긴다 / 중력 이용 놀이기구(자이로 드롭·롤러코스터·바이킹) / 중력 이용 스포츠(다이빙·스키·집라인·봅슬레이) / 마찰력=움직임 방해하는 힘 / 거칠수록 마찰력 커짐 / 무거울수록 마찰력 커짐 / 빙판길 미끄러지지 않으려면 마찰력 크게(❌ 작게) / 더 잘 미끄러지려면 마찰력 작게
