# 고등학교 과학① · Ⅲ. 인체와 유전 (기본교육과정)

- 교과서 108~159쪽 / 교사용 지도서 「교수·학습의 실제」 236~394쪽
- 중단원: 1. 인체의 구조와 기능(10차시) · 2. 인간의 성장과 유전(10차시, 과학 다지기·더하기·진로 연계 포함)
- 교과서 차시 틀: 도입 문장 → 활동 → **정리** 한 줄 → **평가** 한 문항. 지도서 차시 틀: 학습 목표 → 지도의 중점·유의점 → 교수·학습 자료 → 개요(도입·전개·정리 및 평가) → 기초·탐구·보충 활동 → 교사 Tip → 참고 자료

## 단원 개관 (지도서 236~239쪽)

- 단원 도입 그림: 사람의 성장 과정(태아기→유아기→아동기→청소년기→성인기). "모든 사람은 살아가기 위해 에너지가 필요하다."
- 목표: 소화·배설·순환·호흡기관의 구조와 기능을 일상생활과 연계하여 찾고 파악, 인간의 탄생과 성장 과정의 신체 변화 구분, 유전 현상을 가계도로 표현.
- 장애 정도가 심한 학생: 그림/모형 자료를 신체 해당 부위에 가까이 위치시켜 위치 파악, 기관의 명칭 말하기, 시기별 한눈에 관찰, 가계도 따라 그리기로 재구성.
- 시각장애·중복장애: 모형(촉각), 청각 자료, 직접 경험 활용.

### 핵심 아이디어

- [인체와 유전] 우리 몸은 다양한 기관으로 구성되어 있으며, 각 기관의 유기적인 작용으로 생명을 유지한다.

### 성취기준

- [12과학03-01] 소화·배설 기관의 구조와 기능을 관찰한다.
- [12과학03-02] 순환·호흡 기관의 구조와 기능을 관찰한다.
- [12과학03-03] 인간의 탄생과 성장 과정에서 나타나는 신체 변화를 구분한다.
- [12과학03-04] 인간의 유전 현상을 관찰하고 가계도를 이용하여 표현한다.

### 단원 목표 (요약)

- 지식·이해: 소화·배설·순환·호흡기관의 구조와 기능 설명 / 탄생·성장 과정 신체 변화 구분 / 유전 형질 종류와 가족 유전 형질 설명
- 과정·기능: 모형·실험으로 구조 관찰 및 기능 설명 / 탄생·성장 관찰·변화 설명 / 유전 현상 관찰·가계도 표현
- 가치·태도: 우리 몸에 대한 흥미와 호기심 / 기관 구조·기능 탐구 태도 / 우리 몸의 소중함 / 인간의 삶 가치
- 과학과 생활: 기관 건강 생활 습관 적용 / 생애 과정·가족과의 삶으로 탄생·성장·유전 이해 / 과학 탐구의 유용성 체험 / 가족 유전 형질 파악

### 연계

- 이미 배운 내용(초등): 우리 몸의 생김새(3~4학년군), 감각기관의 구조와 기능. (중학교 과정에서는 소화·배설·순환·호흡기관 미학습 → 이 단원에서 기본 이해 중점)
- 앞으로 배울 내용(고등): 뼈와 근육의 생김새와 기능, 우리 몸의 생활(과학②).

### 단원 평가 중점

- 소화·배설·순환·호흡기관의 구조와 기능을 설명할 수 있는가? / 몸속 기관 기능을 다양한 활동으로 이해할 수 있는가? / 몸속 기관 건강 유지 방법 실천할 수 있는가? / 인간의 탄생·성장 과정 신체 변화 설명할 수 있는가? / 인간의 유전 현상을 관찰하고 가계도로 표현할 수 있는가?
