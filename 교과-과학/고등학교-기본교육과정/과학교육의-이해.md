# 고등학교 과학 · 과학과 교육의 이해 (기본교육과정)

- 대상: 특수교육 고등학교 / 2022 개정 특수교육 기본 교육과정 과학과
- 교과 영역: 운동과 에너지 · 물질 · 생명 · 지구 (4개)
- 교과서 차시 체계: 도입 활동 → 기초 활동 / 탐구 활동 → 정리·평가 → 보충·심화(과학 다지기/더하기) → 일상생활 적용 → 단원 마무리

## 1. 과학과의 성격과 목표
- 맞춤형 교육과정: 장애 특성·교육적 요구 고려, 실생활 중심 기능적 과학적 문해 중시
- 성격: 모든 학생이 자연·일상 현상에 호기심을 갖고 과학 기본 개념·탐구 능력·태도를 기르는 과목; 장애학생은 생태학적 접근 기반 기능 중심 학습
- 목표: 자연·일상에 대한 흥미와 호기심 → 탐구 → 기초 과학 지식 → 일상 문제 해결 (과학적 소양); 세부 (1) 흥미·호기심·참여·협동 (2) 탐구 방법을 일상 문제에 적용 (3) 기초 개념 이해 (4) 과학·기술·사회 상호 관계 이해와 실천
- 추구 인간상: 자기주도·창의·교양·더불어 사는 사람 / 핵심역량 6종 / 고등학교 교육 목표 4종

## 2. 과학과의 내용 체계와 성취기준
- 내용 체계: 성격·목표 / 내용 체계 및 성취기준 / 교수·학습 및 평가
- 4영역 × 지식·이해 / 과정·기능 / 가치·태도 3차원, 학년군(초3-4·5-6·중·고) 연계
- 영역별 핵심 아이디어: 운동과 에너지 4개, 물질 3개, 생명 3개, 지구 4개
- 생명 영역 핵심 아이디어: 우리 몸 기관의 유기적 작용 / 동물·식물의 환경 적응·생장 / 생태계 구성요소의 상호 영향·균형
- 성취기준: 내용+기능 결합 형태, 성취기준 해설, 장애 정도 심한 학생 고려 사항 포함

## 3. 과학과의 교수·학습 및 평가
- 교수·학습 방향: 보편적 원칙 + 장애 특성 고려; 방법: 영역별 보편 방법·유의 사항·장애 고려 방법
- 평가 방향: 장애 특성 고려, 보편적 학습설계, 원격수업 평가; 평가 방법: 장애 정도 심한 학생 고려
- 교수·학습 방법: 관찰·분류·측정·예상·추리·의사소통 등 기초 탐구 중심, 실생활·사회 문제 적용

## 4. 과학과의 구성 요소
- 탐구 과정: 기초(관찰·측정·분류·예상·추리·의사소통) + 통합(문제 인식·가설 설정·변인 통제·컴퓨터 활용·모형 개발·논증·자료 해석·결론 도출·일반화)
- 기초 탐구 기능: 관찰(오감·도구), 측정(단위·오차), 분류(명확·비중복·일관), 예상(외삽/내삽), 추리, 의사소통
- 통합 탐구 기능: 문제 인식, 가설 설정(검증 가능), 추리, 의사소통 등
- 가치·태도: 자연·생명 존중, 관심·호기심, 적극 참여·협력, 위험 인식·대처, 과학 유용성, 상상력·창의성, 공동체 참여, 안전 생활 실천

## 5. 과학과의 교수·학습 모형 및 적용
- STS 수업 모형: 문제로의 초대 → 탐색 → 설명 및 해결 방안 제시 → 실행
  - 문제로의 초대: 일상·사회 문제 제기, 심각성 인식
  - 탐색: 개념 조사, 해결 방안 모색, 실험
  - 설명 및 해결 방안 제시: 대안 검토, 지식·경험 통합
  - 실행: 실천, 영향력 행사
- 적용 과제: 생태계 보전, 지진 대처, 공기·흙 오염 피해, 기후변화 대응
- 유의점: 일상 문제를 학생 자신의 문제로 인식·동기 유발, 시간 배정에 유의

## 6. 과학 교과 안전 지도
- 실험실 안전 용품·설비: 실험복·보안경·장갑, 눈 세척기·비상 샤워기, 소화기·모래 상자·물걸레, 알코올램프 대신 핫플레이트 권장
- 안전 장비: 실험복·보안경·보호 장갑·마스크, 소화기·모래주머니·환풍기, 비상 연락 체계 구축
- 학생 안전 수칙: 실험 전(선생님 안내, 긴 머리 정리, 실험복·보안경 착용) / 실험 중(젖은 손으로 전기 기구 금지, 시약 맛보기·냄새 맡기 금지, 장난·음식 금지, 깨진 기구는 교사에게 알림, 환기) / 실험 후(약품 정해진 곳에 폐기, 기구 세척·정리, 손 씻기)
- 야외 활동: 사전 계획·답사, 긴소매·긴바지·운동화, 향수 자제, 정해진 장소만, 손 씻기·옷 털기
- 사고 처리(CCC): Check(상황 파악·대피) → Call(관리자·보건 교사·보호자 보고, 119) → Care(처치), 원인 파악·보고·후속 조치

## 7. 과학과 교과용 도서의 구성 및 활용 방안
- 편찬 방향: 교육과정 충실히 반영, 삶과 연계·개별화 학습, 미래 대응(디지털·기후)·생태 감수성
- 개발 목표 8가지: 교육과정 목표·내용 충실 / 학교 교육 체제 적합 / 학습자 중심 / 세분화된 학습 활동 / 미래 변화 대응 / 과학적 태도 / 안전·생태 감수성·심미적 감성
- 구성 체계: 교과서 안내, 부록(뜯기 자료·붙임딱지), 분권(학년군 내 수준별), 단원 전개 체제(도입→전개→마무리)
- 단원 전개: 도입 활동 → 기초/탐구 활동 → 정리·평가 → 보충/심화 → 일상 적용; 날개에 안전·주의·지구를 위해·과학 다지기/더하기·디지털 활용·STEAM·진로 연계
- 활용: 단원 시작하기(구성 파악) → 활동하기(기초/탐구) → 단원 마무리(보충·심화·핵심역량·정리·평가)

## 8. 과학과 지도 계획
- 과학① 대단원: Ⅰ 힘과 단열 / Ⅱ 용액과 기체 / Ⅲ 인체와 유전 / Ⅳ 땅과 밤하늘
- 과학② 대단원: Ⅰ 전기와 빛 / Ⅱ 물질의 변화 / Ⅲ 동물·식물과 생태계(식물 구조와 기능·동식물 활용·생태계 보전) / Ⅳ 화산 활동과 지진
- 단원별 지도 계획: 대단원·중단원·차시(도입→기초→탐구→정리·평가)·단원 마무리(보충·심화·핵심역량·정리·평가)
