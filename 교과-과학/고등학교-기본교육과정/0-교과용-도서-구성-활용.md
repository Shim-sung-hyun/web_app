# 고등학교 과학 교과용 도서의 구성 및 활용 방안 (기본교육과정)

- 2022 개정 특수교육 기본교육과정 과학 **고등학교 1~3** 교과용 도서의 편찬 방향·구성·활용.
- 공통 이해는 [기본교육과정-과학의-이해.md](../기본교육과정-과학의-이해.md) 참고.

## 1. 기본 편찬 방향
- 교육과정을 충실히 반영하고 교육과정 중심 학교 교육 체제에 적합하도록 편찬. 학생이 과학에 관심·흥미를 갖고 자연현상을 이해하며 일상 문제를 과학적으로 해결하도록 함.
- **발달장애 학생이 일반 학생과 동일한 교육 경험을 공유**하면서 **개별 학생의 교육적 요구를 지원**하도록 구성.
- 3축: ① 교육과정 충실 반영(핵심 아이디어·핵심역량, 전인적 성장, 진로·삶 자율, 공동체 의식, 성취기준) ② 삶 연계·개별화(친숙한 자연·일상, 경험 반영, 장애 특성 맞춤, 쉽게 이해) ③ 미래 사회 대응(디지털 전환·기후변화, 과학적 소양, 심미적 감성, 생태 감수성, 포용성·민주시민성).
- 「기본 방향·주요 추진 내용」: 미래 변화 대응 특수교육 대상자 중심 중·고 교과서(과학적 소양 기반 개인 안녕, 자기주도성–창의와 혁신–포용과 시민성). 3개 영역(교육과정 충실 구현 / 미래 핵심역량 인재 / 실생활 맥락 삶·성장·자기주도 학습).

## 2. 개발 목표(가~사)
- **가** 교육과정 목표·내용 충실 반영(수준·학습량 적정화, 심화·보충, 과학적 소양·자기주도성·창의·포용·시민성).
- **나** 교육과정 중심 실생활 중심(현장 교사·전문가·과학 교육자·대학 교수 의견, 성취기준 중심 자기주도 학습).
- **다** 학습자 중심(개인차·발달 단계, 기초 탐구·문제 해결력, 활동·놀이, 다감각·다양한 표현·소재, 실물 사진·편집, 워크북·워크시트, 교사 활용 편리).
- **라** 세분화 학습 활동(차시별 ①기초 → ②일상 적용·문제 해결(심화 탐구), 중도·경도 수준; 중도는 다감각·조작·유희, 경도는 위계 세분화·순차).
- **마** 미래 대응·과학적 소양(단원 마무리 디지털·생태 감수성·진로·보충–심화).
- **바** 탐구 과정으로 과학적 태도(관찰·측정·비교·분류·예상·의사소통; 태도 우선).
- **사** 안전·생태 감수성·심미적 감성(날개 ‘안전’·‘주의’, ‘지구를 위해’).

## 3. 교과서 구성 체계
- 내용 요소 선정: 실생활 중심, 목표 달성, 개별화 지원, 장애 유형·특성 접근, 디지털·AI 환경, 진로 연계, 모든 대상 고려. 학년군 간 연계성 고려.
- 구성: (교과서 안내) 구성·활용, 쪽 번호 / (부록) 뜯기·붙임딱지 / (학년군 내 수준별 분권) / (단원 전개 체제).
- **단원 전개**: 단원 도입(단원명·목표·제재·전개 안내, 동기 유발) → 단원 전개(차시: 도입–전개–정리·평가–보충·심화–일상 적용·미래 대응) → 단원 마무리(보충·심화 + 디지털·AI, 생태 감수성, STEAM, 진로 연계 신설).
- **대단원–중단원–차시 모형**: 대단원(대표 이미지·발문, 핵심 아이디어·성취기준을 목표로, 스토리텔링) / 중단원(친숙 이미지, 실생활 연계, 주제) / 차시([수업도입]–[이미지]–[탐구활동: 기초·주요]–[정리·평가]–[보조단: 안전·주의]–[지구 사랑: 생태]).
- **과학 ①·② 단원 구성**:
  - ① Ⅰ.힘과 단열 / Ⅱ.용액과 기체 / Ⅲ.인체와 유전 / Ⅳ.땅과 밤하늘
  - ② Ⅰ.전기와 빛 / Ⅱ.물질의 변화 / Ⅲ.동물, 식물과 생태계 / Ⅳ.화산 활동과 지진

## 4. 교과서 활용 방안
- **단원 시작하기**: 단원명·안내·핵심 개념·중단원 목차로 구성 파악(대단원 개관에서 일상 연계 스토리텔링).
- **중단원 도입**: 제목·차시·안내, 삶·일상 연계 이야기로 학습 준비(뜯기·붙임딱지·전자책).
- **차시 학습**: 기초 활동 → 탐구 활동 → 정리·평가. 차시 도입에서 주제 확인·흥미로운 현상·질문으로 시작.
- **과학 다지기**(보충) / **과학 더하기**(심화).
- **단원 마무리**: 보충·심화, 핵심역량 함양 활동, 디지털 활용(디지털·AI 전환), 융합(STEAM), 생태 감수성(기후·생태), 진로 연계, 그림 개념 정리·단원 평가.
- 교사용 지도 계획: 단원별 차시 학습 주제·교수학습 내용·활동·주요 용어·지도 유의점·전자책등 제시. 차시별 안전 유의·수준별 선택·시범 실험 등 지침.
