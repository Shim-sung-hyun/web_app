## 단원 개관 (지도서 473~478쪽)

- 단원 도입 그림: 밤 도시 야경(조명·스마트폰 카메라) — 전기와 렌즈가 생활을 편리하게 하지만 잘못 사용하면 감전·화재가 발생할 수 있음.
- 목표: 전기 안전과 전기 절약 필요성을 인식하고 전기 기구의 올바른 사용법과 전기의 효율적인 이용 방법을 탐구·실천하는 역량을 함양하며, 렌즈에 대한 기본 개념을 익히고 일상생활에서 빛의 굴절을 인식하는 것에 지도의 중점을 둔다.
- 특수교육 고려: 장애 정도가 심한 학생은 최대-최소 촉진법으로 일상생활에 필요한 전기 기구를 독립적으로 사용하는 방법을 안전하게 지도. 시각장애 학생은 전기 기구에 점자를 붙여 지도. 전기 사고 상황은 학생이 모방하지 않도록 강조. 시각장애 학생은 안경·돋보기·확대경을 직접 활용해 렌즈 이해도를 높임.
- 성취기준 재구성 가능: 전기 절약과 관련된 구체적인 행동 수칙을 실천하는 성취기준으로 재구성하여 적용.

### 핵심 아이디어
- [전기와 자석] 전하나 전류는 다양한 전기 현상을 일으키며, 전기를 실생활에서 안전하게 사용한다.
- [소리와 빛] 빛은 반사·굴절 등 파동의 특성이 있으며 거울과 렌즈 등을 실생활에 활용한다.

### 성취기준
- [12과학01-01] 전기기구를 안전하게 사용하는 방법과 전기를 절약하는 방법을 조사하고 실천한다.
- [12과학01-03] 볼록렌즈와 오목렌즈로 물체를 관찰하고, 생활에서 렌즈가 이용되는 예를 조사한다.

### 단원 목표 (요약)
- 지식·이해: 전기 사고의 종류와 대처 방법 / 전기 기구의 안전한 사용법 / 생활 속에서 전기를 절약하는 방법 / 볼록 렌즈와 오목 렌즈의 특징 / 생활 속에서 렌즈가 이용되는 예
- 과정·기능: 생활 속 전기 사고 문제 인식 및 협력 해결 / 전기 기구의 안전한 사용법과 전기를 절약하는 방법 조사 / 오목 렌즈와 볼록 렌즈의 특징 관찰·분류 / 생활에서 렌즈가 이용되는 예 조사
- 가치·태도: 전기의 소중함과 유용성을 느끼고 전기 안전과 전기 절약의 필요성을 인식 / 생활 속에서 안전한 전기 사용을 실천하는 태도 / 렌즈를 사용하는 기기에 관한 관심과 호기심, 현상을 관찰하는 과학적 태도
- 과학과 생활: 전기 사고의 종류를 알고 예방법을 실천 / 전기 절약이 환경 보존과 관련이 있음을 알고 전기를 효율적으로 사용하는 태도 / 일상생활에서 렌즈의 활용과 유용성을 체험

## 단원 마무리 (교과서 57쪽)
- 전기 기구와 안전: 안전한 전기 사용 — 안 쓰는 플러그 뽑기
- 렌즈의 이용: 우리 주변의 렌즈 — 안경, 사진기
- 단원 평가 ① 전기 기구를 사용하지 않을 때 플러그를 뽑아 두면 전기를 절약할 수 있다. (○) ② 물이 닿을 수 있는 곳에서 전기 기구를 사용하지 않는 것은 전기를 안전하게 사용하는 방법이다. (○) ③ 볼록 렌즈는 작은 물체를 크게 볼 때 사용한다. (○) ④ 가까이 있는 물체가 보이지 않으면 볼록 렌즈를 이용한 돋보기안경을 사용한다. (○)

단원 정리(그림으로 단원 마무리): 사용하지 않는 플러그는 뽑아 두어야 전기를 절약할 수 있다 / 젖은 손으로 플러그나 전기 기구를 사용하면 위험하다 / 사용하지 않는 콘센트에 안전 덮개를 덮어 주면 안전하다 / 근시 안경은 오목 렌즈, 돋보기안경은 볼록 렌즈 / 카메라는 과속 단속과 범죄 예방에 사용 / 현미경은 작은 물체를 크게, 망원경은 멀리 있는 물체를 선명하게

## 차시 평가 모음 (지도서 529~531쪽)
- 전기 기구와 안전: 전기장판은 (열)을 내는 전기 기구이다. / 합선이나 누전으로 전기 화재가 발생할 수 있다. (○) / 감전 사고 시 전기가 (통하지 않는) 물체를 이용해 감전 요인에서 사람을 분리해야 한다. / 선풍기를 사용할 때 시간 설정 기능을 사용하여 전기 화재를 예방할 수 있다. (○) / 전기 안전을 위해 콘센트의 먼지를 주기적으로 확인하고 제거해야 한다. (○) / 전자레인지에 알루미늄 포일이나 유리병을 넣으면 사고가 발생할 수 있다. (○) / 전기를 절약하려면 외출할 때 텔레비전을 꺼야 한다. (○) / 전기를 절약하려면 항상 전등을 켜 두어야 한다. (❌) / 에너지 소비 효율 등급 숫자가 (낮을수록) 전기를 절약할 수 있다.
- 렌즈의 이용: 해를 등지고 분무기의 물을 분사하면 무지개를 관찰할 수 있다. (○) / 빛이 물속으로 비스듬히 나아갈 때 공기와 물의 경계에서 빛의 빠르기가 달라져 빛이 꺾여 나아간다. (○) / 물속에 있는 동전은 실제보다 (가까이) 있는 것처럼 보인다. / 가운데 부분이 가장자리보다 두꺼운 렌즈는 (볼록) 렌즈이다. / 볼록 렌즈로 멀리 있는 물체를 보면 물체가 (거꾸로) 보인다. / 오목 렌즈를 통과하는 빛은 렌즈의 가장자리 쪽으로 꺾여 퍼져 나아간다. (○) / 근시 안경을 쓰면 멀리 있는 물체를 선명하게 볼 수 있다. (○) / 사진기는 렌즈를 이용한 기구이다. (○) / 망원경은 렌즈를 이용해 멀리 있는 물체를 (크게) 볼 수 있는 기구이다.
