# 중학교 과학 교과용 도서의 구성 및 활용 방안 (기본교육과정)

- 2022 개정 특수교육 기본교육과정 과학 **중학교 1~3** 교과용 도서의 편찬 방향·구성·활용.
- 공통 이해는 [기본교육과정-과학의-이해.md](../기본교육과정-과학의-이해.md) 참고.

## 1. 기본 편찬 방향
- 교육과정을 충실히 반영하고 교육과정 중심 학교 교육 체제에 적합하도록 편찬. 자라나는 학생이 과학에 관심·흥미를 느끼고 ‘신나는 과학 탐구’로 자연현상을 이해하며 일상 문제를 과학적으로 해결하도록 함.
- 특히 **발달장애 학생이 일반 학생과 동일한 교육 경험을 공유**하면서 **개별 학생의 교육적 요구를 지원**하도록 구성.
- 3대 축:
  1. **교육과정 충실 반영** — 핵심 아이디어·핵심 역량 함양(전인적 성장, 진로·삶 자율 개척, 공동체 의식, 더불어 사는 삶, 성취기준 충실).
  2. **삶 연계·개별화** — 친숙한 자연·일상 연계, 경험 반영, 실생활 맥락에서 삶·성장 지원, 장애 특성 맞춤, 쉽게 이해.
  3. **미래 사회 대응** — 디지털 전환·기후변화 대응, 과학적 소양, 심미적 감성, 생태 감수성, 포용성·민주시민성.
- 「기본 방향·주요 추진 내용」: 미래 변화 대응 특수교육 대상자 중심 중·고 교과서(자기주도성–창의와 혁신–포용과 시민성). 3개 영역(교육과정 충실 구현 / 미래 핵심역량 인재 / 실생활 맥락 삶·성장 지원·자기주도 학습).

## 2. 개발 목표(가~사)
- **가** 교육과정 목표·내용 충실 반영(수준·학습량 적정화, 심화·보충, 과학적 소양·자기주도성·창의·포용·시민성).
- **나** 교육과정 중심 실생활 중심 교과서(현장 교사·전문가·과학 교육자·대학 교수 의견, 성취기준 중심 자기주도 학습).
- **다** 학습자 중심(개인차·발달 단계 고려, 기초 탐구·문제 해결력, 활동·놀이 탐구, 다감각·다양한 표현·소재, 실물 사진·편집, 워크북·워크시트, 교사 활용 편리).
- **라** 세분화 학습 활동(차시별 ①기초 → ②일상 적용·문제 해결 → ③심화 탐구, 중도·경도 수준 맞춤; 중도는 다감각·조작·유희, 경도는 위계 세분화·순차).
- **마** 미래 대응·과학적 소양(단원 마무리 디지털·생태 감수성·진로·보충–심화).
- **바** 탐구 과정으로 과학적 태도(관찰·측정·비교·분류·예상·의사소통; 태도 우선).
- **사** 안전·생태 감수성·심미적 감성(날개 ‘안전’·‘주의’, ‘지구와 함께’).

## 3. 교과서 구성 체계
- 내용 요소 선정: 실생활 중심, 목표 달성, 개별화 지원, 장애 유형·특성 접근, 디지털·AI 환경, 진로 연계, **장애 정도가 심한 학생 포함 모든 대상 고려**. 학년군 간 연계성 고려.
- 구성: [교과서 안내](구성·활용, 쪽 번호) / [부록](뜯기·붙임딱지) / [학년군 내 수준별 분권] / [단원 전개 체제].
- **단원 전개**: 단원 도입(단원명·목표·제재·전개 안내, 동기 유발) → 단원 전개(차시: 도입–전개–정리·평가–보충·심화–일상 적용·미래 대응) → 단원 마무리(보충·심화 + **디지털·AI 활용, 생태 감수성, STEAM, 진로 연계 신설**).
- **대단원–중단원–차시 모형**: 대단원(대표 이미지·발문, 핵심 아이디어·성취기준을 목표로, 스토리텔링) / 중단원(친숙 이미지, 실생활 연계, 주제 제시) / 차시([수업도입]–[이미지]–[탐구활동: 기초·주요]–[정리·평가]–[보조단: 안전·주의]–[지구를 위해: 생태]).
- **과학 ①·② 단원 구성**:
  - ① Ⅰ.무게와 열 / Ⅱ.액체와 혼합물 / Ⅲ.우리 몸 / Ⅳ.날씨와 기후변화
  - ② Ⅰ.전기와 소리 / Ⅱ.물 / Ⅲ.동물과 식물 / Ⅳ.바다의 모습

## 4. 교과서 활용 방안
- **단원 시작하기**: 단원명·안내·핵심 개념·중단원 목차로 구성 파악.
- **중단원 도입**: 제목·차시·안내, 삶·일상 연계 이야기로 학습 준비(붙임딱지·뜯기·전자저작물).
- **차시 활동**: 기초 활동 → 탐구 활동 → 정리·평가. 날개 ‘안전·주의’ 등 보조단 활용.
- **단원 마무리**: 보충(과학 다지기)·심화(과학 더하기), 핵심역량 활동, 진로 연계(예: 저울–약사·바리스타, 커리어넷), 디지털 활용, STEAM·생태 감수성, 그림 개념 정리·단원 평가.
- 교사용 지도서는 단원별 지도 계획으로 차시별 방법·유의점·전자저작물 유형을 안내(중도·경도 수준 맞춤). 예: 밀도·돌림힘·중력·전도·대류 등 개념은 다루지 않고 정성적 접근, 체중 직접 비교 지양, 뜨거운 물·전기·날카로운 도구 안전 유의, 소리 민감 학생 배려.
