# 중학교 과학① · Ⅰ. 무게와 열 (기본교육과정)

- 교과서 6~61쪽 / 교사용 지도서 「교수·학습의 실제」 108~177쪽
- 중단원: 1. 수평 잡기(8차시) · 2. 무게 측정(6차시) · 3. 열의 이동(12차시: 10차시 + 과학 다지기 + 과학 더하기 + 진로 연계)
- 교과서 차시 틀: 도입 질문 → 활동 두 개(①②) → **정리** 한 줄 → **평가** 한 문항. 곳곳에 「과학 용어」, 「지구를 위해」, 「도움말」, 「안전」·「주의」 상자. 붙임딱지 쪽수 표시(19).
- 지도서 차시 틀: 학습 목표 → 지도의 중점 → 지도의 유의점 → 교수·학습 자료 → 교수·학습 개요(도입·전개·정리 및 평가) → 기초 활동 / 탐구 활동 / 보충·심화 활동 → 교사 Tip → 참고 자료

## 단원 개관 (지도서 108~111쪽)
- 단원 도입 그림: 쌀·밀가루·커피의 무게 측정 / 벽난로에 타오르는 모닥불 — "생활 속 무게 측정 방법과 열의 이동 원리를 알아봅시다."
- 목표: 무게와 열의 기본 개념을 체험 활동으로 익히고 실생활에 적용. 무게는 들었을 때 힘이 드는 감각 경험 → 어림 → 측정 순, 열은 온도가 높은 곳에서 낮은 곳으로 이동함을 실험으로 확인.
- 체험 활동 위주, 생활 속 물건 사용. 수준에 따라 낮은 학생용(두 물체 비교)부터 높은 학생용(쌀알로 같은 무게 맞추기)까지 고르게 배치.
- 중복·시각장애 학생: 음성 저울 등 보조 기구 제공, 열의 이동은 촉각 자료로 확인.

### 핵심 아이디어
- [수평 잡기] 무거움과 가벼움의 개념을 알고, 양팔저울을 이용해 무게를 비교하는 방법을 알 수 있다.
- [무게 측정] 무게 측정의 필요성을 인식하고, 다양한 저울의 사용법을 말할 수 있다. 또한 일상생활 속 다양한 상황에서 어떤 저울을 사용해야 하는지 고를 수 있다.
- [열의 이동] 열은 온도가 높은 물체에서 낮은 물체로 이동함을 알고, 일상생활 속에서 열이 이동하는 사례와 열의 이동 방향을 설명할 수 있다.

### 성취기준
- [9과학01-04] 수평 잡기 활동을 통해 물체의 무게를 비교하고, 여러 가지 무게 측정 방법에 흥미를 갖는다.
- [9과학01-05] 무게를 정확히 측정하려면 저울이 필요함을 알고, 저울을 사용해 무게를 측정하고 비교한다.
- [9과학01-02] 고체, 액체, 기체에서의 열의 이동을 알고, 열의 이동이 나타나는 일상생활 속 사례를 관찰한다.

### 단원 목표 (요약)
- 지식·이해: 무게의 개념 말하기 / 무게 측정 방법 설명 / 열의 이동 방향 말하기
- 과정·기능: 무게 어림하기 / 양팔저울로 무게 비교 / 쓰임새에 맞는 저울 선택 / 열 이동 실험 수행 / 무게 측정 직업 탐색
- 가치·태도: 무거움·가벼움에 대한 호기심, 온도·열 이동에 대한 흥미, 정확한 측정의 필요성 인식, 에너지 절약과 안전
- 과학과 생활: 화재 대피 방법과 열의 이동, 냉난방 기구 배치와 에너지 절약

### 연계
- 이미 배운 내용(초등): 미는 힘과 당기는 힘(3~4학년군), 힘과 물체의 위치 변화(3~4학년군), 차가운 정도와 따뜻한 정도(3~4학년군), 온도(5~6학년군)
- 앞으로 배울 내용(고등): 중력과 마찰력 / 삶(가정 및 생활): 단열
- 이 단원에서 다루지 않는 것: 무게의 단위·단위 변환, 질량과 무게의 차이, 밀도의 정의, 돌림힘, 전도·대류·복사 용어

### 단원 평가 중점
무거움·가벼움 개념을 감각과 연계해 말하기 / 무거운 순서 나열 / 무게 어림·대소 비교 / 수평 조건·시소 평형 설명 / 양팔저울 사용법·비교 / 무게 측정 필요성 / 쓰임새별 저울 선택 / 고체·액체·기체 열 이동 방향과 사례.

## 1. 수평 잡기 (교과서 8~23쪽, 지도서 116~133쪽)

## 3. 열의 이동 (교과서 38~61쪽, 지도서 148~173쪽)
도입(38~39쪽): 냄비(밑바닥·물·수증기) — "열은 어느 방향으로 이동할까요?"
