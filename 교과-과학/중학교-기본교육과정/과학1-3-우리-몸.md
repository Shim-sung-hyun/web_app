# 중학교 과학① · Ⅲ. 우리 몸 (기본교육과정)

- 교과서 114~165쪽 / 교사용 지도서 「교수·학습의 실제」 244~309쪽
- 중단원: 1. 감각기관(12차시) · 2. 뼈와 근육(12차시 + 과학 다지기·더하기 + 진로 연계)
- 교과서 차시 틀: 도입 그림/질문 → 활동 두 개(①, ②) → **정리** 한 줄 → **평가** 한 문항. 곳곳에 「지구를 위해」, 「과학 용어」, 「도움말」, 「주의」 상자. 붙임딱지 쪽수 표시(13·15·17·19).
- 지도서 차시 틀: 학습 목표 → 지도의 중점·유의점 → 교수·학습 자료 → 개요(도입·전개·정리 및 평가) → 기초 활동 / 탐구 활동 / 보충·심화 활동 → 교사 Tip → 참고 자료

## 단원 개관 (지도서 244~249쪽)

- 단원 도입 그림: 학생들이 공놀이하는 모습(공을 차고 잡는 모습) — "살아 있는 생물이 외부의 자극을 받아들이고 적절한 행동을 하며 신체를 건강하게 유지하는지 알아봅시다."
- 목표: 세상의 자극을 받아들이는 감각기관의 구조와 기능을 관찰하고, 자극에 대한 작동 과정을 모의실험으로 관찰. 우리 몸을 구성하는 뼈와 근육의 생김새와 기능을 관찰해 건강하게 유지하는 방법 실천.
- 특수교육 대상 학생: 신체를 직접 촉진하거나 모형 조작, 그림·동영상 시청으로 간접 경험. 명칭 따라 말하기, 명칭과 기능 짝짓기로 재구성 가능. 시각장애·중복장애: 촉각 모형·촉진, 언어적 정보 충분히 제공.
- 시각장애·중복장애: 촉각 모형, 청각 자료 활용.
- 성취기준 재구성 가능: 내부 구조의 명칭 대신 "감각기관의 종류와 위치 말하기", "뼈와 근육의 생김새와 명칭 설명하기" 등으로 단순화.

### 핵심 아이디어

- [우리 몸] 우리 몸은 다양한 기관으로 구성되어 있으며, 각 기관의 유기적인 작용으로 생명을 유지한다.

### 성취기준

- [9과학03-01] 감각기관의 구조와 기능을 관찰한다.
- [9과학03-02] 우리 몸을 구성하는 뼈와 근육의 생김새와 기능을 관찰한다.

### 단원 목표 (요약)

- 지식·이해: 감각기관의 종류·위치 말하기 / 구조와 기능 설명 / 뼈와 근육의 생김새·명칭 설명 / 움직임 관찰해 기능 설명

- 가치·태도: 우리 몸에 대한 흥미와 호기심 / 감각기관·뼈와 근육 건강 유지 생활 습관 / 안전 수칙 준수 / 건강한 신체 유지 태도
