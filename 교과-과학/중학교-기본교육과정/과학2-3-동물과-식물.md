# 중학교 과학② · Ⅲ. 동물과 식물 (기본교육과정)

- 교과서 112~167쪽 / 교사용 지도서 「교수·학습의 실제」 622~689쪽
- 중단원: 1. 동물의 생활(7차시) · 2. 식물의 생활(9차시) · 3. 생태계와 환경(10차시: 8차시 + 과학 다지기·더하기 + 진로 연계)
- 교과서 차시 틀: 도입 문장 → 활동 두 개(①, ②) → **정리** 한 줄 → **평가** 한 문항. 곳곳에 「지구를 위해」, 「과학 용어」, 「도움말」, 「안전」·「주의」 상자. 붙임딱지 쪽수 표시(13·15·17·19).
- 지도서 차시 틀: 학습 목표 → 지도의 중점·유의점 → 교수·학습 자료 → 개요(도입·전개·정리 및 평가) → 기초 활동 / 탐구 활동 / 보충·심화 활동 → 교사 Tip → 참고 자료

## 단원 개관 (지도서 622~625쪽)
- 단원 도입 그림: 초원 생태계(동물·식물·비생물요소가 모여 생태계를 이룸).
- 목표: 동물과 식물이 환경의 영향을 받으며 산다는 것을 탐구, 생김새·생활 방식이 환경과 관련 있음을 인식, 생물적·비생물적 환경 조건 이해. 생태학적 감수성과 자연보호 태도.
- 동물은 희귀한 동물보다 **주변에서 쉽게 볼 수 있거나 친숙한 동물** 중심.
- 장애 정도가 심한 학생: 학교 근처, 동물원, 수족관에서 직접 관찰. 어려우면 동물도감·식물도감, 실감형 콘텐츠. '가치·태도'에 중점.
- 시각장애·중복장애: 생물요소는 조작할 수 있는 모형(촉각)이나 청각 자료(동물 울음소리), 빛·물·온도·바람은 교실 안팎에서 직접 경험.
- 성취기준 재구성 가능: 생태계 구성 요소 대신 "구성 요소의 명칭 말하기", "생활 속 환경오염 예방 실천 방법 익히기".

### 핵심 아이디어
- [동물과 식물] 동물과 식물은 환경에 적응해 다양한 생김새와 생활 방식으로 생장한다.
- [생태계와 환경] 생태계의 구성 요소들은 서로 영향을 주고받으며 균형을 이룬다.

### 성취기준
- [9과학03-03] 다양한 환경에 서식하는 동물을 관찰하고, 동물의 생김새와 생활 방식이 환경과 관련되어 있음을 인식한다.
- [9과학03-04] 다양한 환경에 서식하는 식물을 관찰하고, 식물의 생김새와 생활 방식이 환경과 관련되어 있음을 인식한다.
- [9과학03-05] 식물의 생장에 환경이 중요함을 알고, 실험을 통해 식물의 생장 조건을 찾는다.
- [9과학03-06] 생태계를 생물 요소와 비생물 요소로 분류한다.

### 단원 목표 (요약)
- 지식·이해: 다양한 환경에 사는 동물·식물의 종류 말하기 / 서식 환경에 따른 생김새·생활 방식 차이 설명 / 생물요소·비생물요소 구분 / 식물 생장 조건 설명
- 과정·기능: 서식 환경별로 관찰·분류 / 씨가 싹 트는 조건 추론 / 식물이 자라는 조건 찾기 / 생물·비생물요소 분류, 환경오염 예방 수칙 실천
- 가치·태도: 생태 감수성, 동물과 식물을 사랑하고 소중히, 수질·대기·토양오염에 호기심과 실천 의지
- 과학과 생활: 일상의 동물·식물 소개, 오염 대응 실천, 과학 탐구의 유용성 체험

### 연계
- 이미 배운 내용(초등): 동물·식물·생물의 특징(3~4학년군), 동물·식물의 한살이, 동물·식물의 생활(5~6학년군) → 이 저장소의 [`초5-기본교육과정/`](../초5-기본교육과정/README.md) 2·5단원과 이어짐
- 앞으로 배울 내용(고등): 뿌리·줄기·잎·꽃의 구조와 기능, 생활 속 동물과 식물의 이용. 먹이 사슬은 고등학교 과학②.
- 이 단원에서 다루지 않는 것: 광합성의 자세한 과정, 먹이 사슬, 생물–비생물요소의 구체적 상호 작용(고등).

### 단원 평가 중점
개별 맞춤형 과정 중심 평가. 좋아하는 동물·주변 동물 말하기 / 서식 환경에 따른 식물 구분 / 잎의 형태적 특징 / 씨의 공통점과 차이점 / 실험으로 생장 조건 찾기 / 생태계 보전 실천.

## 1. 동물의 생활 (교과서 114~127쪽, 지도서 628~643쪽)
도입(114~115쪽): 다람쥐, 개미, 버들치, 백로 — "서식 환경에 따라 동물의 생김새와 생활 방식은 어떻게 다를까요?"
학습 용어: 동물(길짐승·날짐승·물고기·벌레·사람 따위를 통틀어 이르는 말), 서식 환경, 사막, 둥지.

## 2. 식물의 생활 (교과서 128~147쪽, 지도서 644~663쪽)
도입(128~129쪽): 들, 산, 강이나 연못, 사막 4컷 — "서식 환경에 따라 식물의 생김새는 어떻게 다를까요?"
학습 용어: 서식지, 수생식물(부유·부엽·정수·침수식물), 식물의 생장. 교과서는 풀(초본)과 나무(목본)로 쉽게 구분.
