# 5-1 · 2. 동물의 한살이 (42~79쪽, 주인공 솔이)

단원 안내: 동물은 어떤 과정을 거치며 자랄까요? — 새끼를 낳는 동물 / 알을 낳는 동물 / 한살이 관찰·조사

## 1. 새끼를 낳는 동물의 한살이 (도입 44~45쪽: 삼촌네 소가 송아지를 낳는 날)

| 차시 | 쪽 | 제목 | 주요 활동 | 꼭 기억해요 / 정리 |
|---|---|---|---|---|
| 1 | 46~47 | 개의 한살이를 알아봅시다 | 할머니 댁 진돗개. 갓 태어난 새끼 강아지(어미 젖) → 큰 강아지(다 자란 개와 비슷) → 다 자란 개(몸집·힘, 암컷은 새끼를 낳음). 몸으로 표현, 펼침책 만들기, 강아지–다 자란 개 사진 붙이기(부록 43쪽) | 동물은 태어나서 자라고, 새끼를 낳고, 늙어서 죽는다 = **동물의 한살이**. 1. 개는 새끼를 낳는 동물입니다. 2. 개는 갓 태어난 새끼 강아지, 큰 강아지, 다 자란 개의 한살이를 거칩니다. 3. 강아지와 다 자란 개는 생김새가 비슷합니다. 정리: 순서대로 숫자 쓰기 |
| 2~3 | 48~51 | 새끼를 낳는 여러 동물의 한살이를 비교해 봅시다 | 고양이·돼지·토끼·소 알아보기(부록 43쪽). 고양이·돼지 한살이 카드 순서대로(갓 태어난 새끼 → 새끼 → 다 자란). 순서에 맞게 붙이고 공통점 찾기(부록 11쪽) | 1. 고양이와 돼지는 새끼를 낳는 동물입니다. 2. 새끼 동물, 다 자란 동물의 한살이를 거칩니다. 3. 새끼 동물과 다 자란 동물의 생김새가 비슷합니다. 4. 다 자란 암컷이 새끼를 낳을 수 있습니다. 정리: 새끼–다 자란 동물 연결 |

## 2. 알을 낳는 동물의 한살이 (도입 52~53쪽: 솔이네 금붕어가 알을 낳음)

| 차시 | 쪽 | 제목 | 주요 활동 | 꼭 기억해요 / 정리 |
|---|---|---|---|---|
| 4 | 54~55 | 오리의 한살이를 알아봅시다 | 호수 공원 오리 가족. 알(옆으로 길쭉한 둥근 모양, 하얀색) → 새끼 오리(태어나 한 시간이면 혼자 걸음) → 다 자란 오리(암컷은 알을 낳음). 몸으로 표현, 돌림책(부록 83~85쪽) | 1. 오리는 알을 낳는 동물입니다. 2. 오리는 알, 새끼 오리, 다 자란 오리의 한살이를 거칩니다. 정리: 빈칸 사진 붙이기(부록 11쪽) |
| 5 | 56~57 | 금붕어의 한살이를 알아봅시다 | 알(투명, 아주 작음) → 새끼 금붕어(노란색·주황색으로 변하기 시작) → 다 자란 금붕어(지느러미·몸집 커짐). 작은 책 만들기, 카드 순서(부록 45쪽) | 1. 금붕어는 알을 낳는 동물입니다. 2. 알, 새끼 금붕어, 다 자란 금붕어의 한살이를 거칩니다. 3. 다 자란 암컷이 알을 낳을 수 있습니다 |
| 6~7 | 58~61 | 알을 낳는 여러 동물의 한살이를 비교해 봅시다 | 거북이 모래 구덩이에 알 낳는 텔레비전 장면. 거북·닭·참새·개구리와 알 연결(부록 45쪽). 거북(알 연한 갈색·흰색, 길쭉 → 새끼 거북 등껍질 얇음 → 다 자란 거북 등껍질 단단), 닭(알 둥글고 흰색 → 병아리 노란 솜털, 삐악삐악 → 다 자란 닭 꼬끼오·꼬꼬댁, 암탉이 알). 공통점·차이점(부록 13쪽) | 1. 거북과 닭은 알을 낳는 동물입니다. 2. 알, 새끼 동물, 다 자란 동물의 한살이를 거칩니다. 3. 다 자란 암컷이 알을 낳을 수 있습니다. 4. 동물마다 알의 생김새가 다릅니다. 정리: 알을 낳는 동물 ○표 |

## 3. 동물의 한살이 관찰·조사하기 (도입 62~63쪽: 텃밭의 나비 — 새끼를 낳을까, 알을 낳을까?)

| 차시 | 쪽 | 제목 | 주요 활동 | 꼭 기억해요 / 정리 |
|---|---|---|---|---|
| 8 | 64~65 | 배추흰나비의 한살이를 알아봅시다 | 알(아주 작음) → 애벌레(기어다니며 먹고 허물 벗음) → 번데기(움직이지 않음) → 어른벌레(훨훨). 몸으로 표현, 당김책(부록 87~92쪽) | 배추흰나비는 알, 애벌레, 번데기, 어른벌레의 한살이를 거칩니다. 정리: 순서대로 숫자 |
| 9~10 | 66~69 | 배추흰나비의 한살이 관찰 계획을 세워 봅시다 | 나비 체험관 다녀옴. 준비물(알, 애벌레 먹이 케일, 사육 상자), 관찰 도구(돋보기, 스마트 기기). 주의점: 알·애벌레를 손으로 만지지 않기 / 근처에서 모기약 쓰지 않기 / 케일에 물 주기 / 생명을 소중히. 관찰 계획서(기간·장소·도구·내용·주의점, 부록 13쪽). 사육 상자 만들기(케일 모종 심기 → 지지대 네 개 → 방충망·고무줄) | 1. 돋보기나 스마트 기기를 사용합니다. 2. 알과 애벌레를 손으로 만지지 않습니다. 3. 생명을 소중히 여기는 마음을 지닙니다. 정리: 관찰 도구 ○표 |
| 11 | 70~71 | 배추흰나비 알과 애벌레를 관찰해 봅시다 | 알 생김새·색·움직임(실제 크기). **부화**: 애벌레가 알껍데기를 뚫고 나오는 과정(알 속에서 움직임 → 뚫고 나옴 → 알껍데기를 갉아 먹음). 허물 1~4번 벗은 애벌레. 관찰 기록(부록 15쪽) | 1. 손으로 만지지 않고 관찰 도구를 사용합니다. 2. 생명을 소중히 여기는 마음을 지닙니다. 정리: 알은 움직이지 않음 / 애벌레는 움직임 |
| 12 | 72~73 | 배추흰나비 번데기와 어른벌레를 관찰해 봅시다 | 번데기 되기(입에서 뽑은 실로 몸 묶음 → 머리부터 허물 → 번데기 → 주변 색과 비슷하게). **날개돋이**: 번데기에서 어른벌레가 나오는 과정(번데기 투명 → 머리부터 → 몸 전체 → 날개 펴고 마르면 날 수 있음). 관찰 기록, 관찰 일기장(부록 15쪽) | 정리: 번데기는 움직이지 않음 / 어른벌레는 움직임 |
| 13 | 74~75 | 반려동물의 한살이를 조사해 봅시다 | 동물 보호소 봉사 이야기. 기르고 싶은 반려동물 색칠(고슴도치·개·앵무새·닭·고양이·햄스터)과 이유, 입양 신청서. 동물도감으로 한살이 조사 — 새끼를 낳는 동물은 파란 표, 알을 낳는 동물은 빨간 표(부록 17~19·93~97쪽) | 정리: 나의 반려동물은 ( 알 / 새끼 )을/를 낳는 동물 |

## 보충·심화
- **보충(76쪽) 새끼를 낳는 동물과 알을 낳는 동물 분류하기**: 사다리 길 따라가 붙임딱지(부록 47쪽)
- **심화(77쪽) 동물의 암수 생김새**: 개(비슷), 사자·금붕어·장수풍뎅이(비슷/다름 고르기), 사슴·원앙 암수 다른 점 ○표

## 단원 마무리 (78~79쪽)
- 되짚어 보기: 새끼를 낳는 동물(새끼 → 다 자란 동물, 생김새 비슷, 개의 한살이) / 알을 낳는 동물(알 → 새끼 → 다 자란 동물, 알 생김새 다름, 오리의 한살이) / 배추흰나비(알·애벌레·번데기·어른벌레, 돋보기·스마트 기기, 생명 존중)
- 생각 키우기: 고래의 한살이 예상(몸이 크고 무거움, 어미 젖을 먹고 자람, 암컷이 새끼를 낳음 → 새끼를 낳는 동물). 부록 47쪽
