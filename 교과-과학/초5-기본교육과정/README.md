# 기본교육과정 과학 5학년 (5-1, 5-2)

## 책 구성
- **단원 안내** — 사진을 보고 배울 내용을 이야기한다.
- **중단원 도입** — 그림과 이야기로 시작한다.
- **기초활동(초록 단추)** — 관찰과 탐색으로 과학 개념을 배운다.
- **주요활동(빨간 단추)** — 기초활동에 이어지는 탐구활동이다. 「무엇이 필요할까요?」(준비물), 「어떻게 할까요?」(순서)가 붙는다.
- **차시 끝** — 「꼭 기억해요」(핵심 내용·용어), 「정리해 볼까요?」(간단한 문항)
- **보충(더 알아볼까요?)** — 기초활동 내용으로 하는 놀이·조작 활동
- **심화** — 주요활동 내용을 실생활에 쓰는 활동
- **단원 마무리** — 되짚어 보기, 생각 키우기
- 차시마다 이야기 주인공이 나온다: 1단원 나영, 2단원 솔이, 3단원 미소, 4·5·6단원 지수, 7단원 민희.
- 붙임딱지와 부록 쪽수(예: `79`, `83~85`)가 활동 곳곳에 나온다.

## 눈에 띈 점 (앱 만들 때 참고)
- 4-13차시 「정리해 볼까요?」에 4단원 주인공(지수)이 아닌 "미소"가 나온다(3-6차시 문항을 옮긴 듯).
- 6-3차시 정리 2번은 답 "(반사)"가 이미 채워져 있다.
- 6단원 "평면거울은 오른쪽과 왼쪽이 반대로 보입니다"는 교과서 표현 그대로다(엄밀히는 앞뒤가 바뀜).
- 1-11차시 정리 문항은 "가볍고 단단하여 머리를 보호할 수 있는 모자"(안전모)인데, 앞 활동에서는 안전모를 플라스틱으로 연결한다.
